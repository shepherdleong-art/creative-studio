# 批量包装位置调整闪屏修复

用户反馈：批量「检查成片」中拖动卖点调整位置，松手后画面闪一下，像重新加载。

## 原因与修复

`BatchReviewPreviewDock` 将 `editRevision` 同时放进 `BatchPackagingOverlay` 的 React key 和包装 iframe URL。一次 `set_packaging` 保存递增修订后，会卸载包装组件、重新请求整份 HTML。底片播放器仍存在，但文字、字体、动画与编辑桥重新初始化，产生可见闪烁。

隔离浏览器复现命令为 `node scripts/batch-packaging-preview-stability.playwright.test.mjs`。修复前，一次真实鼠标拖动后 `sameFrame=false`、`sameDocument=false`，包装 HTML 请求由 1 次变成 2 次，测试失败。单独稳定组件 key 后仍会请求新 HTML，确认 URL 也是独立触发点。

修复后的包装组件按成片/输出版本保留，包装文档按实际内容更新；版式变化通过模板现有 `__pointLayout.apply` 同步，保存与撤销继续使用原版本/修订校验。撤销、重做、恢复默认及保存失败回滚不重载；同内容轮询不覆盖正在拖动的草稿。文案、字体、模板、时序、封面来源变化仍重新生成文档。

PR 基于 `main`（`9e062d69`）独立实现，不依赖贴纸集成。共享 `PackagingOverlay` 增加可选 `onFrame` 回调，让批量包装同步现有 iframe 的版式；原调用方不传回调时保持原行为。main 原版也已用同一测试复现 `sameFrame=false`、`sameDocument=false` 和第二次 HTML 请求。
