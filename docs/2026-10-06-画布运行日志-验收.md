# 画布运行日志

日期：2026-10-06。分支：`codex/infinite-canvas-beta`。

## 交付

- 编辑器右上角「运行日志」显示当前画布记录；任务列表的「查看日志」显示该任务记录，跨画布任务使用所属画布的查询地址。
- 复用原项目 `LogDrawer` / `LogViewer`，支持每秒刷新、级别筛选、复制全部／错误、手动刷新和自动滚动。查询失败显示错误提示；兼容原项目 SQLite UTC 时间和画布 ISO 时间。
- schema v4 追加独立日志表，经过原有备份与升级 gate，不借用旧项目／任务表。新任务记录排队、准备、提交、远端身份、查询异常、下载、成功、失败及恢复／停止操作。正常轮询与租约心跳不刷屏。
- 未有阶段记录的历史任务显示状态快照，首次恢复前保留其遗留错误；不能还原此前未记录的全过程。
- 数据库和 `storage/logs/canvas-YYYY-MM-DD.log` 使用脱敏内容，移除密钥、鉴权串和 URL 查询参数。文件路径基于 `dataRoot()`，文件名日期使用 UTC。
- 日志抽屉打开期间禁用画布编辑快捷键，Esc 关闭抽屉，避免查看日志时误删节点。
