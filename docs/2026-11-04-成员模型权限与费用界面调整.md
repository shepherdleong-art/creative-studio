# 成员模型权限与费用界面调整

## 使用方式

- 账号与权限 → 成员行“模型与额度”：可不限模型，或勾选允许调用的模型；限定模式下不勾选任何模型代表禁止调用。已有账号默认不限模型，不改变原有权限。
- 公共 BGM 库列表最大高度 480px，在列表内上下滚动，上传区域不随曲目数量增长。
- 团队模式 `/usage` 只展示“费用与用量”。上方“我的额度”始终属于当前登录人；明细默认仅看自己，管理员可以切换全团队，明细展示成员身份。旧的本地核心模型仪表盘仍用于 local 模式。
- 已计金额包含费用预留，不能将“已计”和“待结算预留”再次相加。金额是工作台估算与结算记录，并非供应商最终账单。

## 实现约定

- execution 追加 v5 迁移，沿用共享升级 gate，保存 `allowedModelsJson`；NULL 表示不限，空数组表示全部禁止。
- 模型列表与额度共用策略版本和 IMMEDIATE 事务。旧客户端省略 `allowedModels` 时保留已有权限；员工不得改策略，过期版本返回 409。
- 统一准入和提交意图落库前均检查模型权限；精确匹配服务端快照的配置模型、模型、请求模型或画布模型别名，不以计价别名或前缀授权。受限策略缺少模型身份时拒绝。已受理任务的收取和结算不受影响。
- 模型选项来自已有供应商配置及历史执行快照，接口仅返回模型标识、名称与分类；还可填写完整模型标识以覆盖自定义调用。
- `/api/team/usage` 默认个人范围；管理员显式 `scope=team` 才查询全团队，员工传入该参数仍限制在自己。CSV 导出保留管理员的团队口径。
- 长上游请求 ID 收进可展开详情，费用列前移并固定表格布局。

## 验证

- 通过 execution-operations、execution-admission、execution-attempts、execution-admission-contention、team-usage-admin、team-usage-routes、team-usage-ui-contract、usage-ui-contract。迁移验证包含 v4 已有账号升级后保留额度、并发、暂停和版本，同时默认不限模型；重复启动不重复执行迁移。
- 新增覆盖：精确模型匹配、空白名单、缺模型身份、发送前撤销授权、重新授权恢复、旧客户端保留限制、过期版本冲突、员工越权拒绝；模拟另一成员费用，验证管理员个人 / 团队范围及员工隔离。
- 定向 ESLint 通过；`npm run check:main-path` 通过，真实付费调用为零。
- 使用隔离数据根与模拟接口完成 Playwright 浏览器验收：模型勾选及保存请求、80 首 BGM 容器滚动、本人 / 全团队切换、长请求 ID 不撑宽表格、深色模式均通过，无浏览器异常。截图在本机 `outputs/team-ui-review/`；临时验收页面已移除。
