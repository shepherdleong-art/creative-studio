# 短片段选中与修剪修复

用户反馈批量时间轴中自动安排的短片段难以拉伸、删除。隔离浏览器复现使用真实时间轴组件与 CSS，不连接应用服务和用户数据库。

根因：0.25 秒片段在默认缩放下被撑到 16px，左右修剪手柄各 10px，覆盖区域重叠 6px；点击中心命中右手柄，手柄又不设置选中对象，因此删除没有目标。缩小后固定最小宽度还会遮住相邻片段。

修复对应 PRD T-04、执行验收 A13/A18：视频按时间比例显示（仅保留 1px 可见下限），手柄各不超过宽度的 25%；主体和边缘按下即选中正确片段，缩略图关闭浏览器原生图片拖动。新增「放大片段」将缩放调至 180px/s 并水平定位选中片段。修剪仍受源时长、相邻片段、0.5 秒下限与 24fps 限制。

验证命令：`node scripts/batch-review-short-clips.playwright.test.mjs`。修复前断言“窄片段中心必须可以选中”失败，修复后覆盖中心/边缘选中后删除、最小缩放下相邻短片段独立命中、双边拉长、每次拖动只保存一次、Esc 取消与放大。此测试验证浏览器事件及提交命令；保存边界由 `batch-output-clip-edit.test.ts` 回归，非整帧接缝由 `batch-review-video-trim.test.ts` 回归。
