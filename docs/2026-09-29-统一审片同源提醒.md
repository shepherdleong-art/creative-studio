# 统一审片同源提醒

## 最终行为

自动生成及「换一批画面」不把同一原始分镜图生成的不同视频自动放入同一条成片，即使分镜组或运镜不同也按同源处理。素材不足以完整排片时报告原因并保留旧成片，不生成含同源兄弟或循环窗口的替代品。

手动编辑与自动排片分开：插入、替换、撤销、确认、导出只提醒，不强行阻止。人工明确锁定的画面保留，自动部分预留其版本与源区间，不额外加入同源兄弟。

判断使用 `resolveModule4AssetGroupKeys` 的权威来源链，不以文件名、缩略图或生成候选图归组。纯分割同一视频、封面、跨成片使用不触发这条提醒。旧成片无需重建或改写即可提示。

时间线的素材复用检查另行覆盖纯分割和跨成片使用：片段常驻显示「同一素材 ×N」，实际源区间交叠才加「区间重叠」与斜纹。同片内部也检查，不依赖点击或当前选中；「区间重复」页签展示这两类情况，顶部汇总覆盖全批次，包括隐藏行。

## 实现

- `source-conflicts.ts` 从当前 arrangement 的不同素材 ID 识别同源组。
- workspace 与 arrangement 视图派生 `sourceWarnings`；编辑结果也返回同源提醒，不持久化容易过期的警告。
- 成片行和预览区展示中文提示。局部编辑刷新优先用最新 arrangement 提醒，删除或替换后自动清除。
- 分配器规则升级为 `batch-allocation-v4`，主分配和拼接均过滤同源兄弟；同一已知来源视频在本片的已用窗口不能循环补时长。锁定与历史窗口分别处理，撤下的子句释放占用后再拼接。
- `review/video-usage.ts` 统一按素材 ID 聚合使用次数与源区间交叠；时间线从该结果派生常驻徽标、斜纹与筛选，不再在选中片段后逐行重复检查。
- 编辑、审核、导出未增加硬约束，用户现有成片未被自动改写。
