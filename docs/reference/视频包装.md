# 视频包装与贴纸

本文记录四套 HyperFrames 包装、单条与批量包装入口、贴纸编辑和正式渲染的常驻架构。修改共享包装、贴纸、预览或导出前必读。批量跨片事务另见 `docs/reference/批量生产模块.md`；classic/1 固定渲染另见 `docs/reference/固定渲染命令.md`。

## 1. 范围与边界

当前包装模板：

| 模板 | UI 名称 | 贴纸风格 |
| --- | --- | --- |
| `overlay-poster` | A 花字种草 | `comic` 圆润卡通 |
| `overlay-journal` | B 手账拼贴 | `journal` 手帐拼贴 |
| `overlay-minimal` | C 极简高级 | `editorial` 暖调杂志 |
| `overlay-variety` | D 综艺撕纸 | `show` 立体综艺 |

`overlay-basic` 只保留旧任务兼容，不进入新包装选择器。四套当前模板都支持贴纸，且共享同一贴纸运行时。

明确边界：

- 单条精准混剪与批量统一审片都扩展现有 HyperFrames overlay，不另写一套 React 预览动画或 FFmpeg 动画。
- `lib/film-render/` 与 `packaging/templates/classic` 是冻结域；classic/1 不接受贴纸字段，不得把“支持贴纸”误解为所有渲染入口都支持。
- 贴纸只进入正文，片头 20 帧不出现贴纸；包装主副标题与卖点文字始终位于贴纸上层。
- 包装总开关只控制预览和导出，关闭时不删除贴纸数据。

## 3. 包装配置与持久化

`FinalEditPackagingConfig` 保存启用状态、模板、文案覆盖、卖点时序、按模板记忆的文字版式、三槽字体，以及两个独立贴纸字段：

```ts
stickers?: PackagingStickerInstance[];
stickerDefaults?: PackagingStickerDefaults;
```

`parsePackagingConfig` 对旧配置和脏数据做兼容清洗；缺省贴纸为空数组，默认动效为 `follow-template`。写入命令边界必须做严格校验，不能靠清洗时静默丢弃非法实例来完成保存。

贴纸实例包含：功能素材 ID、固定／跟随模板风格、整帧起止、有效图案中心、视觉宽度、旋转、轨道、动效和来源。自动来源另含 `autoGroupId` 与 `autoEdited`。

持久化边界：

- 单条保存在组级包装 JSON，通过组级 revision、串行命令和渲染快照隔离。
- 批量保存在每条成片自己的 `arrangement.packaging`，通过 `outputVersionId + editRevision` 隔离。
- 重新提取卖点、恢复文案或文字版式不得清理贴纸。
- 预览、刷新、撤销后重做和正式导出只能读取已保存实例，不得重新随机。

## 4. 贴纸素材目录

正式素材位于 `packaging/stickers/`，由 `scripts/build-sticker-assets.mjs` 通过显式 `--source` 装配：

- `comic` 28 张、`journal` 29 张、`editorial` 29 张、`show` 29 张，共 115 张。
- `catalog.json` 记录风格、功能 ID、分类、中文名、文件、尺寸、有效 alpha 包围框和 SHA-256。
- WebP 缩略图只服务素材库；预览与正式导出使用原始 PNG。
- 28 个共同功能 ID 可跟随模板切换风格；`special` 跨风格语义不同，必须固定风格。
- 面板默认只加载当前模板缩略图，“全部风格”按需展示，不在列表批量加载原图。

有效图案几何以 `alpha_gt8_bbox` 为准，不以 PNG 透明画布为准。`visualWidthPct` 是有效包围框宽度占比；换风格时重算图片显示尺寸，避免视觉跳变。

## 5. 时间与层级契约

统一使用 24fps 整帧：

- `STICKER_INTRO_FRAMES = 20`，最早开始帧为 20。
- 手动默认时长 48 帧，最短 19 帧；当前位置剩余不足 19 帧时不添加。
- `endFrame` 为开区间，最大为 `20 + bodyFrames`。
- 入出场完整包含在 `[startFrame, endFrame)` 内，不额外拖尾。
- 批量正文秒与含片头时间只在边界换算，批量面板调用贴纸算法前加 `20/24` 秒。

轨道顺序就是贴纸之间的画面层级：越靠上层级越高。固定总层级为：

```text
视频底片／正片字幕 → 贴纸 → 包装主副标题与卖点文字
```

时间轴移动和修剪使用本地草稿，松开后一次提交；换轨只改层级，不改时间。拖动中单击右键取消，磁吸使用现有可见开关。

## 6. 最新编辑交互

单条和批量当前成片共用以下行为：

- 素材按分类和中文关键词筛选，点击素材新增，拖入预览按落点新增；点击另一素材不替换当前贴纸。
- 预览支持拖动位置、等比缩放、旋转和调整框删除；不提供非等比拉伸或镜像。
- 时间轴块显示中文素材名和固定青绿区分色，支持移动、修剪、换轨与 `Delete/Backspace`。
- 预览或时间轴选中后，右栏自动进入贴纸页；点击预览空白取消选中，不额外提供取消按钮。
- 已删除单张复制功能、右栏属性卡和位置数值输入；`Ctrl/Cmd+D` 不复制贴纸。
- 时间轴 `pointerdown` 后必须显式聚焦贴纸块，否则焦点留在预览 iframe，Delete 无法到达父页面快捷键。

动效区按选中状态切换目标：未选中时编辑“新贴纸默认”，选中时只编辑当前贴纸。“应用到全部贴纸”只影响当前成片，是动效区内直接展示的实心主按钮。

## 7. 动效系统

六种实例动效：

| ID | 行为 |
| --- | --- |
| `soft` | 淡入并轻微上浮，柔和淡出 |
| `bounce` | 缩放淡入并回弹，缩小淡出 |
| `rise` | 下方进入，向下淡出 |
| `slide` | 左侧进入，右侧淡出 |
| `zoom` | 放大进入，缩小淡出 |
| `none` | 直接出现与消失 |

`follow-template` 只作为默认／实例设置存在，运行时按模板解析：poster、variety 推荐 `bounce`，journal、minimal 推荐 `soft`。

动画只使用透明度、位移和缩放，由共享 GSAP 时间线执行。短时长会等比压缩入出场，并保留稳定显示帧。动效选择浮窗使用同一张示例图同时循环六卡，不为素材生成 GIF 或视频副本。

保存动效后的播放必须等待新 iframe 文档、当前贴纸动效和 `window.__timelines.overlay` 真正就绪，并用请求序号淘汰旧播放任务，避免播放旧时间线。

## 8. 一键基础布置

正文至少 144 帧（6 秒）才允许自动布置。每次从当前模板风格生成 6 张：

- 开头 2 张，来自 opening，不重复。
- 中段 1 张 explain + 1 张 gesture。
- 结尾 2 张，来自 ending，不重复。
- 箭头和圈注不进入自动池。

三阶段边界使用 `round(i * bodyFrames / 3)`；阶段内中心位于 25%／75%，默认时长为 `min(48, max(19, round(stageFrames * 0.4)))`。位置只取 `PACKAGING_STICKER_AUTO_SLOTS` 的四模板安全槽位。

自动 6 张共享 `autoGroupId`。移动、修剪、换轨、改风格或改动画会标记 `autoEdited`；换一组只替换自动实例，保留手动实例，已编辑时先提示。整个操作作为一次历史记录。

## 9. 跨片随机变体

跨片复制只复制 `stickers` 与 `stickerDefaults`，目标自己的模板、字体、文案、卖点和版式不变。

- 手动与已编辑自动贴纸：保留素材、风格、位置、尺寸、旋转、动效与轨道，起止帧按目标正文时长等比映射；映射后仍须满足 19 帧和正文边界。
- 未编辑自动贴纸：只复制来源仍存在的实例，按目标三阶段重排，不补回已删除实例。
- 自动素材从目标模板同类别池抽取，同阶段不重复，并通过使用计数尽量避开来源和本次其他目标；池耗尽后有限放宽。
- 中心点只在目标模板对应阶段的安全槽位内随机，保留尺寸、旋转和轨道。
- 每张未编辑自动贴纸独立从 `soft/bounce/rise/slide/zoom` 抽取一种可见动效，不抽 `none` 或 `follow-template`。
- 每条目标生成新实例 ID 和新自动组 ID，随机只在复制命令执行时发生。

`lib/media-core/packaging-sticker-variants.ts` 是可注入随机源和 ID 生成器的纯领域模块，目标时长预检与多目标规划均为纯函数；事务与 API 见批量生产参考。

## 10. 预览与正式导出

预览数据流：

```text
包装配置 → 时间线变量 + 贴纸实例 + 默认动效 + 实际 PNG 元数据
→ 四套模板共享宿主/runtime.js → window.__timelines.overlay
```

单条预览入口为 `app/api/final-edit-groups/[id]/packaging-preview/route.ts`；批量入口为 `app/api/batch-production/batches/[id]/outputs/[planId]/packaging-preview/route.ts`。编辑预览还注入文字编辑桥与贴纸编辑桥，父页面按当前成片校验回调。

正式导出：

1. 从任务冻结快照读取包装与贴纸，不读取更新后的工作区配置。
2. `resolvePackagingStickerAssets` 按目标模板解析实际使用的原图与几何信息。
3. `buildTimelineVars` 显式携带 `stickers`、`stickerDefaults`、`stickerAssets`、`stickerTemplate`。
4. `package-video.mjs` 复制共享运行时和快照实际使用的原图，逐个校验相对路径与 SHA-256。
5. HyperFrames 渲染透明 WebM，FFmpeg 叠加到底片；片头封面另按无贴纸时间区间合成。

原图缺失、路径越界、哈希异常或读取失败必须停止相关导出，不静默跳过。已排队任务使用排队时快照，后续编辑不得改变旧任务。

## 12. 修改红线

- 不复制四套贴纸业务逻辑，不在组件内生成正式导出动画。
- 不新增贴纸数据库表；不把贴纸混入 `pointCues`。
- 不让预览、刷新、撤销后重做或渲染重新随机。
- 不把开发机绝对素材路径写入任务或安装负载。
- 不把贴纸放入 classic/1，不修改冻结资产、构建器或校验器。
- 不用 React 状态、文件名或时间戳推断批量贴纸归属；始终使用当前 `planId + outputVersionId`。
