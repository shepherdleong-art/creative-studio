# 一键成片

员工工作台的「一键成片」入口：同一项目从素材走到可下载 MP4，分五个阶段。代码在
`lib/one-click-film/`（领域与存储）、`app/api/one-click-film/`（接口）、
`components/one-click-film/`（工作台界面）、`app/(workspace)/one-click-film/`（页面）。

## 模块边界

- 自带独立迁移流 `ONE_CLICK_FILM_MIGRATIONS`（`schema.ts`），走 `lib/schema-upgrade/` 的共享
  备份／跨进程锁／审计 gate，scope 为 `one-click-film`。**只能追加版本，不改已发布条目。**
- 只从 `media-core/`、`script-providers/`、`video-*`、`final-edit/export-naming` 取共享能力，
  **绝不从 `final-edit/` 的成片状态导入**。
- 迁移未通过时整个模块返回 503（`assertOneClickFilmApiReady`），不写半套数据。

## 身份与版本

- 一个项目一个 run（`one_click_film_runs`），一个 run 下多条目标成片条目
  （`one_click_film_entries`，界面编号 F01…F12）。
- 调整数量只增删尾部条目；调整结构只重写结构变化的条目；其余手稿、配音与确认记录原样保留。
- **重新生成本条**只重写该条，沿用其结构与已选卖点，回到待确认。
- 确认稿会把最终口播写回提示词的声音段，视频模型收到的就是这一步确认的全文。

## 声音

- 默认原生画外音；可选 TTS 统一旁白或不配音。TTS 与不配音时提示词只要求环境声与动作声。
- TTS 音频按「口播文字 + 服务 + 音色 + 语速」签名（`narrationSignature`）。文字或设置变化后
  旧音频仍属于原版本，新稿必须重新生成。**只有播放过当前版本才能确认**；播放只记「已试听」。
- 配音超过正文时长时保留完整尾句并阻止提交，提示改文案、调语速或选更长正文。

## 生成与审片

- 每条确认稿提交一个整片任务（`submitOneClickFilmGeneration`），`requestKey` 由条目 + 确认稿 +
  参数派生，双击或断线重发命中同一任务。
- 服务端按通道声明校验时长／画幅／生成模式（`video-models.ts`），判定与界面一致。
- 下载后在原片上做实际切点识别（`scene-detect.ts`），一镜到底保留一个区间，识别失败仍保留
  整条可播原片并允许手动加切点。切分／合并只改区间，源文件不动；只能合并相邻镜头。

## 包装与导出

- 正文 24 fps 下 360 帧；启用封面在片头加 20 帧，共 380 帧。正文第 0 秒对应成片第 20 帧
  （`filmTimeForBodyTime`），字幕与花字只顺延一次。
- 包装资格：直出审片通过，或样片转高清且复核通过。不配音跳过口播字幕。
- 导出记录绑定当时的脚本修订、包装修订、声音方案与文件摘要；重复提交找回同一记录，
  重新导出形成独立记录，旧文件摘要不变。ZIP 只从登记记录取文件，不扫目录。

## 验证

```powershell
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-domain.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-generation.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-rework.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-delivery.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-acceptance.test.ts
```

`one-click-film-acceptance.test.ts` 是双片贯通验收：同一项目两条片，从建项目到 ZIP 解压，
真实 FFmpeg、真实切点识别、真实导出；识图／脚本／视频／TTS 用固定响应，付费调用 0 次。

## 已知边界

- 首版交付「重新生成片段」与「整条重抽」的记录与采用链路；高清转换目前只产出来源清单与
  登记记录，供应商侧转高清任务复用样片绑定能力，需在具备真实通道的环境验收。
- 包装阶段产出的是包装版本与时间轴契约；真实 HyperFrames 渲染沿用共享管线，未在本模块内重写。
- 批量包装与导出目前按「每条一个文件」交付，不做跨条合并渲染。
