# 一键成片

员工工作台的「一键成片」入口：同一项目从素材走到可下载 MP4，分四个阶段。代码在
`lib/one-click-film/`（领域与存储）、`app/api/one-click-film/`（接口）、
`components/one-click-film/`（工作台界面）、`app/(workspace)/one-click-film/`（页面）。

## 模块边界

- 自带独立迁移流 `ONE_CLICK_FILM_MIGRATIONS`（`schema.ts`），走 `lib/schema-upgrade/` 的共享
  备份／跨进程锁／审计 gate，scope 为 `one-click-film`。**只能追加版本，不改已发布条目。**
- 只从 `media-core/`、`script-providers/`、`video-*`、`final-edit/export-naming` 取共享能力，
  **绝不从 `final-edit/` 的成片状态导入**。
- 迁移未通过时整个模块返回 503（`assertOneClickFilmApiReady`），不写半套数据。

## 身份与版本

- 一个项目一个 run（`one_click_film_runs`），一个 run 下多条目标成片条目
  （`one_click_film_entries`，界面编号 F01…F12）。
- 分析和重新分析都使用当前项目已上传的全部场景图与详情页。451 显示安全的错误说明并保留素材。结果页展示该版本实际使用的图片。
- 缩减数量会将尾部条目移出本轮，恢复数量时沿用原编号与身份。已导出的文件和记录可继续下载。
- 应用结构或已确认卖点的变化时，只为受影响的条目生成新稿。其他条目沿用手稿、配音与确认记录。
- **重新生成本条**只重写该条，沿用其结构与已选卖点，回到待确认；也支持在单条编辑区切换本条出镜人物后重写。
- 出镜人物支持整批设定（自动匹配／无人物／成年女性／成年男性／儿童／亲子互动／自定义）与逐条单独覆盖；分析阶段提取 `suggestedModel` 供自动匹配，同一设定同时写入脚本 LLM 输入与分镜提示词「全局设定」。
- 生成口播时参考同批其他稿件，按各自结构区分开头和叙事重点。检测到近重复时最多重写一次。
- 模型生成的成片标题可在脚本页编辑。旧稿从原始分镜提示词恢复标题，包装的「逐条标题」默认选用该条脚本标题。
- 减少成片数量后，可在「已移出本批」查看尾部原稿。「恢复原稿到本批」按原编号、结构和确认状态加回，无需请求模型。「应用设置并生成脚本」则按所选结构和分析逐条处理。「历史稿件」可查看重写前的原文或载入编辑区。
- 确认稿会把最终口播写回提示词的声音段，视频模型收到的就是这一步确认的全文。

## 声音

- 默认原生画外音；可选 TTS 统一旁白或不配音。TTS 与不配音时提示词只要求环境声与动作声。
- TTS 音频按「口播文字 + 服务 + 音色 + 语速」签名（`narrationSignature`）。文字或设置变化后
  旧音频仍属于原版本，新稿必须重新生成。**只有播放过当前版本才能确认**；播放只记「已试听」。
- 配音超过正文时长时保留完整尾句并阻止提交，提示改文案、调语速或选更长正文。

## 生成与审片

- 每条确认稿通过共享视频队列提交一个整片任务。队列冻结提交参数、样片或直出模式、参考素材和确认稿。
- Seedance 2.5 默认参考图超出尺寸、宽高比或字节限制时，在提交和重试时规整交付副本；原图仍供素材分析使用。
- 局部采用按正文帧区间合成，只替换选中的画面。旁白与现场声从连续音轨读取。转高清按当前剪辑实际采用的样片来源提交，再按原入出点合成。
- 返工可使用项目图片或单独上传的图片、视频参考。提交前校验实际媒体，待核对的任务会显示原因。剪辑历史保存各候选及截取起点，可恢复到仍可用的历史版本。
- 整条重抽先显示原通道、范围、可用费率及声音安排。「修改提示词」从该片的生成快照预填，修改只冻结进本次候选。采用后按重抽片的实际切点审片，已确认的 TTS 旁白继续使用。
- 服务端按通道声明校验时长／画幅／生成模式（`video-models.ts`），判定与界面一致。
- 首次生成、返工和转高清在同一 SQLite 写事务中登记请求和队列任务。素材分析与配音使用独立的请求锁，进程退出后可沿用原操作重试。
- 样片转高清及返工在发送前复核原模型通道的账号指纹。公司代理按当前别名的唯一上游配置核验；缺少绑定证据的旧样片需要重新生成。
- 下载后在原片上做实际切点识别（`scene-detect.ts`），一镜到底保留一个区间，识别失败仍保留
  整条可播原片并允许手动加切点。切分／合并只改区间；相邻镜头的合并按当前成片来源记录撤回快照，刷新后仍可撤回。

## 包装与导出

- 正文 24 fps 下 360 帧；启用封面在片头加 20 帧，共 380 帧。正文第 0 秒对应成片第 20 帧
  （`filmTimeForBodyTime`），字幕与花字只顺延一次。
- 候选按 24 fps 解码统计可用画面帧数，成片渲染和包装输出均检查视频帧数与音轨。升级后旧包装缓存重新渲染，已导出的历史文件继续可下载。
- 旧审片记录若采用了包含音频尾部的容器时长，播放、字幕和包装按原片可验证的画面帧数结束。镜头身份、已采用的候选、原有复核记录与导出文件继续沿用。
- 原片生成后即准备包装草稿，统一审片页共用预览和时间轴；点主画面镜头可切分、合并、返工。正式导出要求直出审片通过，或样片转高清且复核通过。不配音跳过口播字幕。
- 写入草稿的 `coverMedia` 与封面开关分别保存。自动全景在正文或镜头切点变化后重新挑帧。模型权限或额度不足时回退到正文首帧，员工可在策略调整后重新挑选。手动选择的本片帧随新正文校正范围，项目图片与 AI 候选继续沿用。
- 封面预览、成片卡片和正式渲染共用取景裁切。面板可选本片帧、项目图片及已生成的候选图。播放头在封面时段可切换为底图构图。
- GPT Image 2.6 封面从面板手动提交，参考图经 COS 交付。后台按成员额度、模型权限和云端并发领取任务。已受理的任务超时后保留远端标识和费用预留，每 30 秒核对原任务。供应商确认终态后结算并释放并发名额。
- 包装调用共享 HyperFrames 和 FFmpeg。口播字幕优先使用显式配置的 OpenAI 兼容转录，否则用豆包 ASR。豆包优先用 `CREATIVE_STUDIO_VOLC_ASR_API_KEY`，也可复用现有豆包语音 Key；资源默认 `volc.seedasr.auc`，可用 `CREATIVE_STUDIO_VOLC_ASR_RESOURCE_ID` 覆盖。
- 草稿编辑器从上到下显示字幕、花字包装、贴纸、主画面、原声／旁白和配乐。封面在花字包装轨开头，字幕按时间拆成短句，每句单行显示，画面位置与时间轴区间均可拖动调整。
- 审片共用字幕样式编辑器、包装模板和普通项目贴纸库。默认花字取确认稿的卖点短语，主副标题分别进模板槽位，自动贴纸随花字时段出现。
- 口播对时从当前成片实际使用的原声或已确认 TTS 取时间戳。等待识别名额时自动续查。未对时的脚本字幕仅用于编辑，导出用已对时或人工校对保存的字幕。
- 保存草稿只写包装设置。确认渲染并导出后才生成包装 MP4。交付记录冻结确认稿、剪辑、音轨、封面来源、包装修订及文件摘要，ZIP 按已登记的导出记录读取。

```powershell
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-domain.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-generation.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-rework.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-delivery.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-auto-cover.test.ts
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/one-click-film-cover-generation.test.ts
npm run check:main-path
npm run build
node scripts/one-click-film-employee.playwright.test.mjs
```

`one-click-film-employee.playwright.test.mjs` 使用隔离团队服务和普通员工会话。单个本地 HTTP 夹具处理视觉挑帧、
451 回退、GPT Image 2.6、COS 查询与上传。验收实际运行切点检测、FFmpeg 和 HyperFrames，核对封面画面与第 20 帧的
正文起点、音轨、ZIP 校验和及历史交付。三档窗口覆盖浅色和深色。`OCF_ACCEPTANCE_CHROME` 可指定本机 Chrome。
`OCF_ACCEPTANCE_OUTPUT` 保留三份带封面的验收 MP4、ZIP 和 `verification.json`。
