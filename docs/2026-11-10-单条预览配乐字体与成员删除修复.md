## 修复

- 预览接口在媒体繁忙或衍生物尚未完成时返回 202 JSON。浏览器 video 把它当加载错误，原代码没有恢复请求，产生刷新/切菜单才正常的黑屏。成片双槽和素材监看共用恢复 hook：错误后用一字节 Range 探测，202 时按等待时间重试，就绪后重新 load；退出/换素材取消旧请求，等待有界并可手动重试。202 响应禁止缓存。
- 自动选曲在 HTTP 提交主体下冻结可读曲库，后台 prepare 只使用这份快照并核验曲目身份、路径、内容指纹与 ready 状态。保持后台任务的项目权限边界；没有把全局曲库权限授予旧任务，也不覆盖已有手动选曲。
- 字幕与包装共享 `dataRoot()/storage/fonts` 字体目录。字幕目录返回不暴露物理路径的字体文件地址；登录后按不透明目录 ID 读取受控字体。团队客户端只用服务器目录，选中字体按需加载到 FontFace/Canvas，预览与字幕导出使用同一字体；加载失败保留导出生效校验。
- 成员新增 DELETE 与删除按钮。team schema 仅追加 v17 的 `deletedAt`；删除将账号移出成员列表、停用并撤销会话，历史身份、项目、任务与费用保留。拒绝普通员工删除、删除自己和删除最后一位可用管理员；已删除账号不能通过启用/重置接口复活。

## 字体迁移

新代码上线时，把已获准使用的个人字体复制到服务共享目录；不改变服务账号，也不读取其他账号的目录。工具默认只预检，明确加 `--apply` 后才复制，不改原字体文件、不注册 Windows 字体、重复执行按内容复用：

```powershell
$env:CREATIVE_STUDIO_DATA_ROOT='D:\CreativeStudio\data'
node scripts/team-server/import-shared-fonts.mjs --source 'C:\Users\12089\AppData\Local\Microsoft\Windows\Fonts'
node scripts/team-server/import-shared-fonts.mjs --source 'C:\Users\12089\AppData\Local\Microsoft\Windows\Fonts' --apply
```

该目录属于本机运行数据，不随 standalone 或客户端打包。未安装的收藏字体仍需提供对应字体文件，不从不明来源自动下载。
