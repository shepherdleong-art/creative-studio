# 免安装包 0.5.1 — 同事更新指南（可交给 Agent 执行）

日期：2026-08-17
新包位置（共享盘）：`I:\创意工作台-0.5.1-免安装版`

> 本文写给需要升级工作台的同事。可以把整篇丢给 AI Agent（Kimi CLI 等）说「按这篇帮我更新」，步骤是自包含的。

## 0.5.1 更新了什么

- 视频工位新增**首尾帧**：每条运镜可本地上传一张尾帧图，公司可灵 3.0、公司即梦（Seedance 2.0 / 2.0 Fast）、直连 Seedance 2.0 均已实测出片（比例跟随图片、末帧朝尾帧收束）。
- 公司尾帧链路收紧：必须经本机 LiteLLM（`127.0.0.1:4000`）+ 腾讯云 COS 预签名 URL，不满足会在提交前拒绝并给出中文提示。
- 修复视频结果卡徽标拥挤的排版问题。

## 更新步骤

1. **退出旧版应用**（应用菜单退出，或关闭启动窗口）。
2. **复制新包到本机**：把共享盘的 `I:\创意工作台-0.5.1-免安装版` 整个目录复制到你本机磁盘（如 `D:\创意工作台-0.5.1-免安装版`）。不要直接在共享盘上运行。
3. **迁移本机数据**：把**旧版目录**里的以下三项复制进新目录（覆盖同名项）：
   - `data/`（本地数据库：项目、任务、供应商配置）
   - `storage/`（上传素材与生成产物）
   - `.env.local`（如果你自己改过里面的配置；没改过也用旧的一致即可，新包自带的是发布时的副本）
   `config.yaml` **用新包自带的**，不要从旧目录复制（新包带最新模型别名路由）。
4. **供应商配置（0.5.1 起基本零配置）**：新包首次启动会自动带好公司供应商——
   图片「公司网关 image2-medium」、视频「公司可灵 3.0」「公司即梦 Seedance 2.0 Fast」、
   脚本「GPT-5-6-Luna-Standard」，Base URL 均为 `http://127.0.0.1:4000`，密钥由包内
   `config.yaml` 持有，**不用手填**。老库升级时也会自动补种（没配过同模型公司供应商的话）。
   **唯一的例外**：如果你之前手工配过公司供应商且 Base URL 还是旧的网关直连地址
   （含 `linshimuye`），设置页把它改成 `http://127.0.0.1:4000`，一次性。Agent 也可以
   直接改库（应用退出状态下）：
   ```bash
   node -e "const db=require('better-sqlite3')('data/workbench.db');db.prepare(\"UPDATE video_providers SET baseUrl='http://127.0.0.1:4000' WHERE baseUrl LIKE '%linshimuye%'\").run();db.prepare(\"UPDATE providers SET baseUrl='http://127.0.0.1:4000' WHERE baseUrl LIKE '%linshimuye%'\").run();console.log('done')"
   ```
   （在包根目录执行；`node` 可用 `node-runtime\node.exe` 代替。执行前关闭应用。）
5. **启动**：双击新目录的 `start-windows.cmd`。
6. **验证**：随便找个分镜发一条 5 秒视频任务（不带尾帧），能正常出片即升级完成。

## 用尾帧功能的前提

- 上一步的 baseUrl 必须是 `http://127.0.0.1:4000`（启动脚本会自动拉起本机 LiteLLM，需在公司内网）；
- `.env.local` 里有 `CREATIVE_STUDIO_COS_*` 配置（新包自带副本，勿外泄）；
- 目前只开放三个公司模型别名：`kling-3.0`、`doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`，其余模型上传尾帧会提示不支持。

## 排障速查

| 现象 | 原因与处理 |
|---|---|
| 尾帧任务报「必须通过本机 LiteLLM 地址访问」 | 第 4 步 baseUrl 没改，仍是网关直连地址 |
| 尾帧任务报「受控媒体传输尚未就绪 / CREATIVE_STUDIO_COS」 | `.env.local` 缺失或 COS 配置不全，从旧目录复制或找发布人补 |
| 报 `UnknownParameter` 400 | 包不是 0.5.1（旧包带 `aspect_ratio` 探针字段），重新复制新包 |
| 尾帧任务出片 16:9 横屏 | 同上，说明跑的是旧包；0.5.1 可灵尾帧出片比例跟随图片 |
| 启动后公司模型全部不可用 | LiteLLM 没起来：确认在公司内网，关闭应用重开；仍不行看启动窗口日志 |

## 注意

- `data/`、`storage/` 是本机数据，**不要**提交到任何公共仓库或外发；
- `config.yaml` 与 `.env.local` 含公司密钥，包只在共享盘分发，不要外传；
- 旧目录建议保留几天确认无问题后再删。
