# 实拍重组 P2 Windows 验收

执行方案：[P2 执行文档](superpowers/plans/2026-10-19-实拍重组上游返工-P2执行文档.md)。本轮全部使用隔离 SQLite、合成图片/视频/音频；真实队列通过仅监听 `127.0.0.1` 的假供应商验收，没有调用付费供应商。

## 实现

- 第五步稳定定位镜头到第二/第四步，显示原图、当前图、原始提示词/模型与返工历史；显式编辑底图、参考图、提示词，再生成新候选。
- 追加迁移 v14，逐镜头 CAS、不可变请求记录、幂等请求 ID；缺版本/旧版本/请求标识复用均拒绝。轮询不更新未提交表单的写入基线，冲突保留输入。
- 图片完成不更新当前选择；用户明确采用或恢复导入图才生效。Agent 只生成/登记候选，不能直接采用图片或覆盖已接管时间线。
- 视频冻结当前图及实际生成参数；登记时复核归属、成功状态、哈希、时长、审核区间及转场余量，保存新的托管副本。异步探测后再次 CAS，不改旧 spec 或交付文件。
- 新候选复用第五步修订历史和定长替换；脚本、配音、字幕、包装及其他镜头保持原样。旧无版本写入入口、整组换景、旧视频批量入口和删组受保护；普通项目原行为保留。
- 局部队列只领取/恢复指定任务，保留其他待处理镜头；原任务续跑重用原 ID/参数。CLI 新增 `shot` / `rework`，本机实例与数据目录身份校验沿用 P1。
