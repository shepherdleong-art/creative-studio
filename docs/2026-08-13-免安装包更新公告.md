# 创意工作台（免安装包）更新公告 · 2026-08-13

各位，共享盘里的创意工作台免安装包今天有一轮重要更新，修了几个影响使用的问题，请大家按文末指引更新本地包。

## 一、修了什么

1. **双击打不开、提示健康检查 500 / sharp 模块错误** —— 已修复（包里缺了两个组件文件）。
2. **不用再装 Node.js 了** —— 包里已内置运行环境。新电脑现在只需要装 Python 3.12（公司生图/生视频通道需要），装完双击 start-windows.cmd 就能跑。
3. **成片导出失败（Cannot allocate memory）** —— 已修复。之前字幕一多，导出时内存会爆；现在内存占用大幅下降，16GB 的电脑也没问题。
4. **分镜/场景生成"改错图"** —— 已修复。之前在公司网关通道里图1/图2 的角色是反的，模型会把场景参考图当成要编辑的图。修复后：图1 = 要修改的分镜底图，图2 = 场景参考图，和提示词写的一致。**已有项目里存的提示词不用改**，自动生效。
5. **新场景图默认提示词更新** —— 换成床品类专用版本（只影响新建项目；已有项目在工作台里手动改提示词即可）。
