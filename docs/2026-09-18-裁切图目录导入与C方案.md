# 裁切图目录导入与 C 方案

新增“裁切图文件夹”入口，与上传详情页共用来源集、卖点库、模板选择及脚本生成。用户粘贴绝对目录后点击分析，当前目录中的图片按自然文件名顺序复制到项目存储；不修改原目录，不递归读取子目录。新目录替换本次分析的图片列表，新增上传和删除素材会使旧卖点库失去直接复用资格。

当前运行时使用 C 方案（执行器 v24、提取契约 v7）：合适的裁切图直接发送原字节，长图自动切片；单批最多50张、最多2路并发。识图同时产生完整卖点及详解，只有多批结果额外做全局整理。仍保留结构、图片引用和详解事实检查，取消自动逐条二次核验。所有单次识图结果标记为未复核，来源图片按需手动展开。
