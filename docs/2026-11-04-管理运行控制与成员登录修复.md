# 管理运行控制、公共 BGM 与成员登录修复

## 行为

- 管理员的运行总览和「版本与备份」均提供暂停/恢复。暂停持久化，只阻止新的付费阶段；已提交任务继续回收结果，登录、编辑、下载保持可用。独立于部署维护标记，前端恢复不会解除升级或恢复屏障。
- 「公共资源」顶部提供 BGM 多选上传、上传并发布、已上传音乐列表和试听；已有私有音乐可单独发布。单次最多 100 首，每首前端限制 60 MB，逐文件提交以兼容反代限制。上传复用现有音乐导入、资源归属与发布接口。
- 新增成员与重置凭据均立即打开一次性密码对话框：随机 6 位数字、24 小时有效、显示一次，可复制。关闭后不保存明文；成员首次登录直接进入新密码表单，完成改密前不能访问业务接口。
- 已有成员的原密码不能查看。管理员应选择对应成员的「重置一次性密码」，不会删除成员或业务数据。

## 登录错误根因

Next 的服务端页面和 API 路由编译为不同 bundle，但认证服务保存在进程共享状态。先访问服务端页面后，API 捕获的认证错误与本 bundle 的 `TeamAuthError` 构造器不同，`instanceof` 失败，把错误密码等正常 401 错误误报为 500「身份服务暂时不可用」。

使用进程范围 Symbol 品牌稳定错误类型判定。普通未知异常和伪造的普通对象继续返回 500。已用不同模块实例回归测试与冷启动 standalone 的「管理页面先访问 → 错误密码登录」顺序验证。
