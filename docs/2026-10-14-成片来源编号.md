# 成片来源编号

脚本模板、开头提示词和视频包装分别使用 J、K、A/B/C/D 编号。单条混剪和批量导出使用项目既有生产身份基础名，加实际使用组合，例如：

`20261014-X店-型号-AI种草-剪辑师-J1K2A.mp4`

重复组合依次追加 `-02`、`-03`；封面与视频使用同一基础名。关闭包装不加字母，包装失败后发布原片会去掉包装字母。无可核验出处的素材不按名称猜编号。

## 使用

1. 关闭当前旧工作台，重新构建并启动修改后的源码版本。当前运行目录的 Sharp DLL 被占用，不能在线覆盖构建产物。
2. 在「设置 → 脚本知识与模板 → 爆文模板库」重新导入已添加「脚本编号」列的 Excel，确认保存库版本。已检查原文件可导入：380 条，380 个唯一编号，J1 为指定的床模板。
3. 「设置 → 运镜模板」维护开头编号，离开输入框保存。默认 K1 自然生长、K2 手放家居、K3 纸箱爆炸、K4 毛坯房变身；普通运镜留空。
4. 选择带 J 编号的脚本继续生产。既有冻结批次不会被追改编号；需要完整新编号时重新选择脚本创建批次。

旧项目缺少店铺、生产类型或剪辑师时沿用旧基础名；填写完整项目信息后使用新格式。原有导出文件不批量改名。
