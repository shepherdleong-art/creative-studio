# 画布并入主项目：整合与验收

日期：2026-10-06。

## 基线与范围

- 正式版基线：`main` 的 `bdde69b99f4a9eb38e033a0d02842f25e4dd44ee`。
- 画布来源：`codex/infinite-canvas-beta` 的 `372809ab91d33eea803a03c40096a5f932a1f7c6`。
- 整合分支：`codex/canvas-main-integration`，独立工作区；保留两边提交历史。
- 用户授权整合。代码整合、真实数据搬迁、运行实例切换和远端推送分别记录；本轮不发送真实供应商请求。

## 整合结果

画布作为工作台独立模块接入，带独立表、迁移 gate、调度器、API、编辑器和运行日志；旧项目、批量生产、脚本与智能混剪继续保留。功能开关仍默认关闭，关闭时不建画布表、不启动画布 worker。保留 main 本次合入的视频整数秒校验、统一审片修剪、混剪分割和媒体探测修复。

三处文本冲突分别为全局 CSS、即梦适配器和即梦测试。CSS 保留按钮令牌与画布样式；供应商同时保留普通工作流时长校验与画布多模式、自动时长及 Draft/Final 请求合同；测试保留两边用例并补集成边界。

- 即梦三个普通生成入口按精确型号接受 `-1` 自动时长，非法小数、越界与非有限值在网络请求前拒绝，不再静默截断；旧项目 API 仍只接受共享规则内的整数秒。
- Final 继续使用独立白名单，不重新发送提示词、原媒体、普通时长或声音默认值。
- 画布公司适配器解除对 main 已删除导出的依赖；2.5 时长跟随 main 的 4–30 秒，Fast 固定使用共享 720p 像素表。
- 旧 Fast 节点的 `gateway-default` 在读图时转为 720p，仅匹配公司 Fast；其他模型与显式非法档位不被改写。冻结任务保留旧值兼容。
- 公司 2.0 标准版仍未在画布注册；主项目单图分辨率实测不作为画布全部创作模式的真实验证。

## 正式版运行配置

`desktop/main.ts`、macOS 启停脚本及其守护测试保持 main 版本；`package.json` 只增加 `@xyflow/react` 依赖，保留 main 全部 npm 入口。排除 `canvas-profile.sh`、`canvas-dev.sh`、私有隔离测试和 `.trae` 本地文档；历史文档与原画布分支仍保留原始记录。

正式版沿用原桌面名称、`CreativeStudio` 数据目录、源码网页默认 3000／LiteLLM 默认 4000。手动 P7 工具改为正式版默认端口，并允许通过已有环境变量指定目标；本轮没有执行这些真实请求工具。

画布入口启用配置：

```dotenv
CREATIVE_STUDIO_CANVAS_ENABLE=1
CREATIVE_STUDIO_CANVAS_EXECUTOR=company
```

`company` 是现有真实执行器枚举，内部按供应商能力分流到公司或外部适配器；不是强制只能使用公司模型。只配置第一项可打开画布，执行器仍默认 disabled。启用应在确认数据根后重启相应源码实例；本轮未改用户 `.env.local`、未重启现有应用、未安装新桌面包。

## 数据衔接

代码合并不会搬迁 `creative-studio-canvas/data` 或 `storage`。新工作台内画布使用正式版的 `dataRoot()`，旧画布数据继续留在原目录。

若后续需要迁入已有画布，应先对两边做 SQLite Online Backup 并单独备份画布素材；只迁移画布模块表及其引用资产、产物、导出文件，核对相对路径、ID 和供应商绑定。停止或核清在途任务后再切换，禁止把画布整库覆盖到原项目，也不覆盖原项目供应商密钥或把 4100 路由整批复制到 4000。迁移脚本须先在副本验证；本轮未执行真实数据迁移。

### 首轮浏览器诊断

- `canvas --suite all` 的 interaction、editor、execution、recovery 通过；export 完成下载后总错误断言失败，日志为主动切换 fixture 服务期间的 `ERR_CONNECTION_REFUSED`。修正测试 harness：停服前先卸载旧页面，停止其后台轮询；不忽略普通网络错误，随后重跑。
- 脚本模板改写、批量准备区和统一审片短片段浏览器验收通过。
- 混剪全套在封面字体断言失败；从原始 `bdde69b` 导出的干净副本、同一 Node/浏览器依赖、独立临时数据根下复现完全相同的失败。两份实际列表相同，均只缺预期中的 PingFang SC。此项是原 main 既有测试/行为不一致，不报告为通过；原始日志保存在 `mixcut.log` 与 `mixcut-main-baseline.log`。

- 性能观察首轮完成 300 秒、523 轮输入／拖动／缩放，无丢字，最长心跳往返 3ms；后续重载断言仍假定固定 50 节点，与结果自动物化行为不符。改为核对每个已保存节点的 ID 均恢复（初始节点至少 50），并保留结果物化与任务候选验证；重跑完整性能套件。
