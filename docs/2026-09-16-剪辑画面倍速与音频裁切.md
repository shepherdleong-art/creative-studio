# 剪辑画面、倍速与音频裁切

两个入口均支持：单条精准混剪的预览编辑、批量生产的成片编辑。

- 选中视频片段，右栏调整画面缩放（25%–300%）、水平和垂直位移，松手自动保存；重置画面恢复居中原尺寸。
- 选中视频后在右栏使用滑杆或数值输入设置 0.25–4 倍速，松手保存，可一键恢复 1 倍。源素材窗口保持不变，时间线长度按倍速换算（批量保留微秒精度，避免恢复原速时整帧取整误判重叠），后续片段位置保持不变；放慢若占用相邻片段则拒绝并提示。
- 选择分割工具，在口播或背景音乐上点击切开，再右键删除对应音频片段。删除区间静音，其他声音、字幕、视频位置保持不变。
- 时间轴拖动素材中间可移动到空位；拖过其他片段可调整排序，源截取范围不变。拖边缘仍是修剪。右侧倍速和画面面板分别使用独立组件标识，切换素材不会累积面板。
- 删除视频或缩短片段后保留空位，预览和导出显示黑场。批量插入素材优先填空位，不足时才顺延；其他编辑不再隐式压紧时间线。

数据采用已有 JSON 草稿和版本事务，无数据库迁移。旧草稿默认完整音轨和原速；批量既有源/时间线比例仍按原比例播放。画面及音频变化沿用修订号、审核重置和正式产物失效契约。音频纯分割不改变实际声音。

验证覆盖保存与重载、相邻片段保护、倍速后的源区间换算、实际 FFmpeg 画面颜色/黑场及音频静音。批量合成尾部黑场使用明确的固定帧数，避免仅依赖 concat 后的帧率元数据补帧。
