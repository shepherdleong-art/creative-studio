# 04: GPT Image 2.6 按需生成全景封面与候选管理

**What to build:** 为一键成片新增按需触发的「AI 生成全景封面」能力，解决全片皆为特写且项目原图构图不适合竖屏包装封面的救场需求。通过追加数据库迁移建立一键成片封面资产记录与项目受管衍生文件存储，在「更换封面」面板补齐「AI 生成全景」页签；剪辑师可主动勾选当前项目参考图、选择已启用的公司网关 GPT Image 2.6 通道（Flare 或 Sunburst）并选填一句构图偏好发起生成，服务端自动拼装含产品外观与当前包装模板顶部留白约束的提示词、经 COS 媒体传输 Adapter 交付参考图，并纳入团队费用额度、云端并发公平共享池与用量统计；生成的图片以本条目候选画廊持久保存，支持多张对比切换采用、构图拖拽与失败保留原封面。

**Blocked by:** 02: 选用项目图片与画布取景构图

**状态：** `ready-for-agent`

## Acceptance criteria

- [ ] 通过一键成片独立迁移流追加新版本（走共享迁移备份、跨进程锁与审计门禁，不改既有迁移条目），新增封面资产表记录本条目按需生成的封面任务状态、去重键、模型通道、参考图快照、提示词、相对路径、尺寸与错误信息。
- [ ] AI 生成全景封面严格为按需手动触发，绝不随批量成片或草稿准备自动发起付费调用；当公司网关未配置或未启用任何 GPT Image 2.6 通道（Flare / Sunburst）时，界面给出清晰中文原因并禁用生成按钮，不影响本片选帧与项目选图。
- [ ] 在「AI 生成全景」页签支持勾选本项目参考图（默认带入项目场景图并受公司网关参考图上限约束）、切换已启用的 GPT Image 2.6 通道与输入可选构图/场景补充说明；服务端校验全部参考图归属本项目后，结合产品名称、外观与场景线索、成片画幅及当前包装模板标题留白要求拼装提示词（明确保持产品外观一致且不生成装饰文字）。
- [ ] 参考图交付公司网关严格经由既有 COS 媒体传输 Adapter，不暴露本机服务公网地址，签名参数与鉴权信息不写入日志；生成调用接入团队统一执行准入（模型权限、月度费用额度、云端并发公平共享池）、基于请求键的防重复提交锁与用量计费记录；等待并发名额时返回明确等待态提示而非报错。
- [ ] 生成期间不阻塞剪辑师查看其他成片或继续调整字幕与花字；生成成功后将图片落盘于统一数据根下的一键成片封面目录并登记为项目受管衍生文件，写入本条目候选画廊且不强制覆盖未确认草稿。
- [ ] 剪辑师可在候选画廊中对比本条目历史生成的所有就绪候选并一键切换采用（设为 `generated_image`），采用后直接支持 02 的画布拖拽缩放构图、包装取色预览、成片卡片同步与 380 帧导出；生成失败、被策略拦截或超额度时展示清晰中文原因并完整保留当前使用中的封面。
- [ ] 生成封面图的受控读取路由与封面生成动作均强制校验当前用户对所属项目的读写权限与 CSRF，跨项目访问或引用其他项目封面资产一律拒绝。
- [ ] 一键成片包装与交付域测试补齐新迁移安全升级、候选持久化、跨项目封面资产引用拒绝与导出快照冻结校验，全部通过。
