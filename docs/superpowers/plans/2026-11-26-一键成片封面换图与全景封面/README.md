## 跨票约定

- **模块边界**：所有一键成片封面状态、自动挑帧、AI 封面生成与渲染均收口在一键成片独立模块内；封面裁切与取景几何单向复用共享媒体核心的封面合成实现，绝不从单条精准混剪的成片状态模块导入。
- **时间与帧数契约**：正文保持 24 fps 下 360 帧，启用封面在片头增加 20 帧共 380 帧；正文第 0 秒对应成片第 20 帧，字幕、正片花字与贴纸顺延一次的规则不变。关闭封面开关不清空已选封面配置。
- **团队生产边界**：遵循 [轻客户端与服务器统一生产边界](../../../adr/0001-轻客户端与服务器统一生产边界.md) 与 [领域词汇表](../../../../CONTEXT.md)。视觉挑帧与 GPT Image 2.6 生图在统一生产服务执行，受费用额度、云端并发公平共享池、模型权限、项目归属与受管文件权限约束；参考图仅经 COS 媒体传输 Adapter 交付，不暴露本机服务公网地址且签名参数不落日志。
- **统一测试接缝**：不在业务代码中新增测试专用 mock 钩子，外部 AI 依赖统一收敛在供应商 HTTP 边界；数据库迁移、受管文件权限、FFmpeg 抽帧拼接与 HyperFrames 包装合成均执行真实实现。
