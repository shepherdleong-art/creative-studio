# 02: 选用项目图片与画布取景构图

**What to build:** 在「更换封面」面板新增「项目图片」来源页签，让剪辑师可以直接选用当前项目在「素材与脚本」阶段托管的场景图或详情页图片作为封面底图，并复用共享封面合成几何为任意封面来源（本片帧或静态图片）补齐预览画布取景构图能力。剪辑师在封面时段可以在「编辑文字/贴纸」与「调整封面底图」两种交互模式之间明确切换，通过拖拽底图与缩放把产品主体调整到合适区域（避开上方包装标题和贴纸），一键重置构图，并在预览、包装取色、成片卡片与最终 380 帧导出中得到一致的构图裁切结果。

**Blocked by:** 01: 独立封面底图管线与本片选帧

**状态：** `ready-for-agent`

## Acceptance criteria

- [ ] 「更换封面」面板新增「项目图片」页签，展示当前项目已有的托管场景图与详情页图片缩略图列表（含空状态提示），点选即切换当前草稿封面为 `project_image` 来源。
- [ ] 服务端保存草稿、渲染预览与正式导出时，严格校验 `project_image` 所引用的图片归属于当前项目且文件可读；跨项目图片引用或非法标识明确拒绝，不泄露其他项目文件信息。
- [ ] 播放头处于封面时段且启用封面时，画布提供「编辑文字/贴纸」与「调整封面底图」明确模式切换；处于底图调整模式时拖拽指针只移动底图不误触花字或贴纸，切回文字模式时不误移底图。
- [ ] 支持对任意来源的封面底图调整缩放比例与水平/垂直位移，受共享取景几何边界钳位保证不露黑边，并提供一键「重置构图」恢复默认居中填满。
- [ ] 预览画布底图展示、成片卡片封面展示与正式导出渲染完全复用共享封面合成与取景几何单实现；使用高分辨率项目图片时，渲染前按正文分辨率规整裁切，预览列表加载缩略图避免切换卡顿。
- [ ] 切换项目图片或调整构图后，花字包装预览取色随之刷新；正式导出的 MP4 前 20 帧准确呈现裁切后的项目图片及包装叠加层，正文第 20 帧起不受影响且总帧数与音轨校验通过。
- [ ] 一键成片包装与交付域测试补齐 `project_image` 归属隔离校验、越界构图钳位及渲染输入校验，全部通过。
