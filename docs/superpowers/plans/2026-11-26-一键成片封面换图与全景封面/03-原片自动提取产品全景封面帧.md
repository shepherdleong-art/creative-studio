# 03: 原片自动提取产品全景封面帧

**What to build:** 让一键成片在原片切点识别完成并准备包装草稿时，不再无脑以正文第 1 帧作为默认封面，而是自动按镜头避开起止转场边缘采样候选帧，调用已配置的视觉模型结合当前产品名称与外观线索选出产品主体最完整、画面最清晰的全景帧设为默认封面（`auto_frame`）。支持在封面面板手动点击「重新自动挑选」、按当前成片签名幂等去重、视觉异常或 451 内容过滤时静默回退正文第 1 帧且绝不阻塞审片，同时正确处理剪辑师局部返工或整条重抽后的封面联动与失效校正。

**Blocked by:** 01: 独立封面底图管线与本片选帧

**状态：** `ready-for-agent`

## Acceptance criteria

- [ ] 针对当前成片的镜头切分结果，自动在各镜头避开边缘过渡帧的安全位置采样代表帧（镜头过多时均匀抽样并控制候选上限，缩放为轻量预览图），结合项目产品名称与外观线索请求视觉模型返回结构化挑帧结果。
- [ ] 自动挑帧复用既有支持图片识别的脚本视觉通道，接入团队服务端执行准入、请求去重锁与用量统计上下文；同一成片签名下重复打开或同步不会重复发起视觉模型调用。
- [ ] 视觉模型未配置、请求超时、返回非法 JSON、返回越界编号或触发 451 内容过滤时，安全降级回退到正文第 1 帧并标记回退原因，不报错中断草稿创建、打开或导出。
- [ ] 剪辑师在封面面板点击「重新自动挑选」或「恢复默认封面」时可主动触发/恢复自动全景挑帧；若剪辑师已明确手动选择了本片帧、项目图片或 AI 生成封面，后台自动挑帧完成或重同步绝不静默覆盖手动选择。
- [ ] 当剪辑师局部替换镜头采用或整条重抽导致成片签名变化时：`auto_frame` 标记过期并在新成片上重新挑选（未完成前先安全显示新成片首帧）；手动 `video_frame` 若超出新正文时长则自动钳位到有效范围并给出轻提示；`project_image` 与 `generated_image` 原样保留。
- [ ] 一键成片包装与交付域测试补齐自动挑帧结果解析、异常/451 回退、不覆盖手动选择及换源后三种来源的联动/钳位用例，全部通过。
