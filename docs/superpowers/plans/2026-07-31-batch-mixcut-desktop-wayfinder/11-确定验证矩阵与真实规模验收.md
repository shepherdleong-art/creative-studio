## Question

每个阶段分别需要哪些逻辑、数据库、真实 FFmpeg、桌面安装包、跨平台、真实供应商和用户验收证据，并如何在素材与成片数量均由用户决定的前提下证明批量生产真实可用？

## Resolution

- 研究资产：[规模验收官方资料与现有测试审计](./assets/11-规模验收官方资料与现有测试审计.md)。
- 决定资产：[验证矩阵与可变规模真实验收设计](./assets/11-验证矩阵与可变规模真实验收设计.md)。
- 数量边界：素材、脚本和每份生成数量全部由用户决定，计划总数为 `N`；不把固定 60／8／20、固定素材比例或压力测试数字变成产品上限。
- 验证边界：逻辑、数据库、真实媒体、macOS 安装包、Windows 安装包、真实供应商和用户验收七层分别给证据，不得互相替代。
- 性能边界：16GB + SSD 作为大批量标准验收线；默认全速，普通高负载只提醒并由用户选择，磁盘不足或内存危险才触发保护暂停。
- 进度边界：只显示真实数量、阶段或 FFmpeg 媒体时间；校验和发布完成前不得显示 100%。
- 差异边界：按开头、区间、顺序、封面和音乐等事实解释，不设统一相似度及格线，也不阻止用户导出。
- 稳定性边界：macOS Apple Silicon 与 Windows x64 的候选安装包各连续完成三次代表性真实批量运行；真实供应商每次执行前另行说明范围、费用和持久影响并取得明确授权。
- 用户验收：最终由用户用真实项目验证自选数量、进度、性能选择、暂停恢复、部分结果、单条重试／重分配、批量导出以及按需代理／LUT。
