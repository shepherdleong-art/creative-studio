# 批量混剪与桌面化技术路线图

## Notes

- 产品依据：[批量混剪与桌面化 V1 PRD](../../specs/2026-07-31-batch-mixcut-desktop-prd.md)。
- 统一语言：[Creative Studio 素材生产领域](../../../../CONTEXT.md)。
- 本路线图只管理技术调查与决策，不代表功能已经实现。
- 尚未解决的本地票据与本文件放在同一目录；文件名前缀只表示阅读顺序，票据依赖才决定实际先后。
- 用户以非技术视角逐项确认；每次只解决一个票据，并用“改什么、为什么、风险、怎么验收”说明结果。
- 本仓库没有配置项目问题追踪器，因此暂时使用本地 Markdown 票据；未经用户授权不发布 GitHub Issue。
- 现有单条精准混剪必须持续可用，继续遵守 `projectId + shotSetId` 隔离和历史版本快照规则。
- 优先复用现有 React/Next、SQLite、FFmpeg、脚本快照、视频分析、TTS、字幕对齐、渲染和项目产物能力。
- 桌面方向已由产品评审确定为薄 Electron 壳，不复制参考项目的 Python 后端或界面技术栈。
- 桌面安装包仍是最终交付方向，但实现延后到批量核心与供应商运行环境稳定之后；当前浏览器开发形态继续用于分阶段实现和验证。
- 公司供应商只在公司内网可用，必须经过本地 LiteLLM；一键启动统一管理 sidecar，但 sidecar 失败不得阻塞工作台或外部供应商。
- 每个技术阶段都必须分别报告：设计、代码、逻辑／数据库、真实媒体、macOS 安装包、Windows 安装包、真实供应商和用户验收，任何一层不能替代另一层。

## Decisions so far

- [先画出现有工程的安全边界](./01-先画出现有工程的安全边界.md) — 保留成熟媒体内核与单条 interface，新建项目素材库、持久生产调度和独立批量生产 modules；首个批量迁移前必须先备份并验证数据库。
- [定义批量生产的数据模型](./02-定义批量生产的数据模型.md) — 项目来源允许更新，批次输入按版本冻结；生成份数、成片计划、任务尝试和追加式正式产物各自拥有独立身份与历史。
- [确定桌面应用与本地服务的边界](./03-确定桌面应用与本地服务的边界.md) — 采用安全薄 Electron 壳看管现有私有 Node 服务；原生文件能力走白名单桥，关窗后台运行，明确退出才暂停任务并回收进程。
- [设计项目素材库与原文件引用](./04-设计项目素材库与原文件引用.md) — 项目素材用稳定身份连接多个来源；快速指纹只筛选，完整指纹确认同一内容，重新定位、归档与清理均不破坏批次历史或用户原文件。
- [设计可恢复任务调度与自动资源控制](./05-设计可恢复任务调度与自动资源控制.md) — 用一个持久调度 Module 统一各类生产任务；默认全速，普通持续压力提醒用户选择，磁盘不足或内存危险才保护性暂停新的重任务。
- [打通项目脚本同步与批次快照](./06-打通模块4脚本同步与批次快照.md) — 第 3 步项目脚本以稳定身份自动同步；批次开跑前安全跟随或提示冲突，开跑后冻结正文、标题、版本和份数，同时保留单条与第 4 步分镜组隔离。
- [设计集中式代理缓存与 LUT 链路](./07-设计集中式代理缓存与LUT链路.md) — 代理默认关闭、按需批量生成并集中安全清理；LUT 由用户明确选择，预览使用匹配代理，正式导出始终从原片重放已冻结色彩转换。
- [定义联合分配器与差异性规则](./08-定义联合分配器与差异性规则.md) — 全批脚本与素材一次联合分配，先守住语义、时长和用户锁定，再错开区间、顺序、封面和音乐；素材不足继续生产并按维度解释降级。
- [设计批量生产工作区与卡片状态](./09-设计批量生产工作区与卡片状态.md) — 采用成片总览作为一个批次的持久工作区；真实阶段与卡片汇总保持简单，逐条结果可用，重试、重分配和详细编辑不影响其他成片。
- [设计兼容迁移与桌面打包](./10-设计兼容迁移与桌面打包.md) — 新批量结构先做一致备份再追加；薄 Electron 壳沿用既有数据根和私有 Node 媒体内核，待核心稳定后再交付 macOS arm64／Windows x64 手动升级的内部测试包。
- [确定验证矩阵与真实规模验收](./11-确定验证矩阵与真实规模验收.md) — 素材、脚本和成片数量由用户决定；七层证据分别验收，真实进度不造假，默认全速并由用户处理普通压力提醒，两个平台各连续完成三次代表性真实批量运行。

## Fog

- 普通压力提醒窗口、磁盘安全余量和内存危险红线的具体数值，要在实现后用 macOS／Windows 目标真机和多种真实项目校准，不能从单一测试批次直接写死。
- 代理的默认编码规格和磁盘清理建议，要等手机 4K 与相机素材的真实性能样本完成后再确定。
- Cloudflare 替换为腾讯云后的具体媒体上传、临时授权、有效期与清理方式，要等公司侧约束确认后再锁定；在此之前不能把当前全端口隧道包装成正式方案。
