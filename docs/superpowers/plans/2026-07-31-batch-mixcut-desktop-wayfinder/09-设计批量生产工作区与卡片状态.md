## Question

五阶段批量工作区如何映射到持久化状态，成片卡片如何展示、筛选、播放、重试、重分配和进入详细编辑器，同时让主界面保持简单？

## Resolution

- 决定资产：[批量生产工作区与成片卡片状态设计](./assets/09-批量生产工作区与成片卡片状态设计.md)。
- 主界面：采用用户确认的方案 B「成片总览」；同一个持久工作区覆盖准备中、生产中、暂停、部分完成和待检查，刷新或重启后恢复数据库真实状态。
- 信息层级：顶部批次摘要、四项关键数量、横向五阶段轨道和当前内容构成固定四层；主界面只放当前阶段、真实进度、状态数量和下一步，性能、空间、重试与差异诊断进入任务详情。
- 准备与开跑：素材、自动同步文案和整批默认值并列设置；代理与 LUT 默认关闭；点击一次开始后后台自检并自动继续，不增加确认向导。
- 卡片身份：一张卡片永久对应一条成片计划；重试只增加任务尝试，单条重分配或详细编辑只增加目标成片版本，均不增加卡片或改动其他成片。
- 卡片状态：由可用正式产物、当前版本、生产任务、阻塞和提醒共同汇总，不直接等于最后一个任务状态；旧版可用而新版失败时仍保留播放和导出入口。
- 逐条可用：成片通过发布校验后立即可以播放、筛选和选择导出，不必等待整批结束；部分成功是稳定结果，不回滚成功项。
- 深度处理：原型 C 不作为常驻页面，其单条检查能力收进卡片侧边详情；用户明确点击后才能重试这一条、重新分配这一条或进入现有详细编辑器。
- 原型结论：用户依次确认方案 B 的准备、生产和待检查状态都清楚好用；抛弃式网页原型已删除，只保留决定资产。
