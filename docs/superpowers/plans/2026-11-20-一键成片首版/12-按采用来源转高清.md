# 12 · 按采用来源转高清

**状态：** `ready-for-agent`

**Blocked by:** [06 三种模型、参数核对与样片](06-三种模型、参数核对与样片.md)、[10 等时长采用与版本恢复](10-等时长采用与版本恢复.md)

已通过的样片可点「一键高清」。剪辑师先查看当前版本实际采用的原片与补片，再确认转换，并按原有剪辑复核高清成片。

## 验收标准

- [ ] 从已通过的样片版本列出实际引用的来源、绑定的账号与通道、可用性、可复用的高清结果和预计费用。同一来源用于多个区间只列作一次转换，未采用的候选不提交。
- [ ] 按各来源原始样片标识分别提交转高清。验证 F02 的剪辑使用原片 A、采用补片 B、未采用候选 C 时，只需 A、B 两份可用高清结果。费用依据所需来源的转换范围。
- [ ] 若样片过期、不可访问或绑定不符，具体标出对应来源及受影响条目。失败可针对该来源重试，先前成功且适用的高清结果可复用。任务返回时按发起时的剪辑版本归档。
- [ ] 按已确认的来源入出点重组高清正文。补片占满原选区，前后位置和连续声音正确，正文时长可核对。剪辑师复核两个接缝及音轨并确认高清通过后，当前版本取得包装资格。
- [ ] 直接生成的成片经审片通过即可进入包装。在直出样本上检查高清请求数为零。

## 实现与验证

用户已实测 Seedance 2.5 样片转高清的一致性。此票用固定高清响应检验样片绑定、请求次数、采用区间和可播放输出。对同一来源保留供应商身份及其绑定，复用已有样片转正式版能力。[样片绑定测试](../../../../scripts/creative-canvas-draft-binding.test.ts) · [样片转正式版测试](../../../../scripts/creative-canvas-draft-final.test.ts)

使 A 两次出现在时间轴、B 只出现一次，并让 B 第一次转换失败。核对各次请求的来源、已成功结果的复用和最终高清文件中 B 的画面。
