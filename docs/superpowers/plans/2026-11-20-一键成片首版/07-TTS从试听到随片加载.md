# 07 · TTS 从试听到随片加载

**状态：** `ready-for-agent`

**Blocked by:** [05 确认稿直出原片](05-确认稿直出原片.md)

剪辑师在脚本页选 TTS 服务、音色和语速，逐条试听并确认。生成页随对应原片加载这条连续旁白，能回到同一条脚本调整声音。

## 验收标准

- [ ] 支持为一条或整批生成 TTS，显示每条的音频、实测时长及试听、确认状态。只有播放过当前版本的配音才能确认它，采用 TTS 的稿件需有有效配音才能用于整批视频生成。
- [ ] 两条均试听确认后，只重做 F02 或只改其口播，F02 需要重新生成、试听和确认。比较 F01 音频文件、设置和确认版本，仍能播放先前确认的录音。只改镜头文字时可沿用同一条适用音频。
- [ ] 切换整批配音方式、服务、音色或语速，准确列出受影响条目。迟到的旧音频结果仍属于原版本，新稿不能误用旧配音。
- [ ] 用实测超过 15 秒且有完整尾句的音频配 15 秒正文。界面明确提示修改文案、语速或选更长的支持时长，服务端阻止不匹配的提交。修正后可听完整尾句。
- [ ] TTS 模式的视频请求只要求环境声和动作声，媒体参考中没有旁白录音。生成结果随片加载已确认的 TTS 作为独立连续旁白，校对可听的旁白及音频身份。生成页「调整声音」回到本条脚本。

## 实现与验证

沿用共享 TTS 适配器和实测音频时长。把配音与本条口播、服务、音色、语速及确认状态关联，再把确认的音频交给生成预览和后续步骤。[TTS 适配器入口](../../../../lib/media-core/adapters/tts-registry.ts) · [既有配音测试](../../../../scripts/final-edit-tts.test.ts)

用可区分的两段本地语音和一段超时长录音走正式试听及提交。可在 05 的直出页验证播放与返回脚本，08 会复用同一条声音。
