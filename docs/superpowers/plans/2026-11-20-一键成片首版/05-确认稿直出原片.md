# 05 · 确认稿直出原片

**状态：** `ready-for-agent`

**Blocked by:** [04 编辑、确认与单条重做](04-编辑、确认与单条重做.md)

剪辑师把全批已确认的脚本送入第三步，先在一种已接入的直出通道上生成每条完整正文，在创作队列中播放自己的原片和连续声音。

## 验收标准

- [ ] 进入第三步时能逐条核对成片编号、确认稿全文和脚本阶段选定的声音。服务端拒绝缺少当前确认稿的整批提交，并指出待处理条目。
- [ ] 在支持的画幅下直出 F01、F02 的 15 秒正文。每条各提交一个整片生成任务，供应商收到各自最后确认的全文、参考和参数。冻结脚本和分析版本、模型、通道及账号身份，之后改稿仍可查到原任务的真实输入。
- [ ] 默认原生画外音时提交已确认的旁白文字，要求人物自然使用产品、保留合适的现场声。不配音时仅要求环境声和动作声。两种正文都从第 0 秒开始，封面、烧录字幕、花字和 BGM 到包装阶段才加入。
- [ ] 队列按条目显示进度和生成结果。真实下载的整条原片与音轨可从生成页播放，记录可供切点识别的来源身份、实际媒体时长和帧率。
- [ ] 对同次提交双击或断线重发只对应原任务。在一次 F01 成功、F02 失败的回放中，可读取 F02 的失败原因并只重试 F02，恢复后仍只有两个目标条目。

## 实现与验证

用现有视频适配器、队列和团队任务登记打通首条直出通道，服务端处理凭据、用量和结果下载。06 扩充可选模型及参数核对，08 消费这里保存的完整媒体。[供应商与队列](../../../reference/供应商与队列.md) · [团队生产边界](../../../adr/0001-轻客户端与服务器统一生产边界.md)

用录下请求正文的测试供应商返回两份可区分的本地视频，通过正式提交和下载路径断言传入的手改句、任务归属与实际文件。隔离方法可参考[主流程检查](../../../reference/主流程检查.md)。
