# 02 · 分析并核对卖点

**状态：** `ready-for-agent`

**Blocked by:** [01 建项目并录入素材](01-建项目并录入素材.md)

剪辑师在上传页发起分析，在「分析内容」逐项核对产品名称、外观、使用场景和卖点。确认后，脚本页能取到这次选用的卖点及其来源。

## 验收标准

- [ ] 从「分析 N 份素材」发起任务，呈现进行中、成功或具体失败原因。重试同一次请求可找到原任务，回到已有结果可以直接查看。
- [ ] 每条候选卖点能定位到本项目的来源图片，有详情页分片证据时可核对相应位置。仅给一张场景图时也能分析，可见的外观或使用动作可入稿，具体功能主张需要对应的证据。
- [ ] 产品名称可编辑，卖点可改写、选入或排除。产品名有效且至少勾选一项有内容、有来源的卖点，才能「确认内容，去生成脚本」。确认结果包含选用文字和来源。
- [ ] 在上传、分析及脚本入口间往返可继续本次编辑。换图后需重新分析。修改产品名称或选用的卖点会产生新的分析版本，已有稿件可据此提示复核。历史版本仍能追溯原依据。

## 实现与验证

可复用现有详情页分析的来源集和卖点证据配对，保留剪辑师修改后的文字以及对应图片身份。01 的项目上下文贯穿查询、确认和重试。[卖点规范化](../../../../lib/script-studio/selling-point-normalize.ts) · [详情页智能脚本生成](../../../reference/详情页智能脚本生成.md)

用内容不同的场景图和详情页作样本，在正式页面确认其中一项、排除一项。检查交给脚本页的选项，再换图重试，核对两个版本各自引用的原图。
