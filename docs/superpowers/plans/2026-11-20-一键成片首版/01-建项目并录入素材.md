# 01 · 建项目并录入素材

**状态：** `ready-for-agent`

**Blocked by:** 无，可立即开始。

剪辑师从员工工作台点「一键成片」，用店铺、型号、类型和剪辑师创建项目，随后在同一项目的「上传素材」页整理场景图和详情页。下次打开该项目还能看到已收录的图片。

## 验收标准

- [ ] 创建页只收四项项目信息，显示按现有工作台命名规则计算的预览。点「创建并准备素材」后可核对保存的项目名，同名项目沿用工作台现有的序号规则。
- [ ] 第二步能辨认「上传素材」「分析内容」「生成脚本」三个子页。先在上传页分别添加、预览和移除场景图、详情页，重新打开项目后核对分区、数量与图片。
- [ ] 零份素材时提示先上传。有任意一份时显示可点击的「分析 1 份素材」，点击进入本项目的分析页并带入素材。实际识别由 02 接续。
- [ ] 服务端按已登录员工核验项目和素材。用两名员工验证，本人能重新打开图片，另一名无权员工持有同一个项目或文件标识时请求被拒绝。

## 实现与验证

从已有首页入口接入。表单和服务端共用项目命名规则，图片走现有项目上传与文件归属能力。项目身份由服务端保存，表单中的剪辑师姓名用于生产命名。[工作台入口](../../../../lib/workspace-navigation.ts) · [项目命名](../../../../lib/project-production-identity.ts) · [团队生产边界](../../../adr/0001-轻客户端与服务器统一生产边界.md)

在隔离数据根通过员工页面创建项目，上传两张名称可区分的图片，移除一张并刷新。再用只含一张场景图的项目走到分析页。
