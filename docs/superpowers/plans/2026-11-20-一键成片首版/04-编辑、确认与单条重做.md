# 04 · 编辑、确认与单条重做

**状态：** `ready-for-agent`

**Blocked by:** [03 按数量和结构生成脚本](03-按数量和结构生成脚本.md)

剪辑师能手改一条稿、保存后再确认，也能只重做另一条。视频生成拿到的是每条最后确认的全文和版本。

## 验收标准

- [ ] 在列表中切换 F01/F02 可见各自的大纲、口播、确认状态及整批进度。能编辑大纲和口播，展开、编辑并复制带时间码的分镜全文。取消编辑恢复打开时的内容，保存草稿后可接着改，确认后生成可提交的版本。
- [ ] 确认时固定本条的大纲、口播、提示词全文、声音方案和所依赖的卖点版本。改动后可先保存草稿。有待确认项时整批生成入口提示具体条目，确认齐全后可以继续。
- [ ] 手改并确认 F01 的三项内容，在 F02 卡内点「重新生成本条」。只有 F02 发出重写请求，其新大纲、口播、分镜可与旧稿区分，沿用其结构和选定卖点，回到待确认。
- [ ] 逐项比对重做前后的 F01 条目标识、手改全文、确认记录及已关联的配音版本，结果相同。若 F02 选用 TTS，重写后要为新口播重新准备配音。实际试听由 07 验证。
- [ ] 「重新生成全部」在整批设置区单独发起。重试同一次重写能找回同一版本。F02 失败时可单独重试，F01 已确认稿可继续查看。

## 实现与验证

确认稿要能固定给下游任务，草稿和待确认状态要能在项目重新打开后恢复。用返回不同文本的两次脚本响应检查作用范围，并保留一段容易逐字比对的 F01 手改文字。[项目脚本词汇](../../../../CONTEXT.md)

验收以脚本页真实操作和持久化结果为准。可先用已有音频引用覆盖 F01 的关联验证，07 再走真实试听和确认链路。
