## 跨票交接

- **项目、条目和版本。** 一个目标成片从脚本到交付沿用同一身份。F01、F02 是剪辑师看到的编号。重写、重试、候选与交付版本归在原条目下。服务端核验员工、项目、条目、素材及文件的归属，使用凭据、核算用量并登记产物。客户端负责上传、预览和下载。[团队生产边界](../../../adr/0001-轻客户端与服务器统一生产边界.md) · [领域词汇](../../../../CONTEXT.md)
- **声音与确认稿。** 默认原生画外音。选择 TTS 时，在脚本页生成、试听并确认配音，系统读取音频实际时长。选择不配音时保留现场声。视频任务固定自己的提示词全文、参考和参数。修改上游内容时，按 PRD「返回修改时的影响范围」核对受影响条目及其下游版本。[首版 PRD](../../specs/2026-11-19-一键成片-PRD.md)
- **镜头与高清。** 正文先整条生成，再识别实际切点。A 布局提供「重新生成片段」和「整条重抽」。局部采用只换等长画面，连续声音贯穿正文。剪辑师已实测 Seedance 2.5 样片转高清的一致性，12 验证采用来源、入出点和可播放的合成结果。[A 布局](../../specs/2026-11-19-一键成片-原型/07-review-a.png) · [一键高清](../../specs/2026-11-19-一键成片-原型/08-hd-sources.png)
- **时间基准。** 默认生成 15 秒纯正文。镜头和旁白都以正文第 0 秒为起点。24 fps 交付时正文为 360 帧，启用包装封面只在片头加 20 帧，共 380 帧，约 15.83 秒。字幕和花字随正文一起顺延。[媒体帧数契约](../../../../lib/media-core/render-contract.ts) · [视频包装](../../../reference/视频包装.md)
- **原型与验收素材。** PRD 的「逐页看原型」给出交互入口，原型版本为 `codex/prototype-one-click-film-20261115` 上的 `e47f0974`。演示以两条、结构自动搭配、3:4 画幅起步，这三项均可调。截图里 F02 选区约 4.4 秒。正式贯通测试使用 6–9 秒的 3 秒选区，走实际预览、包装、下载和解压。[原型评审](../2026-11-15-一键成片原型/01-可点原型评审.md) · [双片贯通验收](16-双片贯通验收.md)
