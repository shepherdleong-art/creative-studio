# 03 · 按数量和结构生成脚本

**状态：** `ready-for-agent`

**Blocked by:** [02 分析并核对卖点](02-分析并核对卖点.md)

剪辑师在「生成脚本」决定做几条、每条怎么讲、用哪种声音，一次得到可逐条查看的大纲、适用的口播和带时间码的视频提示词。

## 验收标准

- [ ] 接受 1–12 条目标成片，前后端都校验边界。分别生成 1 条和 12 条，数量与可见编号一致。提交 0 条或 13 条时能看到超出范围的原因。
- [ ] 能自动搭配、整批指定一种结构，或逐条指定并让其余条目自动搭配。原型中包含「场景体验」「结果先行」「痛点解决」。指定 F01 场景体验、F02 痛点解决后，在列表和正文里都能核对这两种讲法。
- [ ] 每条使用已确认产品和卖点，输出大纲、适用的口播和完整分镜提示词。时间码覆盖目标正文，提示词写明产品与场景约束、景别、运镜、人物使用动作及声音安排。
- [ ] 默认原生画外音，人物自然体验产品，旁白在画外讲述。另可选 TTS 统一旁白或不配音，这两种的模型提示词只要求环境声和动作声。稿件保留自己的声音方案，供 07 生成和确认 TTS。
- [ ] 每个目标条目有稳定身份。应用数量或结构变化时，只增减相应条目或更新结构有变化的稿件，仍适用的条目沿用自己的版本。整批设置与单条内容分别展示。

## 实现与验证

从 02 的已确认分析产生条目，按目标数量组织项目脚本。一键成片在本模块编排 1–12 条。现有详情页脚本的公开入口继续使用其单批 6 份限制。[脚本生成数量契约](../../../../lib/script-studio/generation-contract.ts) · [详情页智能脚本生成](../../../reference/详情页智能脚本生成.md)

用可重复的生成响应检查两条不同结构的稿，给 F03 留自动结构，再减少数量并核对保留条目的身份。办公椅样例中的至少六镜、禁 POV 等要求只用于该样例。
