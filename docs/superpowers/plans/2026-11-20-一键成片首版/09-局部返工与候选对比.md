# 09 · 局部返工与候选对比

**状态：** `ready-for-agent`

**Blocked by:** [08 A 布局审片与切点修整](08-A布局审片与切点修整.md)

剪辑师在 A 布局选中一个完整镜头，填写修改要求、添加参考并生成候选。等候、比较和调整截取起点时，仍能播放当前成片。

## 验收标准

- [ ] 返工面板显示所属成片和要替换的起止位置。能为图片或视频标注「产品外观」「人物形象」「动作」「运镜」「场景」等用途，提交后可核对要求、素材身份和用途。
- [ ] 生成沿用原片的模型、通道和账号。服务端校验项目归属、参考格式和通道能力，账号或参考不可用时指出具体原因。带人脸的原件、剪段和抽帧分别按通道已验证的来源规则处理。
- [ ] 明确区分待换镜头、实际送模型的参考或生成范围，以及候选计划采用的区间。选中 6–9 秒而通道最少需要 4 秒时，可生成足够时长的补片，并按实际生成范围展示预估。
- [ ] 候选按镜头收录，可并排播放当前版本与候选、移动候选截取起点、循环试听前后接缝。预览模拟候选画面配当前连续声音。5 秒候选能预选其中 3 秒，两端都能核对。
- [ ] 候选过短时能看到缺少的时长，可重做，不能采用。候选提交、下载失败或重试只影响当前候选。比较、切换候选或退出后，当前采用版本仍可播放。

## 实现与验证

从 08 的实际镜头区间进入现有视频参考交付能力。把来源身份和返工参数固定给任务，记录结果实际时长，短于模型下限的镜头通过多生成再截取处理。[公司网关与 COS 中转](../../../reference/公司网关与COS中转.md) · [视频参考任务测试](../../../../scripts/video-reference-job-create.test.ts)

给 F02 的 3 秒选区准备一份 5 秒和一份 2 秒的返回样本。验证候选比较、接缝循环、越界入点和短候选提示。最终写入剪辑版本由 10 验收。
