# 16 · 双片贯通验收

**状态：** `ready-for-agent`

**Blocked by:** [11 整条重抽](11-整条重抽.md)、[14 包装后继续编辑与返工](14-包装后继续编辑与返工.md)、[15 导出与交付总览](15-导出与交付总览.md)

从员工工作台走完剪辑师确认的五步，在同一个产品项目里交付两条片。验收依据是实际送出的提示词、能看到和听到的结果、以及从总览下载的文件。

## 验收标准

- [ ] 创建店铺、型号、类型、剪辑师齐备的项目，上传场景图和详情页，核对卖点及其来源。到脚本页选两条，F01「场景体验」、F02「痛点解决」，初选声音为原生画外音。
- [ ] 手改并确认 F01 的大纲、口播和一处分镜，保存可逐字比对的两条原稿。只重做 F02，确认 F02 的三项内容都得到新稿，结构和卖点相同，状态回到待确认。检查 F01 手改全文和确认记录，再确认 F02。
- [ ] 用 Seedance 2.5、支持的画幅、15 秒正文、样片模式生成两条。断言两次供应商请求分别收到各自最终确认的提示词，播放无封面及包装的原片，并定位测试媒体实际的 6 秒、9 秒切点。
- [ ] 在 A 布局选 F02 的 6–9 秒，填写要求并加参考，对比有独特测试音的候选，采用、撤销、恢复。比对选区内外的画面，跨两处接缝试听并检验音频，只有该 3 秒画面更换，听不到候选音，F01 仍为原版本。
- [ ] 两条样片通过审片并按各自实际采用来源转高清，F02 高清结果可见采用的补片。高清复核通过后一键包装两条、加封面，在 F02 的「继续编辑」移动花字起点并保存。预览核对新花字和正文第 0 帧所对应的交付第 20 帧。
- [ ] 全选并导出，从已导出总览播放两条、下载 ZIP 并解压。探测两份真实 MP4 各为 24 fps、380 帧，核对完整旁白、启用字幕与画面。再改 F02 包装、单独导出，验证新旧版本可分别播放，旧文件摘要与第一次一致。

## 实现与验证

提供可重复运行的新入口验收（含具体命令），使用隔离数据根与员工会话。远端提供固定的识图、脚本、视频和 TTS 响应。页面、任务、实际切点识别、FFmpeg／HyperFrames、产物登记和下载走正式路径。保留足以定位到 F01/F02、切点、音频差异或导出版本的断言。[主流程检查](../../../reference/主流程检查.md) · [隔离与真实媒体先例](../../../../scripts/main-path.test.ts)

主流程之外，运行各票已覆盖的 TTS／不配音、参数冲突、切点失败、短候选、整条重抽、直出、单条失败重试及归属检查。记录本次新入口验收和原工作台 `npm run check:main-path` 的结果。三档尺寸与浅深主题从实际审片、保存和导出按钮检查可达性。[界面尺寸验收](../../../reference/界面尺寸验收.md)
