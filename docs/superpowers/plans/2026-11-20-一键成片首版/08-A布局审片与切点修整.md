# 08 · A 布局审片与切点修整

**状态：** `ready-for-agent`

**Blocked by:** [05 确认稿直出原片](05-确认稿直出原片.md)

原片下载后，剪辑师能按实际画面切点审片。在 A 三栏的同一屏里切换成片、定位镜头、修整区间并标记当前版本通过。

## 验收标准

- [ ] 对已下载的视频运行实际切点识别，队列显示识别状态。从生成页点某条的镜头，进入 A 布局后定位到该片该镜。15 秒测试原片在 6 秒和 9 秒有实际切点，即使脚本计划的分镜边界不同也按原片定位。
- [ ] 左栏显示成片列表及各自审片状态，中栏显示当前版本、整条或选中镜头预览、时间轴和切点，右栏随选区显示返工对象。切换 F01/F02 后，播放、选区和操作对象一致。
- [ ] 一镜到底时保留一个完整区间。识别失败时提示原因、保留可播的整条原片。两种情况下都可手动加切点，合并相邻同源镜头。跨来源或非相邻镜头不可合并。
- [ ] 手动切分或合并只更新镜头区间。重新打开后比对来源文件、正文长度和连续声音，再播放切点两侧。直接生成可标记审片通过并取得包装资格，样片通过后进入待转高清状态。
- [ ] 审片页能从「调整声音」回到当前条脚本。在三档桌面尺寸及浅深主题下，能切换成片、选镜和标记通过。候选提交与采用分别在 09、10 实现。

## 实现与验证

从共享媒体能力取场景检测结果，按来源帧记录区间。用含实际切点的原片、一镜到底原片和可控的识别失败验证三种状态。样片标记和多来源剪辑可用固定的审片输入验证。[切点识别](../../../../lib/media-core/scene-detect.ts) · [既有切点测试](../../../../scripts/final-edit-scene-detect.test.ts) · [界面尺寸验收](../../../reference/界面尺寸验收.md)

原型图的第二镜约 4.4 秒，用来对照布局和操作。五步验收使用 6–9 秒的完整镜头。两者的区间都从正文第 0 秒计算。
