## 实施步骤

1. 先复现顺序和并发重放；记录初始化、管理员重置、过期凭据及恢复 CLI 的现有行为。
2. 在登录 KDF 后重新检查凭据版本/状态；用条件更新和建 session 的同一事务实现一次性消费。需要新字段时仅追加迁移，兼容既有账号和普通密码登录。
3. 明确消费后丢响应、退出改密页、过期与重置的恢复路径；保留原会话改密能力，重置撤销旧会话，不泄露凭据。
4. 检查改密与重置/停用并发，避免凭据已变化后旧校验覆盖新状态；更新中文错误引导。

## 完成标准

- [ ] 同一凭据顺序第二次登录失败；并发两个请求恰好一次成功，建 session 故障回滚不会留下孤立消费。
- [ ] 消费成功的会话可改密；改密后只有保留会话有效，旧凭据及其他会话失效。
- [ ] KDF 期间发生重置/停用，旧登录不能成功；普通密码仍允许按既定规则多设备登录。
- [ ] 丢响应或退出后只能通过受控重置恢复；员工不能自行重新启用旧凭据。
