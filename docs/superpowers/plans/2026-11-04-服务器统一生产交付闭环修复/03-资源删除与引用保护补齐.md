4. 确保文件/DB 部分失败可恢复重试，删除父项对子项和恢复的语义明确；本地路径保留原合同。
5. 给 07 提供回收站列表、恢复、清理预检与拒绝原因合同。清单有遗漏或临时禁止的必需资源仍算未完成。

## 完成标准

- [ ] server 删除持久资源后回收站可见且可恢复，正常列表隐藏，新任务无法用已删 ID；local 同场景仍符合原行为。
- [ ] 已受理任务继续读取原依赖并收回结果，删除不取消任务，已删项目不自动下载。
- [ ] 任务/历史/备份/shared file 任一引用存在时无法 unlink；无引用的管理员清理可完成且重复调用幂等。
- [ ] 取消未完成上传、撤销会话和取消任务未被误改成回收站资源；非管理员不能永久清理。
- [ ] 按实际清单逐项提供覆盖，新增未分类删除入口使覆盖检查失败。
