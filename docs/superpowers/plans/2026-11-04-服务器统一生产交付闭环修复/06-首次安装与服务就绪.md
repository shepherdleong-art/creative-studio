3. 验证配置 releaseId 与 manifest 对应，生成准确 SERVER_RELEASE_ID，并接入 04 的模块配置；保持环境/身份数据位于受控路径。
4. 安装经过数据根身份判定后创建日志/状态目录，验证服务账号对程序、证书私钥和数据的最小权限；支持安全重入与半途失败诊断。
5. 启动后有界等待 ready，超时返回非成功；交付状态与错误合同给 08/09/11，不把 init-admin 成功或 SCM Running 作为业务 ready。
