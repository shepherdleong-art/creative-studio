# 03: 单条贴纸添加保存与正式导出

**What to build:** 用户在单条精准混剪点击素材新增贴纸，刷新仍保留；预览和正式导出读取同一份保存结果。关闭包装可隐藏、重开可恢复，切换模板可按固定／跟随规则换风格。

**Blocked by:** 02 · 内置贴纸库浏览与授权。

**状态：** `ready-for-agent`

**发布状态：** 用户已确认拆分，已发布为正式实施票；功能尚未开始。  
**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D01、D02、D03、D04、D06、D08、D09；故事 1、6、19、22–25、38–45、48、50；T01 风格解析、T03、T08 单条保存、T09 写入授权、T10 单条基础导出、T11。

## 修改范围

- 引入共享贴纸实例与默认动效类型、读取兼容、原始请求严格校验和实际素材解析；扩展现有包装 JSON，不增加 schema。
- 接入素材库的点击新增、默认视觉大小及合法正文时间计算，复用组级命令和既有串行保存。保留完整模型字段，默认动效遵守规格；动效选择控件由 06 提供。
- 核对所有已开始识别贴纸字段的写入边界，包括现有批量包装／封面请求。共享解析器一旦接受新字段，就要先验证原始输入，不能等批量 UI 上线再补校验。
- 贯通单条和共享预览变量、四模板贴纸层、共用运行时、排队快照、worker 透传与原图校验复制；为后续批量 UI 提供可复用的共享预览／渲染能力。
- 仅增量扩展当前产物发布流程，保留受管登记、封面独立版本、失败回滚、媒体工具显式路径和透明文档配色。保留卖点重提取与布局恢复时的贴纸字段。
- 代码导航：父票「共享模型及算法」「单条保存与历史」「单条界面」「共享预览与模板」「导出快照与正式发布」「批量保存及整包兼容」。

## 不包含

不新增空间手势、轨道编辑、动效选择、一键布置或跨片复制。不将组级配置拆成逐成片草稿存储，不接实拍或 classic/1 新功能。

## Acceptance criteria

- [ ] 从真实素材库连续点击新增，得到不同稳定实例 ID；有效图案中心默认落在预览中央，连续添加轻微错位；默认有效图案宽度为画面 30%，新增不替换已选实例。
- [ ] 统一使用 24fps 整帧；从合法正文播放头开始，默认 48 帧，末尾按剩余帧缩短；不足 19 帧拒绝，19 帧允许。片头 20 帧不出现贴纸，终点使用开区间。
- [ ] 普通保存、已有整包写入及默认动效字段均先检查原始输入；非法项、重复 ID、越界和第 129 个实例被拒绝，不能静默丢项后保存；第 128 个合法实例可保存。
- [ ] 写入检查组与成片草稿归属及当前修订；越权、CSRF 失败和版本冲突零写入。切换到不同正文长度的成片草稿或缩短时间线后，导出前重新检查帧边界。
- [ ] 刷新重载、关闭／重开包装、修改其他包装字段、重新提取卖点和恢复文字版式均保留合法贴纸；显式空数组可清空；旧无贴纸配置行为不变。
- [ ] 28 个共同 ID 跟随模板解析，固定跨风格素材与 special 保持风格；切换模板后有效图案中心和视觉宽度保持。
- [ ] 单条正式导出通过四模板验证；预览与成片的默认位置、尺寸、时间及默认动效一致。用静态实例补测可见边界，片头、最终解码帧数和音轨不变。
- [ ] 入队后再修改贴纸，旧任务仍使用入队快照；丢图、哈希异常、路径越界或不支持模板明确失败，不发布漏图成片。
- [ ] 团队正式产物可通过既有授权链播放和下载，封面历史版本可读；失败发布保持原有产物与回滚行为。

## 验证与演示

以真实页面新增、正式保存、刷新和导出为主链路。沿用单条包装配置／卖点测试、贴纸领域与工作区测试、真实包装渲染、团队授权矩阵和交付发布测试；补原始非法输入与历史快照用例。隔离数据根下演示一张贴纸从素材库进入已登记正式产物。

## 完成后提供

共享实例／默认值与验证合同、保存字段保留规则、四模板统一运行时和冻结快照通路。新增字段不能留下会静默清洗输入的既有写入口。
