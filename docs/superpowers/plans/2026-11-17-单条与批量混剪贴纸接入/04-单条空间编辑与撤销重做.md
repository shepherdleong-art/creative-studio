# 04: 单条空间编辑与撤销重做

**What to build:** 用户直接在预览中拖入、移动、等比缩放、旋转和删除贴纸；每次有效编辑可保存、刷新、撤销和重做，最终导出采用相同结果。

**Blocked by:** 03 · 单条贴纸添加保存与正式导出。

**状态：** `ready-for-agent`

**发布状态：** 用户已确认拆分，已发布为正式实施票；功能尚未开始。  
**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D03、D06、D08；故事 7–8、11–13、21、25、37、39、44；T02 空间编辑与历史、T08、T10 几何、T12 iframe 与焦点。

## 修改范围

- 接入共享贴纸空间编辑桥、当前实例选择和本地手势草稿，绑定当前组、成片草稿、修订及 iframe 身份。
- 在现有单条命令／历史中增加包装恢复分支，形成可供轨道、动效和自动布置复用的“提交一项编辑／提交整组变化”能力；先整理该窄边界，再接手势，不重写全工作台状态。
- 接入拖放落点、移动、等比缩放、旋转、调整框删除与空白取消选中；共享预览组件保留文字编辑及统一封面行为。
- 实例补丁统一维护自动来源的已编辑标记，便于 07 后续提供换组保护；测试可通过合法实例 fixture 覆盖，不提前实现自动布置 UI。
- 代码导航：父票「共享模型及算法」「单条保存与历史」「单条界面」「共享预览与模板」。

## 不包含

不提供位置数值面板、非等比拉伸、镜像、单张复制、关键帧或自定义曲线。时间轴修剪和换轨由 05 实现。

## Acceptance criteria

- [ ] 拖入预览以松手位置作为有效图案中心；移动、等比缩放和旋转以 alpha 有效包围框计算，不把透明画布边距当图案。
- [ ] 有效中心留在画布内，部分超出区域按边界裁切；拖近画布中心、边缘或其他贴纸边缘时显示标线并吸附，离开后可自由移动。
- [ ] 选中贴纸自动进入贴纸页，空白取消；调整框和删除键能删除正确实例，文字输入不被误删，Ctrl/Cmd+D 不创建实例。
- [ ] 手势中只更新草稿，松手形成一次正式保存和一个历史项；右键取消恢复原值、不增加修订或历史。
- [ ] 添加、删除、几何修改均能撤销／重做并刷新恢复，恢复仍受当前修订校验；失败不污染已提交历史，不倒写旧修订。
- [ ] 修改自动来源实例会正确标记已编辑，撤销／重做恢复相应来源状态；手动实例保持手动身份。
- [ ] 快速切换成片草稿、关闭预览或重载 iframe 后，旧手势、旧保存回调和旧文档不能修改新对象；封面／文字编辑不串用贴纸回调。
- [ ] 真实导出抽帧与保存后的预览比较中心、视觉宽度、旋转及裁切；重新打开统一封面编辑和文字编辑仍正常。

## 验证与演示

以真实单条编辑器完成“拖入 → 移动／缩放／旋转 → 撤销／重做 → 刷新 → 导出”；补版本冲突和旧 iframe 回调场景。沿用贴纸编辑器、组级工作区历史、统一封面与快捷键、透明预览缩放测试。覆盖浅深主题和三档窗口的调整框可达性。

## 完成后提供

稳定的实例补丁、整组提交、选中目标与包装历史恢复能力。05 和 06 分别在该边界上实现轨道与动效，不各自复制一套历史。
