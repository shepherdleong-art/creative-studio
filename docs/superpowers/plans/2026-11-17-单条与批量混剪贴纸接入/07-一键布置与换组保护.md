# 07: 一键布置与换组保护

**What to build:** 用户一键生成开头、中段和结尾共六张贴纸，再调整或换一组；手动贴纸保留，已编辑自动组合在替换前得到提醒，结果能保存、撤销、刷新和导出。

**Blocked by:** 06 · 贴纸动效设置与一致预览。

**状态：** `ready-for-human`

**发布状态：** 已实现并完成本轮验收；结果和基线限制见 Comments 与收尾验收记录。

**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D05、D06、D08；故事 18–21、25、32、39、50；T05 本片布置与换组、T08、T10 自动组合。

## 修改范围

- 引入共享自动布置纯规划器和四模板安全槽位，连接真实面板操作、默认动效、正式组级保存和 04 的原子历史。
- 在现有贴纸列表派生自动组与编辑保护状态，新增／换组只发生在用户明确点击时；不把随机放到渲染、读取或 React 重渲染中。
- 复用已存在的实例补丁标记、保存、默认动效及预览导出链路；将整体生成作为单次用户编辑，不循环提交六次。
- 代码导航：父票「共享模型及算法」「单条界面」「单条保存与历史」。

## 不包含

不做跨片随机变体、AI 构图分析、自动箭头指向或全画面随机位置。05 的轨道不是本票开始条件；若轨道已集成，补测轨道修改后的保护标记，最终批量闭环统一覆盖。

## Acceptance criteria

- [x] 正文 143 帧时禁用并说明原因，144 帧及以上允许；每次生成恰好六张，开头两张 opening、中段 explain 加 gesture、结尾两张 ending，同阶段不重复。
- [x] 箭头／圈注不进入自动池；四模板首次布置使用固定安全槽位；正文三等分，每阶段中心取 25%／75%，时长 19–48 帧，帧起止合法、不进入片头、不相互挤出阶段。
- [x] 新自动实例采用生成当时的新增默认动效，整个组合共享一个新自动组身份；更改默认值不回写既有组合。
- [x] 已存在自动组合时改为换组操作，不累加为 12／18 张；手动贴纸的身份、内容和位置保持。
- [x] 自动实例被人工移动、改动效等操作后标记已编辑；换组前提示这些调整将被重置，取消保持原数据，确认后只替换自动组合。
- [x] 手动删除部分自动实例后，普通刷新、预览和导出不补回；显式换组才生成新六张。全部自动实例删除后恢复首次布置入口。
- [x] 生成或换组各为一次保存和一次历史操作；撤销恢复完整原组合及手动实例，重做恢复同一已保存结果而非重新抽取。
- [x] 固定随机源可复现结果，真实用户多次点击会保存各次选择；刷新和排队后导出不重新随机，也不产生外部模型请求。
- [x] 已有手动实例加六张超过 128 上限时明确拒绝且零写入，不删手动实例、不生成残缺组合。

## 验证与演示

演示“手动一张 → 自动六张 → 修改一张 → 换组取消／确认 → 撤销重做 → 刷新 → 导出”。用规划器公共输出测试阶段、类别和随机约束，用真实编辑器验证保护与历史。跨片删除不补回另由 09 覆盖。

## 完成后提供

可复用自动布置操作和规划器，包含显式随机依赖与整组结果合同；08 接到批量当前编辑对象，09 复用其阶段语义而不复制算法。
