# 05: 单条贴纸时间轴与层级

**What to build:** 用户在时间轴选中、移动、修剪和上下换轨，预览同步显示正确时间与层级；保存、刷新、撤销重做和正式导出都保持一致。

**Blocked by:** 04 · 单条空间编辑与撤销重做。

**状态：** `ready-for-human`

**发布状态：** 已实现并完成本轮验收；结果和基线限制见 Comments 与收尾验收记录。

**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D03、D04、D06、D08；故事 9–13、25、37、39–40、46；T02 轨道、T03、T10 时间与层级、T12。

## 修改范围

- 引入共享整帧时间轴运算和可复用贴纸轨道，接到现有单条时间轴及 04 提供的选中、补丁和历史边界。
- 实现整体移动、双边修剪、层级归一化、插入标线和占位，使用现有磁吸开关与取消手势。
- 轨道接口明确“最终时间线帧”和“显示坐标”的换算边界，为 08 的正文零点复用留接口；不要先另写批量轨道实现。
- 调整新增轨道后的高度和滚动，保留当前完整预览优先、主题令牌及其他轨道操作。
- 代码导航：父票「共享模型及算法」「单条界面」「单条保存与历史」「样式与验收设施」。

## 不包含

不新增多选部分贴纸、复制快捷键或新的磁吸交互；不改其他轨道时间单位、视频／音频编辑规则。

## Acceptance criteria

- [x] 预览和轨道双向选中，选中后进入贴纸页；轨道展示中文素材名，颜色通过令牌在浅深主题中保持可辨。
- [x] 移动和双边修剪只产生整帧结果，起点不进入片头，终点不超出正文，最短 19 帧；18 帧请求被拒绝，失败保存不改变原配置。
- [x] 磁吸覆盖播放头、镜头和卖点边界、其他贴纸起止点；关闭磁吸后只保留必要整帧约束，不继续吸附这些目标。
- [x] 多贴纸同时出现时正确分行和叠放；向上换轨只提高层级，不改变起止时间，松手前可见插入标线、目标高亮和占位。
- [x] 同时出现的贴纸按轨道顺序叠放，包装标题／卖点始终在上，正文字幕仍在贴纸之下；导出抽帧验证而非仅看轨道排序。
- [x] 拖动中右键取消后时间、层级和历史均恢复；移动、修剪、换轨各为一次可撤销编辑，自动来源的已编辑标记由共享补丁维护。
- [x] 从预览 iframe 切回轨道后 Delete/Backspace 可删除正确贴纸；输入焦点和其他轨道快捷键不受影响。
- [x] 刷新、撤销重做与正式导出保持时间及层级；起点前、终点及之后帧无意外显示，透明层不增加底片解码帧数。
- [x] 三档窗口和浅深主题中，新增轨道后视频比例正确、时间轴与属性区可独立滚动，不恢复页面外层纵向滚动。

## 验证与演示

演示两张有时间重叠的贴纸，完成修剪、磁吸开关、上下换轨、取消、删除和历史回放，再导出检查起止帧与叠放。复用贴纸时间轴纯函数测试、真实编辑器、快捷键与 UI 尺寸设施。

## 完成后提供

可复用轨道与明确的显示时间偏移接口。无需等待 06 的动效选择器；两票共享预览协调文件时按顺序编辑，不把文件重叠伪装成产品依赖。
