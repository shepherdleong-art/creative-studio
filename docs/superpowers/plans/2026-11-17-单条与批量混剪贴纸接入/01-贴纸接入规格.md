## 实施时优先核对的差异

1. dev 的新资源和跨片接口没有当前团队路由包装；不能原样导出 handler 后绕过授权分类。
2. dev 的单条包装发布实现缺少当前受管产物登记、独立封面版本和回滚步骤；只接贴纸增量。
3. 当前透明预览配色和 Windows 媒体工具显式传递均比 dev 新，必须保留。
4. dev 批量保存存在先清洗后验证的路径；实现规格 D06 时必须先检验原始贴纸字段，并覆盖整包封面应用与恢复入口。
5. 当前完整渲染契约已经消费包装配置；优先通过既有契约证明贴纸编辑使旧渲染失效，不另造渲染身份体系。
6. 当前生产打包通过显式同步复制包装资源，源码可读不等于 standalone 可读；增加完整目录装配与隔离成品验证。
