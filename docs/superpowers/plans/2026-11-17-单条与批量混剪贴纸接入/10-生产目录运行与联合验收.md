## 修改范围

- 补齐既有隔离浏览器、团队授权、媒体真实导出、UI 尺寸和生产装配 fixtures，使它们能从正式入口覆盖贴纸完整工作流。
- 在新生产目录验证资源交付、运行时版本与来源核验、受管产物发布和下载；测量本功能资源体积增量，不新增运行时联网安装。
- 修复联合验收暴露的本功能集成问题，并把根因与证据归回对应票；本票不接收前序缺失的整块产品实现，不顺带修全仓历史问题。
- 更新本功能常驻参考及最终证据索引，汇总检查结果。仅隔离构建／验收，不部署真实服务或生成正式分发包。
- 代码导航：父票「素材和装配」「导出快照与正式发布」「静态资源与团队授权」「样式与验收设施」，以及各前置票拥有的集成点。

## 验证与演示

沿用现有隔离生产服务、团队登录、主流程和 UI 验收入口，测试前先设置独立数据根，再加载会固定数据根的模块；使用正式 API 或隔离库准备 fixture。演示“生产目录启动 → 登录／本地打开 → 单条贴纸导出 → 批量复制与整体撤销 → 正式成片下载”。实际部署、正式签名／发包及真实付费任务不在本票范围。
