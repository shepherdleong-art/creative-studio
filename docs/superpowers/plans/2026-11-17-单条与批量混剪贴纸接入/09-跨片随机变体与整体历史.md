# 09: 跨片随机变体与整体历史

**What to build:** 用户把一条成片计划的贴纸方案复制给同批次版本中的多个有效目标；手动设计适配时长，未编辑自动贴纸产生受控变体。所有目标一起保存、一起撤销或重做，任何冲突都不会留下半批修改。

**Blocked by:** 08 · 批量逐条编辑与正式导出。

**状态：** `ready-for-agent`

**发布状态：** 用户已确认拆分，已发布为正式实施票；功能尚未开始。  
**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D05–D09；故事 26–39、42–43、46、48、50；T05 跨片不补回、T06、T07、T09、T10 变体、T12 复制弹窗。

## 修改范围

- 引入跨片变体纯规划器，复用既有素材目录、阶段与帧规则、实例验证和安全槽位；注入随机源与 ID 生成器。
- 新增批次级复制／恢复事务与正式接口；来源和每个目标均带稳定身份、成片版本及预期编辑修订。团队路由、CSRF、领域访问及嵌套引用授权一并接入。
- 新增目标选择弹窗，复用批量已选集合；每项目标显示有效状态、不可用原因、已有贴纸及审核状态，提交结果刷新实际受影响目标。
- 在既有单片历史旁扩展多片历史项，只保存并恢复贴纸及新增默认动效快照；保留其余编辑、源成片和当前读取机制。
- 优先移植来源分支现有实现，按当前权限、来源版本门禁与单片历史合同适配；不重新设计数据库或建立后台复制任务。
- 代码导航：父票「跨片事务与界面」「共享模型及算法」「批量保存及整包兼容」「静态资源与团队授权」。

## 不包含

不做跨项目／批次／批次版本复制、单张复制、部分贴纸多选或无限唯一变体承诺。整体撤销不恢复旧审核确认，不覆盖目标的完整安排。

## Acceptance criteria

- [ ] 来源无贴纸、包装关闭或不可编辑时不能发起；弹窗排除来源，默认勾选已选有效目标，可全选有效、清空或逐项选择，无效原因可见。
- [ ] 有效范围限定同项目、同批次及同当前批次版本；已有贴纸和已审核目标仍可选，但明确提示整体替换及重新审核。提交中防重复，成功数量对应实际写入。
- [ ] 手动及已编辑自动实例按正文相对帧比例映射，保留素材选择规则、位置、尺寸、旋转、动效与相对层级；不足 19 帧或越界的目标整体拒绝，纯手动方案不错误套用六秒限制。
- [ ] 未编辑自动实例只复制仍存在的部分，不补回删除项；目标至少 144 帧，按目标阶段重排，同类别素材／安全槽位／五种可见动效生成变体，尺寸、旋转和相对层级保留。
- [ ] 同阶段素材不重复，跨片优先较少使用的候选，池耗尽时有限放宽并结束。每个目标有新实例及自动组身份，已编辑自动标记保留，跟随／固定风格规则正确。
- [ ] 只替换目标贴纸与默认动效，其他包装、音频、画面、字幕及封面设置不变；来源不改写。成功目标修订递增并清除审核，完整渲染身份相应失效。
- [ ] 同一事务重验来源与全部目标；来源过期、任一目标版本／修订冲突、停止批次、重复／空目标、跨归属、非法原始输入或保存失败均使全部目标零写入，审核状态也不部分改变。
- [ ] 团队正式接口校验来源、每个目标及预期版本的授权和归属；未知字段不能夹带非贴纸快照修改，越权或 CSRF 失败不泄露其他项目内容。
- [ ] 双目标复制形成一个多片历史项；一次撤销／重做恢复全部目标的贴纸字段，修订继续前进，其他编辑及来源保持；任一冲突零恢复并清除不可回放历史。
- [ ] 结果在命令执行时生成并持久化；刷新、预览、重做和导出使用同一结果。复制后再编辑或排队后变更不串改旧任务快照。
- [ ] 在真实页面从含手动、已编辑自动、未编辑自动实例的来源复制到两条不同时长目标，刷新后各导出一条成片，能核对时间映射、差异和来源不变。
- [ ] 复制弹窗在双内核、浅深主题及三档窗口中可选择、滚动、取消及提交；错误后可重试，不能显示不存在的部分成功。

## 验证与演示

用真实弹窗、正式接口和数据库验证双目标成功及单目标冲突回滚，再做整体撤销／重做和导出。沿用来源变体规划器与复制事务测试、当前批量历史／授权设施；固定随机源测试约束和可复现，不复制实现算法。后端测试覆盖源版本变化，不能只测目标冲突。

## 完成后提供

复制／恢复请求与响应合同、多片历史项和事务证据；更新与本功能直接相关的批量／包装常驻说明。保持父规格与规格入口不变。
