# 08: 批量逐条编辑与正式导出

**What to build:** 用户在批量统一审片选中一条成片计划后，使用完整贴纸库、空间编辑、轨道、动效和一键布置；修改只保存到该成片版本，可撤销、重新审核并正式导出，切片和编辑封面不会串改或丢贴纸。

**Blocked by:** 05 · 单条贴纸时间轴与层级；07 · 一键布置与换组保护。

**状态：** `ready-for-agent`

**发布状态：** 用户已确认拆分，已发布为正式实施票；功能尚未开始。  
**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D03–D06、D08、D09；故事 2、6–25、33、37–50；T02–T05 批量入口、T08、T09、T10–T13 批量相关部分。

## 修改范围

- 复用已完成的贴纸面板、动效浮窗、轨道和共享预览，接入批量包装卡、检查器、预览及统一时间轴；不增加检查器顶层第六页签。
- 扩展当前选择类型、草稿和忙碌状态，绑定成片计划、成片版本与编辑修订；复用现有按需详情加载和请求代际，按当前对象接受回调。
- 将共享贴纸操作适配到现有批量包装命令、整包历史、审核失效及完整渲染契约；补全封面草稿应用和恢复入口的原始输入校验。
- 核对批量正文零点到最终帧号的唯一换算、冻结快照及共享包装导出；保持源画面／声音／字幕规则和既有发布链路。
- 代码导航：父票「批量逐条编辑」「批量保存及整包兼容」「共享预览与模板」「导出快照与正式发布」「样式与验收设施」。

## 不包含

不提供跨片复制或多片历史，不改眼睛预览、导出选择、原素材池、统一封面草稿、读取并发或现有生产调度的产品含义。

## Acceptance criteria

- [ ] 在真实批量统一审片中选中成片计划，包装内的双页签可浏览、点击／拖放添加，并完成空间、时间轴、动效和一键布置操作；所有动作实际保存并可刷新恢复。
- [ ] 预览／时间轴选择同步当前编辑对象；换一组和应用全部仅影响该成片版本，另一条的配置与审核状态不变。
- [ ] 时间轴以正文 0 秒显示，持久化与渲染使用含 20 帧片头的坐标，转换一次；移动、修剪、19 帧下限和片头／正文终点正确。
- [ ] 每次有效单片编辑进入既有历史，递增修订并清除该片审核；整包撤销／重做保留非贴纸编辑合同，冲突不覆盖新状态。
- [ ] 普通包装保存、统一封面应用和历史恢复都先验证原始贴纸及默认动效。非法实例／默认值、重复 ID、数量或时间越界均拒绝，原数据与审核状态保持。
- [ ] 封面草稿取消不保存；应用封面、改标题、重新提取卖点和恢复文字布局均保留正文贴纸。纯正文贴纸编辑不触发封面重做或整片即时渲染。
- [ ] 快速切片、详情迟到、当前版本更换、切换素材监看及多个 iframe 并存时，旧选择、草稿、播放任务和回调均不能作用于新对象。
- [ ] 以有贴纸的两个成片计划验证团队归属、版本／修订和 CSRF；关闭包装时数据保留，恢复后仍可编辑。
- [ ] 从批量正式导出生成带贴纸产物，覆盖四模板和不同正文时长；入队后编辑不改变旧任务，片头、音轨、总帧数及登记／下载保持正确。
- [ ] 当前专注剪辑布局、完整视频优先、内部滚动及按需详情加载保持；浅深主题和三档窗口新增轨道后可用，未恢复整批读取详情。

## 验证与演示

真实批量编辑器造至少两条不同正文长度的成片计划，验证逐条修改隔离、封面兼容、历史、审核和导出。沿用批量片段编辑、整包恢复、安排加载器、统一封面、贴纸编辑器、授权矩阵与真实批量渲染先例；共享组件改动后运行受影响的单条回归。

## 完成后提供

批量单片贴纸保存与历史适配，以及当前成片版本／修订读取接口。05 提供轨道，07 经 06 和 04 提供其他完整编辑能力，所以无需重复列出这些传递依赖。
