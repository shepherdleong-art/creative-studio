# 02: 内置贴纸库浏览与授权

**What to build:** 用户在单条精准混剪的视频包装内打开“贴纸”页，浏览四种风格、按分类和中文搜索找到内置素材；个人本地及团队登录后的界面均读取同一目录，生产目录也能提供这些资源。

**Blocked by:** None (can start immediately).

**状态：** `ready-for-human`

**发布状态：** 已实现并完成本轮验收；结果和基线限制见 Comments 与收尾验收记录。

**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D01、D02、D09；故事 3–5、42、46–47、49；T01 素材发现、T09 静态资源、T12 素材页、T13 装配。

## 修改范围

- 引入已冻结来源中的完整素材目录、清单、缩略图、运行时和素材装配工具；核验实际文件与清单一致。
- 在既有包装卡内接出可复用的贴纸素材库视图。先隔离素材读取、筛选和选择回调，使后续新增行为能接入；只作本票必要的小范围整理，不重构整个预览工作台。
- 新增内置贴纸资源读取，纳入团队路由分类、登录校验与安全路径限制；保留个人本地访问语义。现有模板资源授权仍有效。
- 将资源加入现有生产同步白名单与对应测试 fixture，保留隔离构建和用户数据排除，不更换 Next 文件追踪策略。
- 代码导航：父票“代码落点”中的「素材和装配」「静态资源与团队授权」「单条界面」「样式与验收设施」。具体路径只在该导航维护。

## 不包含

添加、保存、空间编辑、动画选择及正式贴纸导出由后续票接入。本票展示真实素材库，不提供假成功的添加动作；不新增数据库表、资源市场或自定义上传。

## Acceptance criteria

- [x] 在真实单条精准混剪页面打开包装卡的贴纸页，能读到四种风格合计 115 张素材：28／29／29／29；原包装设置页仍可操作。
- [x] 默认仅显示当前模板，切换全部风格、分类与中文搜索组合过滤正确，空结果和加载失败有可恢复的明确反馈。
- [x] 目录与全部原图／缩略图一一对应，清单尺寸、有效包围框和 SHA-256 可验证；列表请求缩略图，浏览素材库不会整批请求原图。
- [x] 团队未登录请求被拒绝；登录后目录、缩略图与原图可读。目录穿越、非法扩展名、未知文件按既有错误规则拒绝，不返回物理路径或私有字体。
- [x] 隔离生产同步目录包含完整贴纸资源，源码目录不可用时仍可读取；用户数据、缓存与密钥继续被排除，轻客户端不增加生产后端。
- [x] 当前模板编号 f1–f4、字体和原有包装入口不变；素材页使用当前令牌，在浅深主题和三档窗口下控件可达、无页面横向溢出。

## 验证与演示

沿用包装资源与 standalone 边界测试、团队 API 授权矩阵和 UI 尺寸设施，补一个真实页面素材发现场景。演示“打开贴纸页 → 筛选 → 全部风格 → 生产目录读取相同资源”。不以源码字符串断言或目录存在代替实际读取。
