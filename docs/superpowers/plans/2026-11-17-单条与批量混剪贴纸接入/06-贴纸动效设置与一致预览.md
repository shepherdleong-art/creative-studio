# 06: 贴纸动效设置与一致预览

**What to build:** 用户在同一小浮窗比较六种动效，设置新增默认、当前贴纸或显式应用到全部；保存后立即预览正确效果，刷新和导出保持同一设置。

**Blocked by:** 04 · 单条空间编辑与撤销重做。

**状态：** `ready-for-agent`

**发布状态：** 用户已确认拆分，已发布为正式实施票；功能尚未开始。  
**Parent：** [01 · 贴纸接入规格](01-贴纸接入规格.md)。  
**规格覆盖：** D03、D05、D06、D08；故事 14–17、25、37–40、46、50；T04、T08 默认值保留、T10 六动效、T12 浮窗。

## 修改范围

- 引入共用动效选择浮窗和六卡示例，接入素材面板及既有模型／默认值；使用 04 的当前选中与历史提交能力。
- 动效区按选中状态选择保存目标；应用全部通过一次明确命令完成，保留已保存的单张设置直到用户显式覆盖。
- 在现有预览加载与播放协调中处理“保存完成 → 新文档和正确时间线就绪 → 播放”，加入目标身份及旧播放任务淘汰。
- 沿用 03 的同一运行时，核对六预设、模板推荐、短时长压缩和导出时间边界，不另造 React 动画实现。
- 代码导航：父票「单条界面」「单条保存与历史」「共享预览与模板」「导出快照与正式发布」「样式与验收设施」。

## 不包含

不做曲线编辑、逐帧关键帧、GIF／视频素材副本；不依赖贴纸轨道已上线，不提前提供自动布置。

## Acceptance criteria

- [ ] 浮窗同时显示柔和、Q 弹、上浮、滑入、缩放、无动画六卡，均用同一示例图；选择、点击外部或关闭按钮可关闭，关闭后示例动画停止。
- [ ] 未选中时修改“新贴纸默认”，仅之后新增实例受影响；选中时只修改该实例，当前组其他实例不变，刷新后设置仍成立。
- [ ] 跟随模板时花字种草／综艺撕纸使用 Q 弹，手账拼贴／极简高级使用柔和；固定预设不因模板改变被重置。
- [ ] “应用到全部贴纸”只更新当前组级包装；有不同单张设置时先提示覆盖，取消零写入，确认后一次保存、一次撤销／重做。
- [ ] 非法默认值和实例动效经正式写入口拒绝，保持原数据；连续快速选择时最终显示最后成功保存的设置。
- [ ] 保存后播放等待正确的新 iframe 文档、实例和时间线就绪；切换成片草稿、重新加载或新的播放请求使旧任务失效，不播放旧效果。
- [ ] 合法最短时长及普通时长下六动效均完整落在实例区间；入出场和稳定帧可见，终点无拖尾，预览与真实成片一致。
- [ ] 浮窗在三档窗口、浅深主题中可操作，不遮住关键视频／时间轴操作区；动效库关闭后无持续示例播放，素材列表不运动。

## 验证与演示

从真实页面比较六卡，分别修改默认、单张和全部，刷新后导出；逐帧检查代表性入场、稳定及退场帧。沿用贴纸编辑器与真实渲染测试，针对新文档就绪和连续选择补竞态测试。
