# 05 团队用量页面验收

**状态：** `ready-for-agent`
**Blocked by：** 03 管理员成员用量下钻、04 员工个人模型统计与明细

**What to build:** 对正式团队用量页面完成多角色、响应式、主题与构建验收，确认真实费用口径、权限隔离和已确认的页面层级可以共同交付。

**依据：** [新 Spec 确认单](../../specs/2026-11-05-客户端无黑窗启动与成员用量分析-确认单.md)。03 已传递依赖 02；本票不等待独立的 06 客户端交付。

**验证入口：** `scripts/team-usage-admin.test.ts`、`scripts/team-usage-routes.test.ts`、`scripts/team-usage-ui-contract.test.mjs`，并复用日期与本地用量合同测试。视觉操作通过隔离数据的正式页面验收，不能只检查源码字符串。

- [ ] 管理员首次进入本月团队成员总览、前 10 位图与完整表、明细展开、成员下钻及返回恢复筛选/位置全部可操作；没有模型优先旧层级。
- [ ] 管理员仅看自己与普通员工个人页正确；真实认证的越权请求不能泄露其他成员身份、费用、额度、明细或 CSV。
- [ ] 至少 12 位成员、多模型数据下，图表排序和前 10 位范围正确，完整表/导出不丢成员；覆盖同金额、零用量、停用与不限额成员。
- [ ] 成员费用、模型费用、趋势、明细和 CSV 在同一筛选下对账；覆盖重试、协议回退、结算、预留、释放、未定价、不确定和跨月边界，预留不重复相加，未知费用不被误示为免费。
- [ ] 验收桌面与窄窗口、浅色与深色，检查长姓名/模型名、图表尺寸、图例、悬浮及键盘提示、表格横向滚动、加载/空/错误和快速切换成员。
- [ ] 运行定向 Node 测试、TypeScript、定向 ESLint、生产构建及浏览器验收；记录执行命令、真实结果、截图位置和未完成检查。若遇无关工作区阻断，明确归属，不回滚他人修改或虚报通过。
- [ ] 使用临时数据根与隔离测试数据；不调用真实付费供应商，不将原型模拟数据或调试路由加入正式入口，不停止现有客户端或服务器。
- [ ] 交付本轮验收记录，区分已实现、已测试与未部署；02/03/04 的功能测试仍由各票负责，不把测试全部推迟到此票。不在本票重写已存在的模型权限能力。
