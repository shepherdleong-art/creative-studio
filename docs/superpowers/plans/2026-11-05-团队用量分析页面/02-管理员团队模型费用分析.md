# 02 管理员团队模型费用分析

**状态：** `ready-for-agent`
**Blocked by：** 01 恢复模型权限准入与统计基线

**What to build:** 管理员在正式用量页面按已确认的本地版分区查看团队月度额度，使用日期、模型和结果筛选查看真实模型排行、逐日费用趋势与调用明细。团队额度不随筛选改变，分析与明细使用同一范围。

- [ ] 页面顺序为团队额度、筛选、模型消耗排行与趋势、调用明细；采用真实数据，不引入原型模拟数据或切换器。
- [ ] 支持今日、近 7 天、本周、本月和自选日期；北京时间自然日、周一起算及左闭右开边界正确。
- [ ] 模型排行展示调用、已计费用和占比；趋势按模型与自然日分桶、无记录日期补零。
- [ ] 已结算、预留、已释放、未定价和不确定保持既有口径，未知金额不显示为零。
- [ ] 趋势图具有足够空间、坐标、图例、空状态及长模型名称处理；不新增图表依赖或硬编码浅色值。
- [ ] 接口测试覆盖筛选一致性、重试与协议回退、费用边界；页面覆盖加载、无数据和错误状态。
