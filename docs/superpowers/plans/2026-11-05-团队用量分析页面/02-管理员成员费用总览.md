# 02 管理员成员费用总览

**状态：** `ready-for-agent`
**Blocked by：** None (can start immediately)

**What to build:** 管理员首次进入团队用量即可比较本月各成员的费用与调用次数，通过前 10 位横条图和完整成员表定位谁用得多，并能从图或表打开已有成员详情。筛选、未知费用提示、额度账期与导出始终保持真实且一致。

**依据：** [新 Spec 确认单](../../specs/2026-11-05-客户端无黑窗启动与成员用量分析-确认单.md)，不是旧模型优先 PRD。

**实现入口：** `components/team/TeamUsagePanel.tsx`、`lib/team-service/usage.ts`；沿用团队用量 GET 和 CSV 路由。先复用已实现的额度、成员汇总和下钻，不修改执行准入。

- [ ] 管理员默认全团队、本月、全部模型和全部结果；前端显式请求团队范围，GET 省略范围仍默认本人，不改变员工隔离。
- [ ] 页面顺序为团队本月额度摘要、筛选、成员横条排行与完整成员表、默认收起的团队调用明细；首页不先展示模型分析，不增加团队总趋势。
- [ ] 顶部含本月已计、已结算、待结算预留、有限额度合计和剩余、不限额人数；标明账期不随筛选变化，预留不重复相加。
- [ ] 支持今日、近 7 天、本周、本月和自选日期，以及模型、结果和刷新；北京时间自然日、周一起及左闭右开边界正确。
- [ ] 成员按期间已计费用降序，同金额按工号稳定排序；图表标明前 10 位并显示金额及调用次数，完整表包括其余成员、零用量及已有停用成员。
- [ ] 表格包含姓名、工号、角色、期间调用、期间已计、本月已计、额度、剩余及查看入口；不限额不显示为零。图表成员和表格按钮均能打开对应成员的既有详情。
- [ ] 成员响应兼容新增筛选期未定价、不确定调用数；使用同范围真实执行尝试聚合，重试计次，已释放不计费用。图表和表格提示未知状态，仅含未知费用不能只显示零元，有不确定预留也必须提示。
- [ ] 保留仅看自己及管理员 CSV；导出匹配当前筛选并覆盖全部成员，不受前 10 位限制。收起明细仍可展开核查，未知费用不被导出为零元。
- [ ] 使用设计令牌，具备可读图表、键盘可达入口、加载/空/失败状态；窄窗口和深色模式可用，不使用原型假数据或调试控件。
- [ ] 扩展团队用量管理、路由及 UI 测试并完成本票浏览器演示：至少 12 位成员、多模型、同金额、未知费用和日期边界；图、表、明细及导出一致，员工请求团队范围不能泄露他人数据。
