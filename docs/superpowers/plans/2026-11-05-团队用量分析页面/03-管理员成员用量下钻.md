# 03 管理员成员用量下钻

**状态：** `ready-for-agent`
**Blocked by：** 02 管理员团队模型费用分析

**What to build:** 管理员在团队模型分析之后查看成员用量，点击成员进入其月度额度、模型排行、趋势和调用明细，并保留筛选返回全团队。成员的筛选期用量与自然月额度明确分开。

- [ ] 成员表展示身份、调用、筛选期费用、本月已计、月度额度、剩余可用和不限额状态。
- [ ] 下钻展示目标成员身份、自然月额度摘要、模型分析及其调用明细，可返回全团队。
- [ ] 下钻复用同一用量查询入口及当前日期、模型与结果筛选，不从全团队响应推断权限。
- [ ] 管理员 CSV 保持同范围过滤和权限，未知金额不导出为零。
- [ ] 路由测试验证指定成员查询、账期差异与权限；页面合同验证下钻与返回路径。
