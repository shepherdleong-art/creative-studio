# 03 管理员成员用量下钻

**状态：** `ready-for-agent`
**Blocked by：** 02 管理员成员费用总览

**What to build:** 管理员从成员图或列表进入详情，看到此人的模型费用排行、每日趋势和调用明细；可以独立调整详情筛选，返回时恢复原团队筛选与列表位置，连续核查多人时不丢失上下文。

**依据：** [新 Spec 确认单](../../specs/2026-11-05-客户端无黑窗启动与成员用量分析-确认单.md)。

**实现入口：** `components/team/TeamUsagePanel.tsx`、`lib/team-service/usage.ts` 及团队用量 GET/CSV 路由；复用既有指定成员查询与 SVG 趋势。

- [ ] 详情顺序为成员身份和本月额度、筛选、模型费用排行与每日模型趋势、调用明细；姓名、工号和返回全团队入口明确可见。
- [ ] 从图表或列表进入同一详情，继承进入时的日期、模型和结果筛选；详情筛选独立修改，返回恢复原团队筛选和列表滚动位置。
- [ ] 模型按费用降序，包含模型名、调用次数、已计费用、占比及横条比较；沿用真实尝试与现有计费模型身份，不增加模块、项目或原始消耗量统计。
- [ ] 模型每日费用趋势保留日期/金额坐标、图例、悬浮与键盘提示；无调用日期补零，长模型名可读，模型排行与趋势有足够展示空间。
- [ ] 结算、有效预留、释放、不确定及未定价保持现有语义；未知状态可见，仅含未知费用的模型不得只显示零元；仅有不确定预留时也提示其未确认性质。
- [ ] 复用服务端指定成员查询；切换成员时清除旧成员数据，过期响应不能覆盖新选择；加载、空数据和失败明确区分。
- [ ] 明细保留时间、模型/模块、结果、费用与可展开的任务/请求关联。CSV 限管理员且导出当前成员及详情筛选范围，返回后恢复团队导出范围。
- [ ] 路由和浏览器测试覆盖 A 成员到 B 成员快速切换、详情筛选后返回、从前 10 位图表和完整表下钻、跨月、未知费用、CSV 与员工伪造他人成员参数被拒绝；通过定向测试及主题/窄窗口检查。
