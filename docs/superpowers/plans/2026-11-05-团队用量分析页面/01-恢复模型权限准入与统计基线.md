# 01 恢复模型权限准入与统计基线

**状态：** `ready-for-agent`
**Blocked by：** None (can start immediately)

**What to build:** 恢复执行准入对实际模型身份的精确权限校验，补齐团队用量查询所需的月度团队额度、成员额度和身份权限基线。现有额度、并发、预留和权限规则保持不变，员工只能访问本人数据。

- [ ] 恢复模型权限字段、读取与更新、精确模型身份判断和既有导出；定价别名不能替代实际模型权限。
- [ ] 缺少模型身份或不在白名单时拒绝准入与提交；恢复授权后既有排队任务可继续。
- [ ] 管理员可取得团队自然月已计、已结算、预留、有限额度合计与剩余及不限额人数；额度与分析筛选无关。
- [ ] 员工查询团队范围不泄露他人数据，查询他人员工被拒绝；成员汇总与 CSV 权限不回退。
- [ ] 保留工作区无关变更，不新增迁移，不修改供应商或生产调度。
- [ ] 执行准入、团队用量路由与用量管理测试通过，并完成类型与构建验证。
