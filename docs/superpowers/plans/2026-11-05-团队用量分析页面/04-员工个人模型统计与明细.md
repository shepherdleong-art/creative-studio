# 04 员工个人模型统计与明细

**状态：** `ready-for-agent`
**Blocked by：** 02 管理员团队模型费用分析

**What to build:** 普通员工在自己的用量页面查看个人月度额度、模型排行、逐日趋势和调用明细，并可按日期、模型和结果筛选。页面与接口均不允许访问团队或其他成员的数据。

- [ ] 员工页面显示个人额度、筛选、模型分析和本人调用明细，具备加载、空状态与错误提示。
- [ ] 不展示团队范围开关、成员列表、成员下钻或团队导出操作。
- [ ] 服务端强制本人范围；伪造团队范围不返回他人数据，伪造他人员工参数得到拒绝。
- [ ] 员工与管理员的相同个人查询得到一致的模型、趋势与明细口径。
- [ ] 使用带认证身份的路由测试验证权限，不仅依赖界面隐藏或源码合同。
