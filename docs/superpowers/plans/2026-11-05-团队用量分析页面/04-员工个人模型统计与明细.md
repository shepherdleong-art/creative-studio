# 04 员工个人模型统计与明细

**状态：** `ready-for-agent`
**Blocked by：** None (can start immediately)

**What to build:** 普通员工直接进入自己的本月额度、模型费用排行、每日趋势和调用明细；管理员“仅看自己”采用相同个人口径。沿用现有个人分析能力，补齐新 Spec 要求的费用比较与未知状态展示，并守住服务端权限边界。

**依据：** [新 Spec 确认单](../../specs/2026-11-05-客户端无黑窗启动与成员用量分析-确认单.md)。

**实现入口：** `components/team/TeamUsagePanel.tsx`、`app/api/team/usage/route.ts` 及既有团队用量查询；沿用共享模型分析组件，不另建个人图表或账本。

- [ ] 普通员工默认本人、本月、全部模型和结果；顺序为个人身份与本月额度、筛选、模型排行及趋势、本人调用明细。
- [ ] 日期选项包含今日、近 7 天、本周、本月、自选日期；模型、结果和刷新生效，个人月度额度不随分析筛选改变。
- [ ] 模型按费用排序并显示金额、次数、占比及横条比较；每日趋势保留坐标、图例、悬浮/键盘提示与无调用日期补零。费用主指标和真实尝试次数口径与管理员一致。
- [ ] 预留不重复计入，未定价和不确定有明确提示，仅含未知费用不得只显示零元；无调用的真正零值与未知费用区分。
- [ ] 员工页面及响应不暴露团队成员身份、排行、额度、他人明细或团队导出；伪造团队范围仍限本人，伪造他人参数被服务端拒绝。
- [ ] 管理员仅看自己采用同一分析能力，保留返回团队范围及原有管理员导出权限；普通员工没有这些管理操作。
- [ ] 加载/空/失败明确，浅色、深色和窄窗口可用；本地版统计与页面不变，不引入模拟数据、模块/项目分析或额度编辑。
- [ ] 带认证身份的路由测试覆盖员工本人、团队参数、他人参数、成员汇总与 CSV 拒绝；本人和管理员查询同一员工时统计一致，浏览器演示个人筛选、未知费用和非管理员无团队入口。
