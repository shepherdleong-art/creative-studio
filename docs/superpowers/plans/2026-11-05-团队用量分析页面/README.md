## 已定边界

- 管理员默认本月成员优先；费用为主、调用次数为辅，仅按模型下钻，不增加模块、项目或原始消耗量分析。
- 保持已有账本、权限、额度、自然月及未知费用语义；接口未传范围仍默认本人，本地版保持原状。
- 全程无黑窗只面向以后分发的新包；无旧包补丁、无现有客户端覆盖、无隐含发布或发消息动作。
- 保留既有未提交修改，尤其团队用量 UI 合同测试和客户端构建脚本；不为让验收通过回滚无关代码。
