## 范围与边界

- 统一员工与管理员的任务费用、用量明细和模型汇总视图。
- 复用 03 的真实尝试与费用记录，不新增与执行账本不一致的第二套计费。
- 仅对可信模型身份做统一模型投影，历史金额与已冻结价格不按当前配置回写。

## 验收标准

- [x] 员工看到本人任务的统一模型、合计用量与费用，一次自动兜底不会被展示为员工又主动创建了一份作品。
- [x] 管理员可从同一任务展开每次真实通道、尝试、价格快照、远端关联与费用核对状态，合计与明细一致。
- [x] 失败尝试不假定免费；未知费用不显示为已确认零元，混合已核账与估算的任务明确标注费用状态。
- [x] 模型分项、趋势、任务详情与总计采用一致的任务／尝试计数口径，说明哪些是生成任务数、哪些是通道调用次数。
- [x] 人员隔离在服务端实现，员工接口不返回其他成员信息或隐藏在页面中的完整通道快照；管理接口继续检查权限。
- [x] 旧记录保留原始金额和身份，统一展示只依据可信快照映射；无法识别的历史记录明确单列，不按名字猜测或按新价格重算。
- [x] 第二次尝试、迟到结果、取消后收尾或管理员核对导致费用状态更新时，任务合计及报表一致更新，重复事件不重复计费。
- [x] 各已接入及后续按共享合同接入的任务来源可被识别；不支持的记录明确说明，不静默漏掉费用。
- [x] 只展示真实估算与结算数据，不承诺固定统一售价或把两通道成本都计成七牛价格；敏感配置与完整上游请求不进入报表。

## 验证与演示

1. 准备单次成功、失败后成功、两次失败、估算与已核账混合、取消后成功及可信／未知历史记录，核对任务明细、汇总与趋势。

2. 以员工和管理员分别调用接口并查看页面，验证同一任务金额一致、人数隔离、计数口径及核对后的变化。

验证使用隔离数据和模拟供应商。涉及真实付费调用或生产变更时，以用户另行明确授权为准；没有外部证据的结论在交接中明确标为未验证。

## 交接要求

- 记录任务与尝试的统计口径、费用状态合并规则和历史身份映射来源，提供可重放的报表样本。
- 交付已核对的金额示例与仍未掌握的上游计费事实，避免将估算写成确定结算。
- 在下方 Comments 记录实际完成范围、验证证据、改动说明、剩余限制及后续任务需要的合同；满足全部验收项后，将执行进度改为“已完成”。
- 发现超出本任务的新需求时单独记录，保持本任务边界；阻塞任务未完成时先报告缺失成果，不另造一套替代合同。

**口径与交接**

- 生成任务数 = 有执行尝试的 `execution_media_tasks` 条数 + 无法映射的 legacy 业务任务去重数；通道调用次数 = execution attempt 条数。模型分项的 `taskCount` 之和与总任务数一致；一个任务若有两条通道尝试，仍只计一个制作任务。
- 任务级金额按当前筛选范围内的 attempts 汇总；`settled` 为已记录实际，`estimated` 为估算，`uncertain` 为待核账，`unpriced` 为未定价，`mixed` 表示同一任务混合状态。UI 不把失败或未知显示为免费。
- 后续入口只要写入 `execution_media_tasks/channels + execution_operations.mediaTaskId/channelKey`，报表自动识别；没有父任务的旧 attempt 继续明确单列。
- 未连接真实供应商账单；金额仍是工作台执行账本口径，不等于供应商最终核账。任务 13 的管理员核对若补齐 actual cost/result，本报表会在下一次读取时自动反映。
