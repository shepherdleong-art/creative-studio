# 14：统一模型费用报表

**状态：** `ready-for-agent`  
**执行进度：** 未开始  
**Blocked by:** [03：Image 2 失败自动兜底](03-Image2失败自动兜底.md)  
**规格覆盖：** A23  
**阅读入口：** [索引与共同约定](README.md)、[功能方案](../../specs/2026-11-10-团队版统一模型调度-功能方案.md)；开始前核对阻塞任务的实际成果与交接记录。

**What to build:** 员工在任务与用量页面看统一模型和本人任务合计，管理员可展开真实通道尝试；清楚区分估算、待核账与实际费用，保留历史口径及人员隔离。

## 范围与边界

- 统一员工与管理员的任务费用、用量明细和模型汇总视图。
- 复用 03 的真实尝试与费用记录，不新增与执行账本不一致的第二套计费。
- 仅对可信模型身份做统一模型投影，历史金额与已冻结价格不按当前配置回写。

## 验收标准

- [ ] 员工看到本人任务的统一模型、合计用量与费用，一次自动兜底不会被展示为员工又主动创建了一份作品。
- [ ] 管理员可从同一任务展开每次真实通道、尝试、价格快照、远端关联与费用核对状态，合计与明细一致。
- [ ] 失败尝试不假定免费；未知费用不显示为已确认零元，混合已核账与估算的任务明确标注费用状态。
- [ ] 模型分项、趋势、任务详情与总计采用一致的任务／尝试计数口径，说明哪些是生成任务数、哪些是通道调用次数。
- [ ] 人员隔离在服务端实现，员工接口不返回其他成员信息或隐藏在页面中的完整通道快照；管理接口继续检查权限。
- [ ] 旧记录保留原始金额和身份，统一展示只依据可信快照映射；无法识别的历史记录明确单列，不按名字猜测或按新价格重算。
- [ ] 第二次尝试、迟到结果、取消后收尾或管理员核对导致费用状态更新时，任务合计及报表一致更新，重复事件不重复计费。
- [ ] 各已接入及后续按共享合同接入的任务来源可被识别；不支持的记录明确说明，不静默漏掉费用。
- [ ] 只展示真实估算与结算数据，不承诺固定统一售价或把两通道成本都计成七牛价格；敏感配置与完整上游请求不进入报表。

## 验证与演示

1. 准备单次成功、失败后成功、两次失败、估算与已核账混合、取消后成功及可信／未知历史记录，核对任务明细、汇总与趋势。

2. 以员工和管理员分别调用接口并查看页面，验证同一任务金额一致、人数隔离、计数口径及核对后的变化。

验证使用隔离数据和模拟供应商。涉及真实付费调用或生产变更时，以用户另行明确授权为准；没有外部证据的结论在交接中明确标为未验证。

## 交接要求

- 记录任务与尝试的统计口径、费用状态合并规则和历史身份映射来源，提供可重放的报表样本。
- 交付已核对的金额示例与仍未掌握的上游计费事实，避免将估算写成确定结算。
- 在下方 Comments 记录实际完成范围、验证证据、改动说明、剩余限制及后续任务需要的合同；满足全部验收项后，将执行进度改为“已完成”。
- 发现超出本任务的新需求时单独记录，保持本任务边界；阻塞任务未完成时先报告缺失成果，不另造一套替代合同。
