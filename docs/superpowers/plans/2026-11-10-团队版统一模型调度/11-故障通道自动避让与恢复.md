# 11：故障通道自动避让与恢复

**状态：** `ready-for-agent`  
**执行进度：** 未开始  
**Blocked by:** [03：Image 2 失败自动兜底](03-Image2失败自动兜底.md)  
**规格覆盖：** A17、A18  
**阅读入口：** [索引与共同约定](README.md)、[功能方案](../../specs/2026-11-10-团队版统一模型调度-功能方案.md)；开始前核对阻塞任务的实际成果与交接记录。

**What to build:** 管理员看到手动启停与系统临时避让的区别；新任务避开持续故障通道，恢复后重新七牛优先，单素材审核失败不触发全通道停用。

## 范围与边界

- 增加共享路由可使用的通道健康状态，并提供管理员可理解的查看与控制界面。
- 区分管理员手动启停和系统临时避让；仅影响未来选路，原任务继续按原通道核对。
- 故障窗口、冷却和恢复策略由本任务给出具体可配置或固定默认方案并记录，遵守规格的行为边界。

## 验收标准

- [ ] 连续可归因的服务故障使相关通道暂时退出新任务候选；有兼容通道时新任务可以直接使用它，不额外等待七牛拥堵计时。
- [ ] 管理员页面能区分手动禁用、系统临时避让和可用状态，并看到脱敏原因、时间及后续恢复安排。
- [ ] 管理员手动关闭的通道不会因自动恢复、重启或健康检查被重新打开；手动设置由服务端权限保护。
- [ ] 单素材审核拒绝、非法用户输入、个人预算或权限问题不使整个通道停用。
- [ ] 故障归因区分具体模型通道、共享网关及公共传输环节，不能把本机代理存活当成全部上游正常，也不能无证据停用所有同供应商模型。
- [ ] 恢复验证通过后通道重新参与新任务选择，遵守七牛优先；并发恢复检查受控，不产生请求风暴。
- [ ] 恢复检查不悄悄新增付费生成；如果以正常待执行任务验证恢复，该任务的授权、预算、池名额和尝试次数照常记录。
- [ ] 运行中或结果未知的尝试继续沿原通道查询及收尾，健康变化不会改写远端身份、释放未知占用或触发重复生成。
- [ ] 定义重启后的健康状态恢复方式；阈值配置、共享状态和管理员操作具有可追溯证据，多 worker 不重复开闭通道。

## 验证与演示

1. 用可控时钟和模拟错误序列演示持续服务故障、单素材审核拒绝、公共网关故障、恢复成功与再次失败。

2. 从管理员手动禁用到自动恢复尝试、重启及员工新任务选路做全链路验证，检查没有额外付费生成。

验证使用隔离数据和模拟供应商。涉及真实付费调用或生产变更时，以用户另行明确授权为准；没有外部证据的结论在交接中明确标为未验证。

## 交接要求

- 记录健康状态机、作用范围、故障证据、阈值及恢复策略，说明如何供各入口共享路由消费。
- 提供管理员演示步骤及已执行验证，标明真实上游尚未验证的判断范围。
- 在下方 Comments 记录实际完成范围、验证证据、改动说明、剩余限制及后续任务需要的合同；满足全部验收项后，将执行进度改为“已完成”。
- 发现超出本任务的新需求时单独记录，保持本任务边界；阻塞任务未完成时先报告缺失成果，不另造一套替代合同。
