## 1. 工具栏怎么被步骤内容复用

项目工作台是**整幅页面**（外壳的紧凑标题已排除 `/projects/[id]`），工具栏由页面自己出，
一条就够，**第 3/4/5 步不要再画第二条**：

```tsx
// app/(workspace)/projects/[id]/page.tsx（07 已实现，08/09 不用改）
<PageToolbar
  role={role}                                  // 'employee' | 'admin'
  title={project.name}
  back={{ href: '/projects', label: '返回' }}
  actions={<>
    <ToolbarButton icon="logs" label="运行日志" onClick={…} />
    <ToolbarButton icon="settings" onClick={…}>项目信息</ToolbarButton>
    <a className="cap" href={`/api/projects/${id}/creative-package`}>导出项目包</a>
  </>}
/>
```

- 工具栏下面是五步分段按钮：`components/workbench/WorkbenchStepNav.tsx`
  的 `<WorkbenchStepNav active onChange />`（`Segmented`，`semantics="tabs"`）。
- 五步的**唯一权威清单**也在那个文件：`WORKBENCH_STEPS`（`scene | storyboard |
  script | video | final-edit`）+ `parseWorkbenchTab` / `getWorkbenchStepLabel`。
  **tab id 与路由不变**，08/09 不要新增 tab。
- 切步骤走 `router.replace('/projects/[id]?tab=…', { scroll: false })`，
  不整页刷新（各步组件状态留在各自 tab 里）。
- 队列（开始/暂停/继续/取消）在分段按钮右侧，由页面统一出；第 1 步的底部状态条
  也自带一份同样的按钮。

| 东西 | 位置 | 说明 |
| --- | --- | --- |
| 第 1 步 | `components/workbench/SceneStep.tsx` | `data-testid="workbench-scene"`、`data-view="compare|grid"` |
| 第 2 步 | `components/workbench/ShotSetStep.tsx` | `data-testid="workbench-storyboard"`；新建分镜组窗口里 `data-testid="shot-pick"` / `set-opening` |
| 上传投放区 | `components/workbench/UploadDrop.tsx` | 拖入 + 多选，落 `role=input` + `usage=scene_seed|shot_source` |
| 纯规则 | `lib/workbench-shots.ts` | 点选顺序 / 全选再取消 / 设为开场 / 版本号 / 左右键下标 / **失败不能标可用** |
| 结果状态 | `resolveShotResultState` + `canMarkShotAvailable` / `canRetryShot` | 09 若在混剪里显示分镜状态，请复用这套口径，别另写 |

**行为红线（已由单测钉住）**：

- 点选顺序 = 镜头顺序，第一张是开场图；「设为开场」只把它移到第一位，其余顺序不变；
- 「全选」再点一次取消全选；素材多于上限时选到上限也算全选状态（否则按钮取消不了）；
- 失败/未出结果的分镜**不能标可用**（`canMarkShotAvailable` 只看 `succeeded`）；
- 改提示词重做**不传 `referenceImageIds`**（传空数组会清掉场景参考图）；
- 删除分镜组必须先确认（`Dialog`，确认前不发 DELETE）。
