# 05：侧栏和头像菜单（团队版外壳）

**状态：** `ready-for-agent`

**What to build：** 团队版去掉顶部的全局顶栏，换成左侧分组侧栏、每页工具栏和头像菜单。员工端分三组，管理员端分五组；「我的任务」「出错的任务」显示数量；入口改用直白的叫法。个人本地版保留原来的顶栏，只换名字和标志。

**Blocked by：** 02、04。

**Parent：** [01 父规格任务](01-林视界面重设计.md)  
**需求依据：** [功能方案](../../specs/2026-11-07-林视界面重设计-功能方案.md)「工作区外壳与导航」；V02。  
**原型对应：** 所有工作页的侧栏和头像菜单。管理员视角在原型的头像菜单里切换。

## 实施边界

- **侧栏：**
  - 顶部是叶子标志和端名：林视创作台或林视控制台。
  - 中间是分组导航，分组、顺序和名字见规格。
  - 「我的任务」「出错的任务」的数量用现有接口取，只算本人能看到的。
  - 底部是头像，点开是头像菜单。
- **头像菜单：** 修改密码、回收站、外观（跟随系统 / 浅色 / 深色）、退出登录，底部一行「关闭窗口不会中断服务器任务」。
- **原顶栏功能的去处：**
  - 客户端需要更新时，侧栏底部出现「修复并更新」提示条，沿用现有的更新入口和诊断上报。
  - 「停止服务」只在个人本地版出现。
  - 「新建项目」放到首页和我的项目的工具栏。
- **每页工具栏：** 用 02 的共用部件。本任务给所有团队版页面接上标题，标题沿用导航名；各页自己的操作按钮由各页的任务补。
- **改名（路由不变）：**
  - 异常中心 → 出错的任务
  - 模型与并发 → 模型与名额
  - 团队生产控制台 → 林视控制台
  - 我的创作空间 → 林视创作台
- 画布开关关闭时，侧栏不显示画布入口。
- 团队版页面不再套全局 980 像素的居中栏，宽度由各页自己决定。混剪页的宽度规则由 09 处理，本任务只保证它不比现在更糟。
- 窄窗口时侧栏怎么收由 15 处理。
- 实现入口见父任务「外壳与导航」一行。

## 验收条件

- [ ] 员工和管理员登录后，侧栏的分组、顺序和名字都和规格一致；画布开关关闭时没有画布入口。
- [ ] 「我的任务」「出错的任务」的数量和对应页面一致，只算本人能看到的。
- [ ] 头像菜单四项都能用；外观三档切换立即生效，并且会保存；退出登录回到登录页。
- [ ] 客户端版本过旧时，侧栏底部出现「修复并更新」，点击后走现有的更新流程。
- [ ] 团队版没有顶部全局顶栏；本地版顶栏正常，并显示新名字。
- [ ] 每个团队版页面的工具栏标题都正确；1536×864 下所有页面不横向滚动（混剪页除外，见 09）。
- [ ] 现有团队验收的浏览器测试通过；在验收工具里加上侧栏、头像菜单和数量的检查，两种内核、浅色深色都通过。

## 可演示结果

员工和管理员分别登录，各自看到分组侧栏和头像菜单，切换外观立即生效。
