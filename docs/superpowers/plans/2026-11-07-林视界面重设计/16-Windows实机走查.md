# 16：Windows 实机走查

**状态：** `ready-for-human`

**What to build：** 在一台员工的 Windows 电脑上（1920×1080、缩放 125%），用最新的内部测试包人工走一遍，确认改版在真实电脑上没问题。

**Blocked by：** 15。

**Parent：** [01 父规格任务](01-林视界面重设计.md)  
**需求依据：** [功能方案](../../specs/2026-11-07-林视界面重设计-功能方案.md) Testing Decisions 的人工验收；V19。

## 走查清单

- [ ] 启动画面、应用图标和窗口标题都是新名字、新标志；登录页正常，首次登录改密码正常。
- [ ] 侧栏分组、数量角标、头像菜单正常；外观三档切换正常。
- [ ] 首页和新建项目正常；新建项目里没有超时、并发、预处理。
- [ ] 五步都走一遍：场景图对照、分镜全选和设为开场、脚本、视频右栏设置和批量检查。
- [ ] 单条精准混剪的操作和改版前一样；导出后点成片能预览，有声音。
- [ ] 批量生产：统一审片操作照旧；导出页预览、上一条/下一条和一键下载全部正常，文件存到了下载目录。
- [ ] 控制台运行总览、全员任务、模型与名额正常。
- [ ] 深色模式下没有刺眼的白块。
- [ ] 把窗口拖到最小，页面照常能用。
- [ ] 字体确实显示为思源黑体和 Inter。
