# 02：外观底座：配色、字体、共用部件

**状态：** `ready-for-agent`

**What to build：** 员工和管理员打开任何页面，都能看到定稿配色（浅色、深色两套）和打包字体（思源黑体＋Inter），深色模式正常。原型里反复出现的部件做成共用件，先用在「修改密码」页上当样板，后面的任务直接拿来用。

**Blocked by：** 无（可以马上开始）。

**Parent：** [01 父规格任务](01-林视界面重设计.md)  
**需求依据：** [功能方案](../../specs/2026-11-07-林视界面重设计-功能方案.md)「外观规范」；V03、V04 的字体部分。  
**原型对应：** 全部屏幕的配色和字体；部件样子看「新建项目」「视频」页的分组列表、分段按钮和标签。

## 实施边界

- **令牌：** 沿用现有按用途命名的令牌（底色、正文、强调色、分隔线、状态色、状态点等），名字不变，只改取值。补上新用途：窗口底、侧栏、预览区底、分段按钮。浅色、深色两套取值见规格。新增颜色只用令牌。
- **外观机制不变：** 根元素上的主题属性、同一个本机存储键、首屏渲染前的初始化脚本、桌面运行壳同步原生控件主题。
- **字体：**
  - 中文用思源黑体，拉丁字母和数字用 Inter，都是 SIL OFL 许可，许可证文件一起放进仓库。
  - 仓库里视频包装用的思源黑体可变字体可以作为切片来源；Inter 要新加入。
  - 中文按 Unicode 区段切成多个小文件，页面用到哪段才下载哪段。
  - 构建时不能联网下载字体，因为公司网络受限。
  - 字体栈依次是 Inter、思源黑体，最后退到微软雅黑和苹方。时长、金额、计数用等宽数字。
  - 字号：正文 13.5px；标签和次要说明不小于 12px；输入框不小于 13px。
- **发布：** 字体文件要能进 standalone 产物和 Windows 免安装包；打包禁入清单和对应守护测试保持不变。
- **共用部件：** 页面工具栏、分组列表行、分段按钮、标签、状态点、空状态、对话框外壳，样子以原型为准。本任务只把修改密码页换成新部件，其余页面在各自的任务里换。
- **不做：** 页面结构调整、侧栏和顶栏改造（05），以及混剪、批量样式里的深色覆盖（09、10）。
- 实现入口见父任务「外观令牌与主题」「字体打包」两行。

## 验收条件

- [ ] 浅色、深色、跟随系统三档切换后，现有页面的颜色来自新令牌；之前保存的外观偏好继续生效。
- [ ] 用浏览器读出页面计算后的字体，确认实际渲染的是思源黑体和 Inter，不只是样式表里写了。
- [ ] 断网环境下也能完成构建。
- [ ] 打开登录页时只下载用到的中文切片，不下载整套字体；测试里给下载的字体文件数量和总大小设上限。
- [ ] standalone 产物和 Windows 免安装包里有字体文件和许可证；打包守护测试通过。
- [ ] 修改密码页用上共用部件，浅色深色、Chromium 和 WebKit 下截图没有错位。
- [ ] 现有浏览器测试全部通过，包括混剪、批量、包装、脚本、画布和团队验收。

## 可演示结果

打开工作台任意页面，切换浅色和深色，配色和字体都是新的；修改密码页已经是新样子。
