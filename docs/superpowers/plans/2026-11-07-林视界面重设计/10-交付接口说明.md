## 3. 你要用的数据已经在 `workspace.cards[]` 里（不用新增查询）

每张卡片（`BatchWorkspaceView['cards'][number]`）已带：

| 字段 | 用途（对应规格 73/74） |
| --- | --- |
| `currentFormalArtifact: { video, cover } \| null` | 有 = 已导出过；`video.id` / `cover.id` 直接拼媒体 URL |
| `exportEligible` | 能不能进「可导出」集合 |
| `exportStatus: 'exported' \| 'rendering' \| 'failed' \| 'not_exported'` | 服务端统一判定，**不要**再从前端任务表自拼 |
| `formalOutdated` | 改过但没重新导出 → 预览要播**上一版正式成片**并写明 |
| `approvable` / `approved` | 审核状态（未通过不能导出） |
| `coverStatus` / `coverTask` | 封面状态与失败重试入口 |
| `fullRenderTask` | 渲染进度（`progress.percent`）与失败原因 |
| `narrationTask` | 配音任务；`status === 'failed'` 时卡片要能「重试配音」 |
| `versionNumber` / `scriptTitle` / `seq` | 卡片标题区 |

媒体 URL 的现有写法（照抄，别自己拼鉴权）：
