## 验收条件

- [x] 三类已有导入资源按源文件、名称、版本、条目数、解析状态和预览列出；管理员无需分别操作库根、修订或条目。
- [x] 上传／导入只形成待发布版本；解析失败、取消或发布失败均不替换当前团队版本，员工不能提前读取未发布私人内容。
- [x] 发布操作使团队当前版本与其必要修订、条目、素材权限一致生效；不能只公开根对象即返回成功。
- [x] 员工在推荐、搜索、详情及创建新任务时解析到同一个团队当前版本；个人空库或其他个人库不遮住团队版本。
- [x] 已上传的目标版本可以从列表选中发布；设置上传和公共页已有直接上传共用资源状态与当前版本，不重复存储或产生两个当前版本。
- [x] 相同发布请求幂等；切换到已存在但非当前的版本时确实完成激活，不能仅因内容存在就误报完成。
- [x] 并发发布检测基准版本变化，提示刷新确认；前端选择的版本与提交时版本变化时不得静默换成其他内容。
- [x] 旧任务继续读取已冻结的修订和条目，重试／恢复不因发布新版本失败；私人未发布版本不随历史兼容被公开。
- [x] 员工不能导入、修改或发布公共版本；无团队版本时显示真实空状态，读请求不顺手为员工创建遮挡公共库的空库。
- [x] 三类资源分别通过“设置上传→候选预览→发布→员工实际使用”的接口和页面验收；补充并发冲突、失败、旧任务快照及跨账号访问回归。
