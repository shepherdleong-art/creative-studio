# 12：前端执行升级与失败恢复

**状态：** `ready-for-agent`

**What to build：** 管理员选择已校验升级包并确认后，系统自动进入维护、备份、切换、迁移和自检；页面重连后可查看同一作业结果，失败时清楚说明实际版本和恢复状态。

**Blocked by：** [10 前端立即备份与维护作业记录](10-前端立即备份与维护作业记录.md)、[11 网页上传升级包与版本校验](11-网页上传升级包与版本校验.md)。

**Parent：** [01 父规格任务](01-团队管理与运维体验完善.md)  
**需求依据：** [功能方案](../../specs/2026-11-06-团队管理与运维体验完善-功能方案.md)，前端升级；A12、A13。

## 实施边界

复用 10 的独立执行器、作业／审计／互斥与备份，消费 11 的受管候选；复用现有受控发布状态机和停机链路，不在会被停掉的普通请求中等待整个升级。

定位见父任务“维护与清理”。本票只在隔离测试服务器执行真实切换，不升级当前生产服务。

## 验收条件

- [ ] 页面展示当前／目标版本和影响，经管理员确认才启动；开始时重新核验候选内容和当前版本，防止准备后发生漂移。
- [ ] 自动完成维护准入、在途排空／证据保存、受控停机、经验证升级前备份、切换、迁移、自检和满足条件后的恢复生产。
- [ ] 备份或必要校验失败时不越过阶段切换；历史步骤、作业身份、真实管理员与结果持久保存。
- [ ] 只停止经核验归属的工作台实例／进程，保留受控服务边界；维护执行器不随应用停止，服务启动后继续同一作业。
- [ ] 页面断开、刷新或关闭客户端不取消升级；重新连接能显示实际阶段和版本，不因 HTTP 失败诱导用户重复提交。
- [ ] 在途和受理不明请求保留证据与占额，不因重启或重试升级无依据重发付费请求。
- [ ] 数据、外部密钥和部署配置不被包覆盖；迁移只追加并走既有保护，应用启动和健康检查不能用“进程存在”代替。
- [ ] 故障按阶段给出可继续处理的状态；仅在代码／数据兼容条件满足时回退，不兼容时保留维护状态和明确处理原因。
- [ ] 重复提交幂等，冲突升级／还原／清理受公共互斥约束；越权或任意路径／命令被拒绝。
- [ ] 维护接口及状态机故障注入测试通过，覆盖备份失败、停机失败、迁移／自检失败、执行器重启和页面重连。
- [ ] 在隔离 Windows 测试服务器实际从网页上传包并完成升级，核对备份、版本、服务状态与任务恢复；不能用模拟执行器宣称实机完成。

## 可演示结果

管理员经网页升级测试服务器，应用停止时页面断开，重新连接可见作业成功及新版本；另演示受控失败并显示真实恢复结果。
