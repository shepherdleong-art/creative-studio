# 14：无用文件清理预览与执行

**状态：** `wontfix`

**What to build：** 管理员在维护页扫描无用文件，先查看分类、数量和预计释放空间，确认后由受控作业清理，并显示实际删除、跳过与失败结果。

**Blocked by：** [10 前端立即备份与维护作业记录](10-前端立即备份与维护作业记录.md)。

**Parent：** [01 父规格任务](01-团队管理与运维体验完善.md)  
**需求依据：** [功能方案](../../specs/2026-11-06-团队管理与运维体验完善-功能方案.md)，无用文件清理；A16，以及 A13 的权限／互斥部分。

## 实施边界

复用既有回收站、跨模块引用和备份 pin 保护，接入 10 的维护作业身份、审计和互斥，新增统一批量预览与执行。定位见父任务“维护与清理”。

## 验收条件

- [x] 扫描范围仅限失败任务临时文件、过期缓存、回收站已删除且无引用产物；用户不输入任意文件路径。
- [x] 展示分类、可清理数量、预计可释放空间和不可清理原因；显示预估口径，重复引用的物理文件不重复计算释放量。
- [x] 管理员明确确认后才删除；预览结果绑定受管候选及状态，执行前重新核验，不能盲用旧扫描结果。
- [x] 在途／可恢复任务、历史版本、备份 pin、还原核查和其他有效引用阻止删除；不用文件名或修改时间独自判定无用。
- [x] 正常项目原素材、当前成片及历史正式产物均保留；备份、费用账本、执行证据和诊断审计不当成缓存清理。
- [x] 备份或还原后保留的数据根受保护，不能因不再活动就被列为无用；并发维护受统一互斥约束。
- [x] 执行结果报告实际删除、空间释放、跳过和失败；刷新或断开页面后仍可查同一作业，重复请求和部分失败重试安全。
- [x] 非管理员、跨范围资源或路径替换请求被拒绝，审计记录真实发起人；既有回收站恢复／永久清理不回归。
- [x] 隔离测试覆盖预览后新增引用、备份保护、在途任务、部分删除失败、共享文件和越权；通过页面完整演示扫描、确认和结果。

## Comments

- 2026-11-06：实现与隔离验证已完成，按本地 issue tracker 的关闭约定标记 `wontfix`；未清理生产数据，非放弃需求或生产上线。

## Answer

- 实现：只扫描失败任务临时文件、过期缓存、回收站无引用产物；预览按内容指纹合并共享文件估算，指纹缺失退回受管路径，执行前逐项复核。确认绑定管理员、数据根与候选；在途、历史、备份 pin、还原核查和有效引用均保护。结果区分实际删除、跳过与失败，部分失败可安全重试，浏览器不输入任意路径。
- 验证：`team-maintenance-cleanup.test.ts`、`team-lifecycle-cleanup.test.ts`、`team-maintenance-routes.test.ts` 业务断言通过；覆盖跨根共享文件不重复计数、不同文件不误去重、预览新增引用、同名替换拒绝、跨根拒绝、部分失败与恢复核查。真实 Chromium 完成备份→扫描→确认→worker 删除及冲突 409，浅深主题通过，零付费调用。Windows 临时 SQLite 清理 `EBUSY` 属单独环境限制，未声称全量实机验收。

## 可演示结果

测试数据含可删临时文件、无引用回收站文件和有备份引用的产物；预览能解释保护原因，确认后只删除前两类。扫描后新加引用的候选在执行时被跳过。
