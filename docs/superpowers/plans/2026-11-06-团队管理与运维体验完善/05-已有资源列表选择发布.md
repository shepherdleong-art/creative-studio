# 05：已有资源列表选择发布

**状态：** `ready-for-agent`

**What to build：** 管理员在设置创建／上传已有非版本库资源后，在公共资源页按名称和预览选中发布，员工随后可以实际使用；全程不查找或输入资源 ID。

**Blocked by：** 无（获得实施授权后可开始）。

**Parent：** [01 父规格任务](01-团队管理与运维体验完善.md)  
**需求依据：** [功能方案](../../specs/2026-11-06-团队管理与运维体验完善-功能方案.md)，公共资源上传与发布；A07、A08 的非版本库部分。

## 实施边界

以视频提示词模板作为首条完整路径，并覆盖当前已支持发布的非版本库资源（如标题预设、LUT）。建立可扩展的受权限控制候选列表和发布交互。BGM 已有上传、试听、发布能力复用，不重做。

知识库与模板库的库／修订／条目原子发布由 06 接入本列表；本票不能以单独发布库根的方式冒充该能力。代码定位见父任务“公共资源”。

## 验收条件

- [ ] 设置中创建／上传一次的真实受管资源自动出现在候选列表，无需第二次上传或复制内容。
- [ ] 展示资源类型、名称、适用预览、源文件或其他可识别信息，以及待发布／已发布状态；内部身份由系统传递。
- [ ] 未发布资源不因出现在候选列表而对员工公开；管理员显式点击发布后，员工能在实际制作入口读取和选用。
- [ ] 管理员看不到无权处理的私人资源；员工不能发布，直接伪造资源身份或跨归属请求也被拒绝。
- [ ] 重复提交幂等；失败保留原状态并显示可理解原因，不显示假成功；删除或失效资源不会留作可发布假候选。
- [ ] 空列表引导到相应上传／创建入口；已接入资源不再要求手填 ID，不把文件名作为资源身份。
- [ ] BGM 既有上传、试听、发布不退化；尚需 06 完成的版本库类型不通过旧库根发布入口绕过完整版本检查。
- [ ] 隔离浏览器／接口验收走通管理员创建、选择发布与员工制作使用，并覆盖越权、重复、失败及浅深主题。

## 可演示结果

管理员在设置创建一个测试视频提示词模板，返回公共资源页按名称预览并发布；员工刷新制作页面即可选择，同内容未重复上传。
