# 08：客户端错误自动上报与断网补报

**状态：** `ready-for-agent`

**What to build：** 工作台轻客户端的界面、上传、下载和更新失败自动进入错误中心；断网时有界保存脱敏事件，恢复连接后补报，用户不必编写错误码。

**Blocked by：** 无（获得实施授权后可开始）。

**Parent：** [01 父规格任务](01-团队管理与运维体验完善.md)  
**需求依据：** [功能方案](../../specs/2026-11-06-团队管理与运维体验完善-功能方案.md)，错误中心与自动上报；A09 的客户端部分、A10。

## 实施边界

已有客户端诊断上报和错误列表可用于本票完整验收，不以 07 为前置。复用诊断存储和归属验证，新增必要阶段时兼容原记录，与 07 协调公共契约。定位见父任务“自动诊断”，同时覆盖独立更新助手的失败回传。

## 验收条件

- [ ] 页面运行异常、未处理异步异常及实际上传／下载终止失败自动捕获；取消、正常暂停、普通表单校验不误报。
- [ ] 更新检查、下载、校验、安装或恢复失败能保留并关联到客户端事件，不仅覆盖更新助手启动失败。
- [ ] 每个事件持有稳定身份并记录可用阶段、版本、任务／传输上下文；服务器重新验证人员和任务归属。
- [ ] 离线事件按明确容量／保留策略有界保存，联网且认证有效时补报；上报成功才确认处理，重试不产生重复记录。
- [ ] 换账号不把旧账号事件归给新账号；缺少可信身份的事件不得强行绑定为当前用户的业务错误。
- [ ] 同一异常造成的界面、传输和重试通知按可验证事件身份去重；上报失败不递归上报、不无限循环或阻塞上传下载。
- [ ] 本地暂存和服务器诊断均脱敏，不保存素材原文、请求体、会话凭据或签名 URL。
- [ ] 员工在错误中心能看到自己的自动事件和编号；其他员工无法查询或下载该诊断，管理员可以授权排查。
- [ ] 在隔离测试中分别走通界面、传输和更新故障；真实客户端验证断网、退出重开后待报事件仍可补报，并输出有界、去重和账号隔离证据。

## 可演示结果

断开测试客户端网络并触发下载失败，再恢复连接；错误中心出现一条关联正确的错误，重复补报不新增副本，换账号也不串记录。
