## 实施边界

复用团队任务查询和公共显示标签。先核对实际基线，保留已经上线的成员分组与筛选。涉及实现入口见父任务“任务名称与模型”，不重建业务任务聚合看板或计费统计。

## 验收条件

- [x] 首页和完整任务页展示一致的中文任务名称、项目／画布名称、人员、状态和制作步骤；已知动态脚本步骤准确区分生成、润色及标题修复。
- [x] 图片、视频、脚本、画布及可用媒体调用读取对应执行时快照展示供应商和模型；修改当前供应商配置后历史显示不变化。
- [x] 多模型或更换模型的重试可按实际调用追溯；等待中配置不标为已调用；缺失、尚未确定和不适用分别说明，不猜测供应商内部路由。
- [x] 解析内部步骤时核验数字含义；未知步骤显示通用中文说明，原始键留在详情；完整 UUID 不作主标题。
- [x] 按发起人分组、成员／状态筛选、搜索、刷新、折叠及复制排查信息仍可用；当前结果数不冒充全历史数。
- [x] 子步骤、任务尝试与制作份数、确定扣费次数不混淆；详情继续保留执行记录、输入与客户端／服务端版本。
- [x] 员工只看到获准任务；接口只投影安全字段，不返回完整供应商快照或凭据。
- [x] 在隔离 HTTP／浏览器验收中验证实际展示、历史模型和多角色隔离，覆盖浅深主题；同类任务旧数据缺少字段时仍可正常打开。

## 可演示结果

打开同一脚本任务的首页摘要和完整列表，查看中文子步骤与模型；修改测试供应商配置再查看历史任务，历史模型保持原值，展开详情可复制原始编号。
