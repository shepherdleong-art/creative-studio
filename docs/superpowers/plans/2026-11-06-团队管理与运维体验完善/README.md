## 已定边界

- 任务显示实际模型及中文步骤；保留排查能力与现有成员分组。
- 新老成员默认继承按实际任务需求分配的自动并发，可手动配置及设置个人例外。
- 资源只上传一次，选中后显式发布；错误自动捕获，无需人工编写技术码。
- 前端提供备份、上传升级包并升级、整套还原和受保护的无用文件清理。
- 记住登录 30 天，并实际修复轻客户端关闭重开丢会话。
- 隔离自动化＋真实轻客户端＋测试服务器验收，不动生产数据或付费调用。
