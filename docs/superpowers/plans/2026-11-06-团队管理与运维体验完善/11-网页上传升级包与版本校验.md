# 11：网页上传升级包与版本校验

**状态：** `ready-for-agent`

**What to build：** 管理员在网页选择服务器升级包上传，看到当前／目标版本、校验进度、兼容性和准备结果；不用终端放包，准备过程不改变当前服务。

**Blocked by：** 无（获得实施授权后可开始）。

**Parent：** [01 父规格任务](01-团队管理与运维体验完善.md)  
**需求依据：** [功能方案](../../specs/2026-11-06-团队管理与运维体验完善-功能方案.md)，升级包选择与校验；A12 的包准备部分、A13 的输入边界。

## 实施边界

独立完成“选择→上传→校验→受管候选版本”的可演示流程；实际升级由 12 消费候选结果。包准备不需要等待 10，但本票必须有自己的持久状态与失败结果，后续不能把临时浏览器状态当作升级依据。

复用现有服务器发布清单、包校验及可信分发约束，定位见父任务“维护与清理”；不新建联网自动更新系统。

## 验收条件

- [ ] 管理员可从网页选择本机发布包，显示上传和校验状态，无需填服务器路径或先用终端复制。
- [ ] 仅接受受控服务器发布包；完整清单、内容哈希、发布身份、运行时／数据兼容及现有信任要求均通过后才标为可用于升级。
- [ ] 安全处理包结构，拒绝目录穿越、链接、意外嵌套、超出资源限制或禁入内容；不能以可解压替代可运行校验。
- [ ] 显示可信当前／目标版本及兼容说明；未验证和不兼容候选不显示可执行升级的成功状态。
- [ ] 候选内容保存在受管位置并以稳定身份引用；校验身份与内容绑定，后续无法用同 ID 偷换包，12 执行时仍需复核。
- [ ] 重复上传、上传中断、空间不足和校验失败有可理解结果，不污染有效候选；失败残留可安全处理。
- [ ] 准备过程不停止服务、不切版本、不覆盖业务数据、部署配置或秘密；已上传候选在页面刷新后仍可查。
- [ ] 非管理员或伪造候选请求被拒绝；浏览器不获得服务执行凭据或任意磁盘读写能力。
- [ ] 隔离 HTTP／浏览器测试覆盖有效包、坏包、越界路径、中断及权限；提供后续升级可用的候选身份和证据。

## 可演示结果

从网页上传一个有效测试发布包并看到可验证目标版本，再上传损坏包被拒绝；两次操作后服务器运行版本均未改变。
