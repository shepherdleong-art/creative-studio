# 01 分镜版本标记

**状态：** `ready-for-human`

**依赖：** 无。  
**规格：** [功能方案](../../specs/2026-11-11-工作台版本标记与团队列表易用性-功能方案.md)第 3、8 节。

## 目标

用户扫一眼缩略图就知道哪些分镜有多个版本、现在使用第几版；查看大图时明确切版本会影响后续制作。

## 修改范围

| 文件 | 工作 |
| --- | --- |
| `components/workbench/ShotSetStep.tsx` | 对照缩略图、全部网格、大图版本条与按钮提示 |
| `lib/workbench-shots.ts` | 必要时抽取候选、当前版本与标签的纯计算，保留旧数据回退 |
| `components/workbench/workbench.module.css` | 版本标签样式，使用既有令牌 |
| `scripts/workbench-shots.test.ts` | 补实际版本计算边界 |
| `scripts/workbench-scene-shots.playwright.test.mjs` | 补多版、切旧版、刷新和界面截图 |

只读核实 `app/api/shot-sets/[id]/route.ts` 的选用持久化契约；本票不需要迁移或改变候选生成/编号顺序。先读外观参考。

## 实现步骤

1. 找到当前候选排序、缺图过滤及 `latestGeneratedImageId` 回退；让网格、缩略图、大图共用相同规则。完成条件：三处针对同一分镜给出一致版本号。
2. 按规格增加 `V1/V3` 标签及“当前使用 / 共 N 版 / 最新”提示。完成条件：多版与单版有文字及视觉区别，状态点含义不变。
3. 明确箭头是“使用上一版 / 使用下一版”，沿用既有 PATCH 和错误处理。完成条件：刷新后显示服务端选用版本；快速点击/请求失败不产生虚假选中。

## 验收标准

- [ ] 无结果不出现 V0；兼容旧结果但无 candidates 时为 V1；仅有一版时不出现可用的切版按钮。
- [ ] 三个有效候选选 V3：缩略图与网格显示 V3，大图显示“当前使用 V3 · 共 3 版”。
- [ ] 切回 V1：大图另示“最新 V3”，刷新后仍为 V1；切换请求携带正确 `selectedImageAssetId`。
- [ ] 候选缺少可展示图片、旧数据选用 ID 不在候选数组时，标签与实际展示图片采用相同回退，不越界或给出虚构的最新版。
- [ ] PATCH 返回错误时保留原选用图片和版本，展示可理解错误；切换成功没有额外生成请求。
- [ ] 绿点、失败点、选中边框、“开场”和审片标记仍可区分，版本色不占用失败语义。
- [ ] 个人/团队版、对照/全部视图、浅深主题均成立；长标签不挤坏缩略图、底部操作栏或图片比例。
- [ ] 键盘可用；屏幕阅读器名称包含分镜编号、当前版本、总版本。
