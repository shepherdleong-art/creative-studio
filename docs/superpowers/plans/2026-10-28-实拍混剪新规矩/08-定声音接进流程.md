# 08：定声音接进流程

**要做什么：** 新批次每条成片的步骤改成：选片 → 识别原声（口播，复用）→ AI 判断 → 定声音 → 配音 → 排时间（任务 09）。定声音调用排片计算，取代旧的「AI 切分整段文案」声音编排。配音只给要配音的行合成，每行一段。去掉「等原声」「待人工」这类停下等人的状态。每一步只有两种结果：做好了，或者失败（带原因、能重试）。

**依据：** 确认单（`docs/superpowers/specs/2026-10-28-实拍混剪新规矩-确认单.md`）第 4 节、第 1 节「定声音」，用户故事 17～29、50。

**要先做完：** 03、04、06、07

**状态：** `ready-for-agent`

- [ ] 阶段测试（内存数据库，假的识别、AI、配音）：缺号不停；文案没写口播台词也不停；AI 出错时这条成片失败、带原因、能重试，同批其他成片照常；只给要配音的行合成，每行一段
- [ ] 同样的文字、同样的声音，配音直接复用（现有能力）
- [ ] 声音方式只认「原声＋配音」「统一配音」，默认「原声＋配音」。新批次遇到「只用原声」时直接报错并说明原因；这个选项在任务 14 去掉
- [ ] 用 ps889 新建一个批次（默认「原声＋配音」）：300 条都走过定声音和配音，没有一条停下等人。失败的只能是识别、AI、配音接口真出错，并写明原因、能重试
- [ ] 排时间在任务 09 接上。在那之前，新批次停在配音之后，不走旧的时间轴；这个批次留给任务 09 接着跑
- [ ] 新批次的结果标新的算法版本；10-26 的旧批次照旧版本读，照常能打开看
