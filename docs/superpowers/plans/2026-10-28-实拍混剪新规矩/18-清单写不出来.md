# 18：清单.csv 写不出来（新规矩成片没有音频映射记录）

**要做什么：** 新规矩（按排时间出片）的成片导出后，`成片/清单.csv` 要能写出来，内容和文件对得上。
现在整份清单写不出来：`lib/live-mixcut/formula/export-manifest.ts` 的 `captureFormulaManifestItem`
按旧时间轴去找「文案与声音分配记录」——它用 `basis.timelineStageId` 去 join
`live_mixcut_formula_timeline_stages` + `live_mixcut_formula_audio_mapping_results`；
新规矩成片的 `basis.timelineStageId` 其实是排时间阶段 id（见 `lib/live-mixcut/formula/schedule-output.ts`），
join 不到，于是抛「成片缺少对应版本的文案与声音分配记录」，路由把错误写进日志、不落文件。

**要做的事：**

- 让清单生成器按来源分两条路：旧时间轴走原来的音频映射；排时间来源改用排时间结果里已有的
  `timeline.clips` / `timeline.sounds` / `timeline.words` / `timeline.marks` 生成同样的记录。
- 清单里该有的字段（每个镜头的取用区间、来源码、替换原因、声音来源、逐字时间、审片标记）一个都不能少。
- 写不出清单时不要只吞进日志：导出接口要把失败原因带回去，让用户看得见。
