# 05 · 视频运镜的「我的常用」

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

员工从视频制作页自由写运镜提示词，也能选公共预设后任意改写。满意的全文可以保存进本人账号的「我的常用」，在其他项目继续选择、编辑和使用。以视频运镜跑通第一条完整的个人保存与取用流程，供场景图和分镜沿用。

## 验收标准

- [ ] 在项目 A 分别试用空白手写和改写公共预设，均能直接提交视频任务。任务使用员工输入的完整文字，以及本人选定的已开放模型和受支持时长。
- [ ] 员工能在普通制作界面保存、选用和更新自己的常用词。关闭后以同一账号重开，在项目 B 能取用已保存的全文。
- [ ] 用公共运镜起稿并另存后，公共库展示管理员发布的原文，员工的改写保存在个人常用中。
- [ ] 员工乙在项目中看不到甲的私有词，也无法凭直接请求读取或改写甲的私有条目。甲仍能在自己的两个项目读取、更新该条目。
