# 03 · 从 Excel 发布到爆文改写

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

IT 通过现有 Excel 导入、预览和发布流程维护爆文模板。员工从详情页提取或复用项目卖点，选取已发布模板进行爆文改写，可换模板再生成、手改正文并保存为项目脚本版本。

## 验收标准

- [ ] 管理员首次导入工作簿，预览后发布，员工可选用该版本。管理员更新并发布后，新创作可选用新版，既有项目脚本和批次脚本快照仍可读取。
- [ ] 使用普通员工会话直接尝试导入、发布或变更公共模板时，服务端拒绝写入，公共库内容一致。
- [ ] 首次从详情页提取卖点和再次复用现有卖点均可完成。两条路径都能挑选爆文模板、生成脚本文案，且员工能编辑并保存一处可辨认的文字修改。
- [ ] 首次生成、换模板、从结果页再生成，以及打开带有旧模式记录的项目后发起的新生成，都只执行爆文模板改写。旧客户端参数或缺省值不能新开「多方向生成」或「痛点解决型 · 15秒」任务。
- [ ] 单条精准混剪和批量生产在已有的项目脚本选择入口均能读到保存后的文字。人工输入或导入已有文字无需启动 AI 写脚本任务。
