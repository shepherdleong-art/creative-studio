# 02 · 团队 Demo 启动与入口裁剪

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

IT 能在本机以团队模式启动演示工作台，用管理员和员工账号分别登录。员工从常规项目进入制作流程，首页收起创作画布和实拍混剪，项目内仍可导入自己的视频做混剪。

## 验收标准

- [ ] 按演示启动方式打开本机浏览器，服务监听回环地址并使用演示数据根。实际登录后，管理员和员工分别进入各自的工作台。
- [ ] Demo 显式关闭创作画布。检查两种角色的导航和首页，直接访问原画布页面、请求创建画布或启动画布任务均不可用，画布执行器未启动。
- [ ] 首页移除「实拍混剪」卡片和对应的“开发中”入口。本地实拍重组仍受团队服务现有策略限制。
- [ ] 员工打开常规项目，能进入场景图、分镜、脚本、视频和混剪页签。单条精准混剪和批量生产都可到达，且均可找到普通视频导入入口。
- [ ] 记录可复现的团队模式启动条件和演示开关。脚本工作室与批量生产可用，真实脚本调度沿用演示环境的显式启用方式。
