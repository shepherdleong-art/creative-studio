# 08 · 批量生产导入到逐条出片

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

PM 从项目素材库选定批次素材池，带入项目脚本或自带文字，自定每份批次脚本的生成份数。用现有批量生产工作区准备、审片和导出，逐条调整镜头、包装与贴纸。

## 验收标准

- [ ] 在批量生产入口逐一试选「模块 4 素材或导入视频」与「项目脚本或自带文案」的四种搭配。员工可粘贴或导入已有文字脚本。
- [ ] 在没有生成视频或 AI 脚本记录的项目中导入视频和文字，创建批次，确认素材池、批次脚本及各自的生成份数，即可预览并正式导出。
- [ ] 设定份数使同一批次至少产生两条成片。成片采用批次启动时确认的脚本快照，能够分别审片并选用现有四套包装。
- [ ] 记下第一条的预览。在第二条更换一个可辨认的镜头，调整包装文字并添加一张指定时段的贴纸，保存并重新打开，两条成片分别呈现各自版本。
- [ ] 实际播放两条导出的 MP4。第一条与自己的原预览一致，第二条在指定时段显示改过的镜头和贴纸，包装与自己的预览一致。启用配音或字幕时，逐条核对对应文字。
