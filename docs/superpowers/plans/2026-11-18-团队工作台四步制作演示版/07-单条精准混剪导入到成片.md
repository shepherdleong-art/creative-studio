# 07 · 单条精准混剪导入到成片

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

PM 在一个分镜组内独立选择视频和文案。可以使用项目生成的视频和已有项目脚本，也可以导入自己的视频和脚本文案，文案可直接输入或粘贴全文。通过现有单条精准混剪完成预览、包装、贴纸和正式导出，修正妨碍这一流程的入口或空状态。

## 验收标准

- [ ] 在普通制作界面逐一试选「模块 4 素材或导入视频」与「项目脚本或自带文案」的四种搭配。可用已有的爆文改写项目脚本独立验证本票。
- [ ] 建立一个没有生成视频或 AI 脚本记录的项目并选定分镜组。入口能指引导入自己的视频、带入自己的文字，素材归属当前分镜组，能据此预览并正式出片。
- [ ] 选择已保存的项目脚本版本或编辑本次自带文案，两者均采用用户最后选定的文字。启用配音或字幕时，成片使用这份文字。
- [ ] 四套现有包装可选。挑一套修改标题或卖点文字，调整一张贴纸的位置、大小和出现时段，保存后再次打开可看到这些编辑。
- [ ] 下载并实际播放正式 MP4，核对所选视频、包装文字及贴纸的位置，分别检查贴纸出现前、出现期间和结束后的画面与预览一致。
