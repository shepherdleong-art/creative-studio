# 04 · 管理员一键查看用户视角

**状态：** `resolved`

**Blocked by:** 无（可立即开始）

**上级任务：** [01 · 规格与实施入口](01-规格与实施入口.md)

## 交付行为

管理员发布公共资源后，能在本人的登录会话里一键进入用户视角，打开自己的项目试用员工界面，再一键回到管理界面。真实员工只进入制作界面。

## 验收标准

- [ ] 管理员一键进入用户视角并一键返回。切换过程中能辨认当前视角，全程使用原管理员账号和会话。
- [ ] 在用户视角打开实际项目，导航和制作入口与员工体验一致。使用公共预设及本人资源，创建或编辑的内容归当前账号。
- [ ] 返回管理界面后可继续使用原有管理功能，包括查看或维护已发布的公共资源。
- [ ] 以真实员工账号登录，界面不提供视角切换。即使直接发出管理请求，也无法取得管理员权限、发布爆文 Excel、修改公共提示词或供应商配置。
