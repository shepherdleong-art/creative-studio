## 交付行为

把各票集成到现有仓库的独立 Demo 分支，按 IT 首次接手的方式在本机启动。用同一个商品跑通生图、生视频、爆文模板改写，以及从两种混剪进入正式 MP4 的交接。PM 能用自己的素材按相同步骤复验。

## 验收标准

- [ ] 从待交付提交按启动说明进入本机团队工作台，验证管理员与员工入口、受限配置写入、管理员视角往返，以及跨项目取用个人常用词。确认创作画布关闭、实拍入口移除。
- [ ] 在已配置并获准使用模型的演示环境，管理员导入并发布业务提供的爆文 Excel。员工为同一商品自选画幅、可用模型和视频时长，完成至少一次生图、生视频和爆文改写，改一句可辨认的脚本文字并保存。
- [ ] 单条精准混剪和批量生产分别采用这份已保存的项目脚本与项目视频，设置批量生成份数，打开实际导出的 MP4，核对镜头、脚本文字、包装与贴纸。启用配音或字幕时核对改过的句子。
- [ ] 汇集 07 和 08 中自带文字与视频的导出证据，以及同批仅修改第二条成片的对照结果。记录主流程检查和实际成片验收各自覆盖的范围。
- [ ] 把已验收的 Demo 实现推送至同仓库独立分支。交给 IT 的说明写明分支名、可复现的提交号、本机启动条件、演示开关和 PM 复验步骤。业务 Excel 另行交接，真实模型凭据在演示环境配置。
