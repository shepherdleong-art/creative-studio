## 怎么做

1. **补交完成记录：** 各任务单里还有没提交的完成记录，先提交。只提交 `docs/superpowers/plans/2026-10-30-实拍混剪移出工作台/` 下面的文件。
2. **跑检查：** 跑上面前五项。任何一项不过就停下来报告，不推送。附录 A 用 `--out $TMPDIR/cs-removal/07.txt`。
3. **确认远端没有新提交：** 先 `git fetch origin`，再看 `git rev-list --count main..origin/main`，应该是 `0`。不是 0 就停下来报告，不要合并，不要 force。
4. **推送：**

   ```
   git push origin main
   git push origin before-live-mixcut-removal
   ```

5. **清失效的工作区记录：** `git worktree prune`。2026-10-30 有两条失效记录，目录都已经不存在：
   - `/Users/liangpeijian/for-cc/live-mixcut`
   - 一个 `/private/tmp/…/scratchpad/wt-head`

   这条命令只清目录已经不存在的记录，其他工作区不受影响。
6. **删旧分支**（先做第 5 步：旧分支还挂在失效的工作区记录上，不清记录就删不掉）：
   - **本机：** `git branch -d live-action-formula-mixcut`。它的提交已经在 `main` 里，`-d` 能删。删不掉就停下来报告，不要用 `-D`。
   - **GitHub：** `git push origin --delete codex/live-action-formula-mixcut`。它的内容已经在 `main` 里，2026-10-30 核对过。
7. **最后核对：** 跑 `git status --short`，确认用户没提交的改动都还在。

## 不要做

- 检查没全过，不推送。
- 不 force push，不合并远端的新提交。
- 不删别的分支和工作区。
