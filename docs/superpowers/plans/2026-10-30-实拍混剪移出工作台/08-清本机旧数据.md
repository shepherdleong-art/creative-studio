## 4. 删之前查引用


## 5. 删表、压缩

2026-10-30 时实拍混剪有 3 个视图、68 张表。另有 152 个索引、84 个触发器，会随表一起删掉。

1. **先生成删除语句：** 视图在前，表在后。

   ```
   sqlite3 data/workbench.db "SELECT 'DROP VIEW IF EXISTS \"' || name || '\";' FROM sqlite_master WHERE type='view' AND name GLOB 'live_mixcut_*';" > $TMPDIR/cs-removal/drop.sql
   sqlite3 data/workbench.db "SELECT 'DROP TABLE IF EXISTS \"' || name || '\";' FROM sqlite_master WHERE type='table' AND name GLOB 'live_mixcut_*';" >> $TMPDIR/cs-removal/drop.sql
   wc -l < $TMPDIR/cs-removal/drop.sql
   ```

   2026-10-30 应该是 71 行。数量不一样就停下来报告。
2. **执行删除：** 表之间有外键，所以删的时候临时关掉外键检查，删完再检查。

   ```
   { echo "PRAGMA foreign_keys=OFF;"; echo "BEGIN;"; cat $TMPDIR/cs-removal/drop.sql; echo "COMMIT;"; } | sqlite3 data/workbench.db
   ```

3. **压缩并检查：**

   ```
   sqlite3 data/workbench.db "VACUUM;"
   sqlite3 data/workbench.db "PRAGMA wal_checkpoint(TRUNCATE);"
   sqlite3 data/workbench.db "PRAGMA integrity_check;"
   sqlite3 data/workbench.db "PRAGMA foreign_key_check;"
   sqlite3 data/workbench.db "SELECT COUNT(*) FROM sqlite_master WHERE name GLOB '*live_mixcut*' OR tbl_name GLOB 'live_mixcut_*';"
   ls -lh data/workbench.db
   ```

   结果要求：
   - 完整性检查必须是 `ok`；
   - 外键检查必须没有输出；
   - 最后的计数必须是 `0`；
   - 数据库文件应该在 24 MB 左右。
