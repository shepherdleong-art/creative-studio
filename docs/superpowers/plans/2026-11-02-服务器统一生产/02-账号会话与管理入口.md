# 02 账号会话与管理入口

**状态：** `ready-for-human`
**依赖：** [01 运行模式与共享迁移](01-运行模式与共享迁移.md)  
**目标：** 交付工号登录、两类角色、会话撤销、一次性凭据与管理员恢复。

## 动手前

阅读 [技术方案](../../specs/2026-11-02-服务器统一生产-技术方案.md) 中对应章节与仓库 AGENTS.md；改动具体模块前读取其 docs/reference 文档。先核实依赖任务的完成证据，再将状态调整为可实施。本任务单描述待做工作，不代表功能已存在。

## 改动范围

拟新增 `lib/team-service/auth/`、`app/api/team/auth/`、`app/api/team/users/`、`app/team/login/`、管理员账号页和受控本机初始化命令；修改 `app/layout.tsx`、`components/Header.tsx` 的 server 状态。

## 实施步骤

1. 按技术方案建立用户和 session 表，文本工号唯一且保留前导零；scrypt 参数、盐和哈希持久化，令牌仅存哈希。
2. 实现登录/首次改密/退出/重置/停用/角色检查、30 天绝对会话期限；写操作 origin+CSRF，登录尝试限流和有界 KDF 并发。
3. 本机初始化首个管理员；最后可用管理员保护；初始与重置凭据一次性且不进日志，重置/停用使既有会话失效。
4. 定义 AuthPrincipal 与受控内部任务主体，运行中任务不依赖请求 cookie；停止新任务与收取既有结果由任务 06 处理。
5. 账号启用状态与“暂停新的付费生成”分开建模；后者由任务 06 管理，不撤销会话、编辑或下载权限。新账号费用／并发初始策略与任务 06 对齐，管理入口在任务 13 接入。

## 完成标准

- 普通用户无法建号、改角色、读凭据或发起维护；重置/停用后已有会话立即不能使用。
- 首次改密前只开放必要身份操作；重复使用初始凭据失败，前导零工号登录正确。
- 员工退出/关闭窗口不调用公共 shutdown；两位管理员初始化与恢复可按文档复验。
