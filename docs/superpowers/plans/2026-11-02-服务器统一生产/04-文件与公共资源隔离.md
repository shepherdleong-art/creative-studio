# 04 文件与公共资源隔离

**状态：** `needs-triage`  
**依赖：** [03 资源归属与接口授权](03-资源归属与接口授权.md)  
**目标：** 让文件预览/下载和模板、音乐等资源使用同一授权规则。

## 动手前

阅读 [技术方案](../../specs/2026-11-02-服务器统一生产-技术方案.md) 中对应章节与仓库 AGENTS.md；改动具体模块前读取其 docs/reference 文档。先核实依赖任务的完成证据，再将状态调整为可实施。本任务单描述待做工作，不代表功能已存在。

## 改动范围

修改 `app/api/images/[...path]/route.ts`、`app/api/videos/[...path]/route.ts`、`lib/media-core/file-response.ts`，以及 scene-references、video-reference-assets、video-prompt-templates、font-favorites、script-studio catalogs/viral-templates/template-assets、BGM/LUT 入口；拟新增 `lib/team-service/files/` 和公共资源发布服务。

## 实施步骤

1. 建立 team_files 与引用登记；文件只通过已授权实体解析，server 旧路径无法对应实体时拒绝。衍生物继承源资源权限。
2. 统一 Range/ETag/ZIP/缩略图鉴权和 private/no-store 策略；GET 预览按任务 09 的媒体合同登记去重转码，不先转码后鉴权。
3. 公共资源由管理员显式发布；个人记录、选择器、历史版本、模板附图和底层文件去重分别处理，避免全局 hash 唯一导致泄露。
4. 员工模型选择用安全目录接口，配置接口仅管理员；字体收藏按用户保存，公开系统字体列表与个人收藏分开。

## 完成标准

- 单文件、Range、代理、ZIP均不能越权；已登出/停用/换账号后不读取前账号缓存内容。
- 相同内容分别上传形成独立可见性，删除一方记录不影响另一方；员工不能修改公共版本。
- 批量与脚本生成只引用有权使用的公共/私有资源，空 BGM 明确阻塞相关生产，不生成静音正式成片。

新增行为测试使用临时数据根并在动态导入前设置环境；具体运行方式以已有测试文件头为准。完成时记录修改文件、测试命令/结果、剩余阻断和依赖变化，不把未执行的检查写成通过。
