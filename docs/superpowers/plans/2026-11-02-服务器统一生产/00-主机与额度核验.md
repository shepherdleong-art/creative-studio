## 实施步骤

1. 预检仅采集 Windows 版本、CPU、内存、GPU/驱动、磁盘与物理设备、网络、可用端口及指定目录权限；不打印完整环境变量或含凭据的进程命令行。
2. 核对实际运行版本、旧数据根及备份；给新服务选择独立部署根、数据根和备份位置。记录服务账号、固定 origin、证书来源与员工信任分发方式。
3. 核验平台账户/Key/模型的额度共享关系、其他调用者及本地各工程限流能力，形成具体池映射与预算；核实前继续错峰。
4. 准备代表性图片、长短视频、字幕/模板/BGM及输出规格；GPU 编码试验在实际服务账号和随包 FFmpeg 下执行。

## 完成标准

- 提交环境核验记录，区分用户确认与工具实测；未取得的数据明确为空，不沿用旧 IP/CPU/盘符假充实测。
- 新旧目录不重叠；备份故障域及空间已标明；证书受信与员工到业务入口的访问可复验。
- 额度映射含证据日期、所有调用者、两边可执行预算及保守余量；没有凭据明文。
