# 07 旧图片视频队列接入

**状态：** `ready-for-human`
**依赖：** [04 文件与公共资源隔离](04-文件与公共资源隔离.md)、[06 统一准入与调用台账](06-统一准入与调用台账.md)  
**目标：** 常规项目图片/视频所有提交、手动重试与恢复接入统一执行设施。

## 动手前

阅读 [技术方案](../../specs/2026-11-02-服务器统一生产-技术方案.md) 中对应章节与仓库 AGENTS.md；改动具体模块前读取其 docs/reference 文档。先核实依赖任务的完成证据，再将状态调整为可实施。本任务单描述待做工作，不代表功能已存在。

## 改动范围

修改 `lib/queue.ts`、`lib/video-queue.ts`、`lib/providers/`、`lib/video-providers/`、项目 run 与 jobs/video-jobs retry/regenerate/resume-poll 路由；接入启动恢复和 shutdown drain。

## 实施步骤

1. 枚举同步图片、异步图片、普通视频、reference submit 的每个分支，为稳定任务/尝试注册共享操作。
2. 替换 startup 批量重置 running；按持有者/回执续查、补下载、明确未受理才重试。保留模型参数与供应商任务身份。
3. 等待额度阶段不算一次提交；COS URL 在实际提交前刷新；下载独立资源。
4. 手动操作记录新尝试并保留历史远端 ID；server 拒绝未纳入范围的本地实拍任务入口，local 实拍专项保护不变。

## 完成标准

- 不同项目图片与视频映射到同一实际池，不各自拥有一份上限。
- 重复点击和服务重启不重发已受理任务，下载失败只补下载；同步未知响应进入核查。
- 员工断线、停用和取消后的结果回收符合统一合同，本地队列和供应商参数回归通过。

新增行为测试使用临时数据根并在动态导入前设置环境；具体运行方式以已有测试文件头为准。完成时记录修改文件、测试命令/结果、剩余阻断和依赖变化，不把未执行的检查写成通过。

## Comments

### 2026-11-02 实现交付

- `lib/legacy-media-execution.ts` 将旧图片/视频的稳定 operation、business attempt、submitRound/transport、actor/scope/instance/fence 接入 06 的真实 `enqueue / admit / markSubmitting / transmit / settle`。图片与视频按规范化 baseUrl＋受保护凭据指纹映射同一实际上游池；Kling 使用原始 access/secret 身份而不是短期 JWT 计算池键。等待名额不增加业务 attempt。
- `lib/queue.ts` 覆盖 GeekAI、gateway-task-image、Packy、Packy Gemini、OpenAI-compatible、Ark 的同步/异步提交；`lib/video-queue.ts` 覆盖普通与 reference submit。供应商原有尺寸、参考图顺序、尾帧精确 allowlist 与公司协议仍由原适配器负责；reference COS 在准入后的实际提交前刷新。同步 URL 图片也改为先结算生成，再独立下载。
- startup 不再批量把 running 改为可重提状态。按 execution 操作、远端 ID 与 resultRef 恢复；unknown 保持 needs_check，明确 not_created 才允许策略重试。已受理任务在取消、成员停用、维护和重启后续查；下载失败只进入补下载。手动 retry 通过追加的 `jobs/video_jobs.executionRevision` 创建新 operation，旧 attempt 和远端 ID 保留在 execution/journal；regenerate 继续创建新任务与持久 principal。
- `lib/legacy-media-lifecycle.ts` 接入 01 四阶段启动及 shutdown drain。server 路由、领取与启动恢复均排除本地实拍重组任务；local 队列计数、取消、限流及实拍专项保护未改。
- 新增 `scripts/legacy-media-execution.test.ts`，使用真实 SQLite/execution、loopback 图片服务与 fake 视频适配器，覆盖跨成员/项目图片视频共池、等待不增 attempt、重复提交、同步未知重启、取消/停用续查、只补下载及同步 URL resultRef 恢复，无真实外网或付费调用。
