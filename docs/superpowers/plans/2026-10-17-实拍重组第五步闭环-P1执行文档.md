# 实拍重组第五步闭环 P1 执行文档

日期：2026-10-17。依据 [需求共识](../specs/2026-10-12-实拍重组Skill与五步工作台接入-需求共识.md) 与 [macOS P0 验收](../../2026-10-17-固定渲染命令-macOS第二阶段验收.md)。本轮实现与 macOS 合成闭环已完成，具体证据和未覆盖范围见文末验收记录。

用户本轮明确：跳过安装版，交付以源码桌面版和免安装版为范围；不安排 DMG/Inno 安装流程。免安装版的 standalone 仍须具备固定渲染所需运行资源。

## 闭环与约束

从 HTML 审片页进入现有项目第五步，定位单条成片及交付修订；更换已登记候选、调整入出点和顺序后，沿用已冻结模板与固定渲染核心导出。输出到该条原交付目录，以 `-v2`、`-v3` 命名；通过完整技术检查并交付成功后才归档旧 MP4/JPG。外置目录不可用时明确失败。

复用现有项目、分镜组、成片组/版本、修订历史与成片 worker，不另建 Agent 专属工作区。导入与更新均须幂等并检查当前修订；Agent 重复登记不得覆盖人工编辑。Agent 生成队列保持唯一执行方，只登记已完成结果及真实出处。

## 实施顺序

1. **源码/免安装运行资源**：去掉固定渲染对随包不存在的 setup 脚本、原始 TS 文件路径的运行期依赖；保留版本和哈希核验。完成条件：源码行为与金样不变，隔离 standalone 资源能报告真实版本与构建器来源，缺失或篡改资源拒绝执行。
2. **登记与素材归属**：定义版本化导入清单，携带工程/片号身份、原交付目录、渲染单、可核验素材、生成出处及已有成片信息。服务端事务登记现有五步对象并保存映射；CLI 经桌面服务状态发现接口，核对实例和数据根。完成条件：重复提交只返回同一对象；文件变化、归属冲突、错误实例拒绝；不创建可被旧队列领取的进行中生成任务。
3. **第五步编辑与版本**：使用现有成片修订及候选素材范围。修改映射回固定渲染单；不支持的编辑明确阻止，不能保存后导出时忽略。换镜头后提示预览已过期；按用户本轮要求，完整带包装预览可选，不增加确认按钮或导出闸门。完成条件：单条修改不影响其他条、旧版本写入冲突、人工修改保留、预览明确区分当前编辑与历史成片。
4. **固定渲染、交付与恢复**：成片 worker 冻结输入与模板，调用 `renderFilm`，接入取消和停机信号；成功后按版本向外部交付目录发布 MP4/JPG，更新审片数据。完成条件：渲染/交付失败保留旧版；并发与重启不重复发布；过期编辑不冒充当前交付；旧版占用产生可重试归档提示。
5. **审片入口与桌面定位**：审片页携带实例/成片/交付版本身份；桌面连接明确版本差异。完成条件：从审片页进入目标条、换镜头、再次导出、刷新审片页完整贯通。安装协议注册与安装包验收按用户指令跳过，免安装启动及连接入口须明确。
6. **验收与 skill 同步**：先隔离数据库和合成工程验证错误分支，再用已有授权素材做本地完整闭环；不调用付费生成供应商。保存运行时、浏览器、成片与交付证据，分别标注源码、免安装环境结论。实际通过后更新 skill 接入指引与验证范围。
