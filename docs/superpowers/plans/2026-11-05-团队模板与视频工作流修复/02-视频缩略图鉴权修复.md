## 目标与代码入口

实现 [规格 §4](../../specs/2026-11-05-团队模板与视频工作流修复-功能方案.md)。先检查 `components/VideoGenerationResults.tsx`、`app/api/shot-sets/[id]/video-jobs/route.ts`、`lib/storage-url.ts`、`app/api/images/[...path]/route.ts`、`lib/media-core/file-response.ts` 及团队路由/文件登记。

当前海报来自 sourceImageId 对应图片；Next 默认图片优化内部请求没有 Cookie 已在本机隔离验证。部署环境仍需用浏览器网络面板确认实际返回，不能把所有破图归为一种原因。

## 实施要求

1. 先建立带真实会话的受保护图片复现，分别核对原始图片 URL 和优化后 URL。
2. 在相应图片组件采用会话可达的同源展示方式；保持现有海报、布局及播放/下载，补失败占位。
3. 扫描直接相关的受保护媒体 Image 调用，记录修复范围；保留服务端鉴权与私人缓存策略，不全局公开图片或在 URL 塞凭据。

- [x] 管理员、所属员工在团队页面和轻客户端均能看到既有成功视频的海报。

- [x] 图片缺失/读取失败呈现占位，无破图图标或无限请求循环；视频仍可播放、下载。
- [x] local 模式及宽窄窗口、深浅主题正常。
