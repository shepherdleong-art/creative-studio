## 接手步骤

1. 读根 AGENTS.md、本规格及被分配票；按票读取对应 reference 文档。
2. 查看 `git status` 和相关 diff，保存工作起点。现有工作区有其他人的未提交修改，不能 reset/覆盖以获得干净状态；特别留意 `resource-scopes.ts`、`script-studio/bootstrap.ts` 和团队构建/验收脚本。
3. 确认依赖票已有验收记录，再实现本票。`ready-for-agent` 表示规格可执行，不代表功能已完成或前置已验收。
4. 票末 `## Comments` 记录改动、实际运行命令、结果、未完成现场项。完成后仍使用仓库五种状态，不新增 done/resolved 等状态；以验收记录标记完成事实。

## 工程量判断

整体中等规模，公共模板和图片预处理占主要工作量；UI 恢复尾帧不能单独上线而遗漏服务端模式与大图创建预检。没有要求重构整个团队系统或重新生成历史视频。数据库增量设计留给 01，必须满足原子发布与稳定团队身份。
