## 目标与代码入口

## 实施要求

1. 默认按 actorUserId 分组，显示姓名、工号、当前结果任务数、折叠按钮；组按最近任务时间排序，组内沿用原排序。
2. 增加成员选择和分组/平铺切换；成员＋状态组合交给服务端，同名成员、历史停用成员均可区分。
3. 保留搜索、复制排查信息、错误链接；刷新保留当前筛选、视图、折叠状态。明确 500 条截断和组计数口径。

## 验收

- [x] 默认分组，可折叠，可切回原平铺；两种视图的筛选结果一致。
- [x] 两位同名成员形成不同组，按 ID 筛选准确。
- [x] 创建超过 500 条其他人的较新任务后，仍可从成员选项找到并查出低频成员任务。
- [x] 状态过滤含取消语义不回归；搜索空态、加载失败、刷新和复制详情正常。
- [x] 员工篡改 actorUserId 查询他人被拒，管理员可按成员查询。
- [x] 组计数明确是当前结果，不能误称全历史任务数；深浅主题和窄屏正常。
