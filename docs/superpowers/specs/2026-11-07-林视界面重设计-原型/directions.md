# 方向卡

> **第一轮的六张（本文下半部分）已被用户否决**，原话「都不好，太花了，像ppt不像工作台」。以下是第二轮。

## 第二轮的判断标准

1. 打开就是活儿：不放大图当门面，不放巨字，页面标题不超过 20px 左右。
2. 颜色只表示状态和当前选中，照片是界面里唯一花的东西。
3. 图只出现在它本来就该出现的地方（素材、候选、成片）。
4. 用面板和分隔线组织，信息紧凑，1536×864 下一屏看完主要操作。
5. 关键屏放真实工作页（项目第一步、运行总览），不放首页门面。
6. 文案用现有真实词：可用 / 待返工 / 废弃 / 重新生成 / 设为场景参考图。

参考板：`refs/board-worktools.jpg`、`refs/board-ui-crops.jpg`（Linear、Final Cut、CapCut、Resolve、Airtable、macOS 官网，已亲眼截图；营销页上能看到的真实界面有限，其余来自对这些软件的了解，未逐屏核对）。这一轮没用秒数轮盘：用户的反馈已经把范围收窄到生产工具。

## 一 Mac 原生 · 用户点名

- **借的是什么**：macOS 悬浮玻璃侧栏，胶囊工具条，分段控件，右侧分组表单（系统设置式），表格斑马纹，底部状态栏。
- **主角素材**：候选图网格，像「照片」App。
- **骨架**：侧栏 + 工具条 + 素材 / 候选 / 参数三栏。
- **标志**：一片叶子也是一只眼睛（林 + 视），绿色圆角方块，Mac 图标样式。
- **取舍**：员工是 Windows，SF 和苹方不能用，要换 Inter 和思源黑体；窗口按钮用 Windows 的。

## 二 剪辑软件 · 现实参照

- **逻辑与来源**：DaVinci Resolve 的底部页面标签、面板贴边；剪映的深灰与青绿强调色。
- **借的是什么**：面板之间用 2px 暗缝，不用卡片；五步 = 底部五个页面；素材、监看、属性三区；控制台带实时日志条。
- **骨架**：顶栏 + 素材 / 监看 / 属性 + 底部标签。
- **标志**：取景框一角加播放键（L + V）。
- **取舍**：一天开在亮办公室里偏暗，表格页显重。

## 三 精密工具 · 现实参照

- **逻辑与来源**：Figma、Linear、Vercel 控制台。
- **借的是什么**：白底细线、无卡片、控件 30px 高、等宽数字、只用黑白灰，主按钮是黑色。
- **骨架**：窄侧栏 + 面包屑 + 步骤标签 + 三栏。
- **标志**：字母 L 加撇号。
- **取舍**：最容易落地，也最不显眼，品牌感靠小细节。

## 四 生产看板 · 现实参照

- **逻辑与来源**：飞书多维表格、Airtable。
- **借的是什么**：行是项目、列是五步，每格显示状态；右侧抽屉直接操作；管理员按成员分组。
- **骨架**：顶部导航 + 大表 + 右抽屉。没有侧栏。
- **标志**：两棵树拼成的「林」。
- **取舍**：结构改动最大；这张表也可以单独搬进其他方案。

## 五 器具 · 最佳设计师

- **逻辑与来源**：Dieter Rams 时期的博朗电器，「尽可能少的设计」。
- **借的是什么**：暖灰机身不用纯白；状态用指示灯；按钮有按键感；读数窗；全屏只有一点橙。
- **骨架**：顶条 + 五个物理键 + 三栏面板。
- **标志**：旋钮也是眼睛。
- **取舍**：最有性格，也最可能有人觉得老气。

## A 生活画报 · 用户已选语言

- **逻辑与来源**：决赛 PPT 方向 4（IKEA《Life at Home》杂志式），用户原话「封面好吸引我」。
- **借的是什么**：家居生活照满出血；白色粗体大字按词错落压在照片上，各转 2 到 3 度；圆形芥末黄贴纸；浅底卡片大圆角。
- **主角素材**：换景后的客厅整图，项目卡片也是满版照片。
- **骨架**：左侧分组导航（选中项是芥末黄胶囊），首页上半是一张大图，下半四张照片卡。
- **胆量花在哪**：工作台首页给一张占半屏的生活照和两行巨字。
- **form 来自内容的哪里**：家具卖的就是过日子。

## B 放映室 · 现实参照

- **逻辑与来源**：Frame.io 的三栏审片界面（`refs/board-tools-1.jpg`）+ 决赛时看过的 Magnum 联系表。
- **借的是什么**：左栏素材列表、中间大画面、右栏决定；深色中性底不给画面染色；胶片边码（琥珀色等宽字 `▶ 17A`）；人用红油笔圈选。
- **主角素材**：真实成片与镜头帧。
- **骨架**：窄图标栏 + 片单 + 监看区 + 判断栏，底部一条胶片带。
- **胆量花在哪**：首页直接就是审片台，不做仪表盘。
- **form 来自内容的哪里**：决赛 PPT 的主线「AI 出内容，人只做判断」。标志是取景框一角加胶片帧号上的 ▶，也是播放键。

## C 林 · 最佳设计师（东亚）

- **逻辑与来源**：田中一光的几何平面构成（样张 `east/09-tanaka-geometric-poster`）。
- **借的是什么**：字和几何块就是画面；三到四色的强比例；把照片裁进圆形，前面立两棵三角形的树。
- **主角素材**：巨型数字、印章、几何树与太阳。
- **骨架**：左侧通高橄榄绿色块 + 右侧奶油底编辑版面，表格无卡片、细线分隔。
- **胆量花在哪**：首页一个占三分之一屏高的「3」。审片通过是盖朱红印章。
- **form 来自内容的哪里**：林是两棵树，对应产品图和短视频两条线；橄榄绿和胡桃木取自 LH122K3 沙发。

## D 取景 · 现实参照

- **逻辑与来源**：Cosmos 首页（`refs/board-tools-2.jpg`）的浮动图块与中央一句话；Flora（`refs/board-tools-3.jpg`）的作品围绕主体。
- **借的是什么**：作品环绕中央一句话和一个输入框；导航收成底部浮动条；只用一个高亮色标记需要注意的东西。
- **主角素材**：用户自己最近的作品。
- **骨架**：没有侧栏。左上标志，中央一句话 + 搜索跳转，四周作品，底部浮动导航。
- **胆量花在哪**：去掉侧栏；峰值对焦绿框只亮在需要判断的作品上。
- **form 来自内容的哪里**：相机的峰值对焦：焦点上的东西会发光。
