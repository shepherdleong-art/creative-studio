定稿方案一 Mac 原生，共 13 屏。选场景图、分镜、视频都把原图和结果并排对照。全部能点，断网也能看。

打开原型

第七轮改了这几处

  1. 剪辑区用回正式产品的操作：左栏「素材调整」，先选素材，再点「替换当前片段」或「添加到缺口」。下面的时间轴有字幕、卖点、视频、口播、配乐五条轨道：单击选中，拖动排序，拖两端修剪，双击视频片段打开截取条，双击字幕或卖点直接改字，右键有删除和口播变速。快捷键也一样：空格、V、B、⌘B、N、左右键走帧、Delete、⌘Z。
  2. 右栏回到一列卡片：选中视频片段时，最上面出现倍速和画面调整；下面依次是视频包装、字幕样式、背景音乐、口播音频变速、口播音量、视频封面设置。字幕样式不再另放小预览，改动直接显示在中间的预览上。
  3. 批量检查成片也照正式产品：成片属性五页（包装、字幕、画面、封面、配音BGM），改完点「应用」。时间轴拖两端修剪、拖中间移动；素材拖到片段上替换，拖到空位插入，拖到末尾追加；鼠标在素材缩略图上左右滑能看画面。
  4. 导出成功后：点成片卡片弹出大预览，能点或拖进度条跳转，左右键换上一条、下一条，空格播放暂停；还没导出的成片会说明播放的是合成预览。「一键下载全部」可以选成片和封面一起打包、只要成片或只要封面。单条混剪导出后，点成片也能预览。

之前几轮改过的

  1. 第六轮：小图悬停看大图；混剪右栏补齐正式产品的全部设置；加了批量生产的四步原型。
  2. 第五轮：分镜能上传、全选、设开场；新建项目、场景图、视频页拿掉超时、并发和预处理；爆文模板内容直接摊开，卖点库默认收起、默认全选；视频页点哪条就显示它的提示词，批量检查加「统一秒数」。

原来的看点还在：选场景图、分镜都是原图和结果并排；脚本字数和时长实时算；视频和混剪用的是这个案例的真实素材。

真的和示例的

  • 真的：案例 LH122K3 的实拍图、分镜图、视频、详情页和成片；第 1 条脚本；模型清单、时长限制、运镜模板和提示词。
  • 示例：金额和任务数；脚本方案 2、3 的文案；切入角度和模板理由；详情页的文件名和屏号；分镜 4、5 的手写提示词；每段视频标的模型（按时长推断）；爆文模板名。提交和生成是定时模拟的，不调用模型。
  • 没验证：还没在真实的 Windows 电脑上看过。这台 Mac 上用 Chromium 和 Safari 内核测过，也模拟了 Windows 窗口和字体。

现在
定稿

分镜、脚本、视频三屏的「现在」是空项目截图，因为探查用的测试数据里没有生成结果，看的时候以页面结构为主。

第一批不做、第二批再加的

  • 工作台的「等你处理」跨项目汇总
  • 成片的「通过 / 这条重做」操作
  • 成片多个版本并排比较

这些现在产品里没有，是这次设计提议新增的。

不做原型，落地时按同样规则延伸

  • 创作画布、成员与账号、用量、供应商配置、公共资源、版本与备份
  • 个人本地版，跟在团队版之后

这几轮新加、产品里原来没有的

  • 导出页点成片卡片弹出大预览（正式产品是每张卡片里嵌一个小播放器）
  • 「一键下载全部」：成片和封面一起打包（正式产品只能逐条下载）
  • 新建分镜组的「全选」和「设为开场」
  • 视频页右栏跟着所选视频显示当时的设置
  • 批量检查里的「统一秒数」原来就有，这次只是放到显眼的位置

落地时要留意

  • 超时、并发和图片预处理改由服务器统一管理：要把它们从新建项目、场景图、视频页拿掉，默认值放到服务器
  • 「正在生产」的百分比：现在只有渲染有真实进度，图片和视频生成落地时只能显示第几条
  • 「模型与名额」按账号合并：数据已有，要改页面和保存方式
  • 总览里「今天的成员」和「开工前还差几件事」：数据已有，页面是新的
  • 改显示名会牵动几个守护测试，要一起改
  • 混剪被侧栏盖住的问题一起解决，同时保留为小屏监看加宽的布局
  • 剪辑区和批量审片的操作照搬现在的混剪时间轴和截取条，只换外观，不改操作习惯
  • 一键下载全部：网页版要在服务器打包成 ZIP，桌面版可以直接存到下载目录
  • 商标还没检索
