## 0. 文档效力

本文件将原始 AI-remix 移植规格与 2026-07-23 前端评审中确认的修改合并为智能混剪 V1 的最终产品口径。

优先级如下：

2. 数据模型、接口、文件路径、实施阶段和测试门禁以技术执行文档为准。
3. 原始移植规格保留为算法、FFmpeg 细节和源项目对照资料；与本 PRD 冲突时，以本 PRD 为准。
4. `/mixcut-preview` 中的文案、颜色和模拟数据只用于评审，不得直接作为真实业务数据写入生产代码。

## 1. 背景与问题

Creative Studio 已能完成场景图、分镜图、口播脚本和视频素材生成，但第五步仍需要把上游产物重新选择、复制或手工整理，用户无法连续完成“脚本—素材—初剪—精调—导出”。

当前主要问题是：

- 模块 4 生成的视频没有以分镜组为边界直接进入剪辑素材池，容易把不同产品、场景或批次混在一起。
- 模块 3 生成的脚本需要手动复制，无法快速切换同一分镜组下的不同脚本草稿。
- 自动剪辑缺少清晰的阶段进度，用户无法判断系统正在分析、配音、匹配还是生成预览。
- 预览区和时间轴空间关系不稳定，纵向视频可能覆盖时间轴；时间轴不能完整滚动、缩放和查看下层轨道。
- 封面调整空间太小，缺少真实画面、独立的主副标题样式、精细拖拽和可复用预设。
- 导出结果没有明确回到当前工作台任务目录，也没有遵循任务的型号和日期命名。

## 2. 产品目标

智能混剪 V1 要实现一条本地优先、可人工修正的四步闭环：

1. 自动承接模块 4 当前分镜组的视频，必要时补充外部素材。
2. 自动承接模块 3 当前分镜组的脚本，允许切换草稿和继续编辑。
3. 以口播真实时长为主轴完成分析、配音、画面匹配和预览，并允许用户调整时间轴、字幕、封面和音乐。
4. 将成片输出到当前工作台任务目录，使用 `成片-型号-日期` 命名。

V1 的成功不是“完全自动且不可修改”，而是：AI 快速形成可解释的初稿，用户可以看懂、调整并稳定导出。

## 3. 非目标

V1 不包含：

- 多轨画中画、复杂转场、关键帧动画和专业调色。
- 跨分镜组自动补素材。
- 云端项目同步、多人协作和在线素材库。
- 重新实现图片、脚本或视频供应商配置。
- 用浏览器临时状态替代 SQLite 持久化。
- 在本期强制移植源项目的 Electron、Python、MUI 或 Tailwind 技术栈。

## 4. 核心产品原则

1. **分组先于素材数量**：一次混剪只消费一个 `shotSetId`，素材不足也不得自动跨组。
2. **上游结果直接复用**：模块 3、模块 4 的正式产物是输入源，不要求用户复制或重新导入。
3. **口播音频是唯一时间基准**：画面、字幕和 BGM 围绕 TTS 真实时长组织。
4. **AI 生成可编辑草稿**：自动结果不能锁死时间轴，也不能覆盖用户已经确认的修改。
5. **所见即所得**：预览、封面编辑和最终渲染使用同一套尺寸、字体、位置与安全区规则。
6. **状态可理解、失败可恢复**：耗时步骤必须显示阶段、进度和失败项；刷新后可继续。
7. **产物回到任务上下文**：导出路径和命名在开始前明确展示，完成后能直接查看。

## 5. 用户与核心任务

主要用户是需要批量制作产品短视频的内容制作人员。

核心任务：

> 在当前产品项目中选择一个分镜组，直接使用该组已经生成的视频和脚本，快速得到一条可预览、可调整封面与时间轴、可稳定导出的成片。

## 6. 信息架构

智能混剪位于项目工作台第五步，包含四个常驻步骤：

1. `导入素材`
2. `AI 智能创作`
3. `预览调整`
4. `导出渲染`

四步组件应保持挂载，切换步骤不得丢失本轮尚未提交的编辑状态。页面采用：

- 左侧：创作步骤导航。
- 左辅栏：当前分镜组、统计、当前步骤概览和最近会话。
- 中央：当前步骤的主工作区。
- 右侧：当前步骤的辅助说明或属性面板；可折叠。
- 封面精调：根级抽屉，不受右侧栏宽度限制。

同一信息不得在左辅栏和中央主区重复展示。当前分镜组与组内统计统一放在左辅栏。

## 7. 详细需求

### 7.1 全局工作区

- 顶部显示产品名称、项目名称和全局画幅。
- 支持 `9:16`、`3:4`；`16:9` 保留兼容入口但不是 V1 主路径。
- 左右辅助面板可折叠；桌面宽屏下可调整宽度。
- 界面文案全部为中文，遵循 Apple 官网式精致极简风格。
- 任意卡片和控件不得出现文字挤压、越界或被相邻面板遮挡。
- 当前会话应自动保存；刷新后恢复到最近可继续状态，运行中任务不得被错误恢复为仍在运行。

### 7.2 第一步：导入素材

#### 7.2.1 分镜组联动

- 当前素材组对应模块 4 的一个分镜组，唯一标识为 `shotSetId`。
- 分镜组选择器放在左辅栏，展示组名、分镜数量、成功视频数量和视频总时长。
- 切换分镜组后，中央素材池、脚本列表、分析结果、时间轴草稿全部切换到该组上下文。
- 不同分镜组必须保持独立素材池，不得合并展示或参与同一次自动匹配。
- 如果当前组没有成功视频，明确提示返回模块 4 生成视频；不得静默展示其他组素材。

#### 7.2.2 模块 4 自动素材

- 模块 4 中 `status = succeeded` 且本地文件存在的视频自动进入当前组素材池。
- 模块 4 后续有新视频完成时，素材池可自动刷新或由用户手动同步。
- 卡片显示缩略图、文件名、分辨率、时长、来源和状态。
- 模块 4 素材标记为 `模块 4`；用户补充的文件标记为 `外部导入`。
- 用户可以多选本次参与混剪的素材；默认选中可用的模块 4 素材。

#### 7.2.3 外部补充素材

- 支持拖拽或选择文件导入 MP4、MOV、AVI、WebM 视频；不支持静态图片（JPG/PNG 为已否决需求，后续也不做）。
- 外部素材只能归属当前分镜组，不进入项目级公共池，也不得自动出现在其他组。
- 导入时校验文件存在性、格式、时长、尺寸，并生成缩略图。
- 单条失败不阻断其他文件；卡片显示可重试的失败原因。

### 7.3 第二步：AI 智能创作

#### 7.3.1 模块 3 脚本联动

- 只列出 `shotSetId` 与当前分镜组一致的模块 3 脚本草稿。
- 默认选择该组最新的有效脚本草稿。
- 下拉项显示脚本标题、生成时间、目标时长和供应商/模型摘要，便于区分不同版本。
- 选中草稿后自动导入口播文案，不需要复制粘贴。
- 用户可以直接编辑导入文案。
- 未修改时显示 `已同步`；修改后显示 `已手动修改`。
- 提供 `恢复导入版本`，恢复当前所选草稿的原始文案。
- 用户切换到其他草稿前，如当前有未保存修改，必须明确提示保留、覆盖或取消切换。
- 脚本下拉与素材分组绑定，禁止选择其他分镜组的脚本。

#### 7.3.2 文案与音色布局

- 文案编辑区和音色选择区采用上下分区或充分宽度布局，不使用导致文案拥挤的窄双栏。
- 文案输入框至少能舒适显示 15～30 秒口播，支持滚动和手动修改。
- 显示字数、预计口播时长、当前来源和最后修改状态。
- 音色支持试听、搜索/查看更多、语速调整；API Key 只显示配置状态，不回显明文。

#### 7.3.3 自动创作流程与进度

用户点击生成后，系统按四个可见阶段处理：

1. 文案拆分与素材分析
2. 逐句口播生成
3. 节拍检测与场景匹配
4. 预热低清预览

要求：

- 显示总进度条、当前阶段、阶段状态、耗时和失败信息。
- 进度来自真实后台任务，不使用前端假进度。
- 单素材分析失败允许降级继续；TTS、时间轴或渲染准备失败则明确阻断。
- 生成期间离开页面后返回，仍能看到真实任务状态。
- 完成后才开放 `去预览调整`。

### 7.4 第三步：预览调整

#### 7.4.1 预览区

- 视频预览必须约束在独立容器内，按当前画幅等比缩放。
- 纵向视频不得越过播放器控制条或覆盖下方时间轴。
- 播放、暂停、定位、当前时间、总时长、全屏可用。
- 拖动播放头或点击时间轴，预览应同步到对应时间。
- 预览画面与最终导出采用一致的裁切、字幕、封面和安全区参数。

#### 7.4.2 精细时间轴

时间轴至少包含：

- T1 视频轨
- T2 字幕轨
- T3 口播音频轨
- BGM 轨

交互要求：

- 时间轴区域可横向滚动、纵向滚动和缩放，不能锁死容器。
- 缩放后可查看完整时长；纵向滚动可看到所有音频轨。
- 播放头可拖动，时间刻度与片段位置保持同步。
- 视频片段可拖动排序，片段边缘可调整源入点/出点。
- 调整不得改变 TTS 和字幕的叙事顺序；产生缺口时明确显示，不静默移动已确认片段。
- 波形、字幕块和视频块使用同一时间坐标系。
- 用户的调整写入草稿 revision，不被重新分析或自动建议静默覆盖。

#### 7.4.3 字幕与音乐

- 字幕文字来自当前编辑后的口播文案，并按 TTS 真实时长对齐。
- 字幕默认单行，超出安全宽度时提示并阻止不一致导出，不自动形成难以控制的多行。
- 字幕面板支持文字、字体、字号、颜色、描边、位置和全局应用。
- BGM 支持选择、试听、音量、淡入淡出和移除。
- 原视频声音默认静音，口播与 BGM 不得因结尾补帧继续播放。

#### 7.4.4 封面摘要与精调入口

- 右侧 `封面` Tab 只展示当前真实封面缩略图、来源片段、截帧时间、主副标题摘要和 `精调封面` 按钮。
- 不在狭窄右栏堆放完整编辑控件。
- 点击 `精调封面` 打开根级抽屉；抽屉约占视口宽度 68%～72%，设最大宽度，并拥有独立标题栏、滚动正文和固定底部操作栏。
- 点击取消、关闭、遮罩或 Esc 放弃本次未应用修改；点击 `应用封面` 一次性提交。

#### 7.4.5 封面精调抽屉

封面编辑必须提供：

- 使用真实视频截帧作为画布，不得使用渐变占位图代替。
- 来源片段列表带缩略图；切换片段后刷新对应画面和可用时长。
- 截帧时间滑杆受该来源真实时长约束。
- 画面缩放、平移和拖拽定位。
- 4% 导出安全区可视化。
- 主标题与副标题分别拖拽定位。
- 主标题与副标题分别控制文字、颜色、字号、正体/斜体、描边颜色和描边宽度。
- 共享字体选择，并保证当前系统字体可用于最终渲染。
- 标题默认保持单行；中文不得因布局测量错误把最后一个字孤立到第二行。
- 文本过长时先提示或按确定性规则缩小字号，不静默换行。
- 提供内置样式。
- 支持输入名称保存自定义预设、应用预设和删除预设。
- 自定义预设保存字体、字号、颜色、描边、正斜体、位置和画面缩放/平移；不保存标题文案、来源片段和截帧时间。
- 自定义预设需持久化，刷新和重启后仍可使用。

### 7.5 第四步：导出渲染

#### 7.5.1 导出前检查

导出页展示：

- 当前任务名称
- 产品型号
- 任务日期
- 输出文件名
- 目标任务目录
- 画幅、清晰度（V1 固定 1080 档，见已锁定决策 9）、帧率和预计时长
- 字幕、封面、BGM 和时间轴检查结果

存在时间轴缺口、文本溢出、封面缺失、素材文件丢失等阻断问题时，不允许开始导出，并提供返回修复入口。

#### 7.5.2 命名与目录

- `型号` 的唯一来源是项目 `productCode`，不得使用 AI 生成模型字段 `projects.model`。
- `日期` 默认取项目创建日期，格式为 `YYYYMMDD`；未来如果工作台引入独立任务日期字段，则迁移到该字段。
- 标准文件名为：`成片-<productCode>-<YYYYMMDD>.mp4`。
- 示例：`成片-JSQ-A1-20260723.mp4`。
- 文件输出到当前项目在本地数据根目录下的成片目录，并在 UI 中以 `工作台/<任务名>/` 的用户语义展示。
- 同名文件不得静默覆盖；再次导出追加 `-02`、`-03` 等序号。
- 如果 `productCode` 为空，导出前阻断并引导用户补充型号，不得用 AI 模型名兜底。

#### 7.5.3 渲染进度与结果

- 渲染使用后台持久化任务，显示真实阶段、百分比、已用时和预计剩余时间。
- 刷新或重启后，运行中任务恢复为可重试的排队状态，不能永久卡在 `running`。
- 成功后显示实际文件名和实际本地路径，并提供预览、在文件夹中查看和下载。
- 结果注册为当前项目产物，并继续参与项目创意包/ZIP 导出。
- 失败保留日志与草稿，不删除用户编辑；允许按同一不可变快照重试。

## 8. 状态与数据边界

| 对象 | 唯一边界 | 产品规则 |
|---|---|---|
| 项目 | `projectId` | 所有脚本、分镜组、视频和成片必须属于同一项目 |
| 当前素材组 | `shotSetId` | 素材、脚本、分析和时间轴均按组隔离 |
| 模块 3 脚本 | `scriptDraftId + shotSetId` | 只允许选择当前组脚本；编辑后形成混剪草稿快照 |
| 模块 4 视频 | `videoJobId + shotSetId` | 只读取成功且文件存在的当前组视频 |
| 外部素材 | `assetId + shotSetId` | 仅归属导入时的当前组 |
| 混剪草稿 | `groupId/variantId` | 保存用户编辑、revision、任务和导出历史 |
| 导出产物 | `renderJobId + projectId` | 必须回写当前项目并保留实际路径 |

## 9. 异常与降级

- 当前组无视频：阻断生成，提供返回模块 4 的入口。
- 当前组无脚本：允许手动输入，但提示建议先在模块 3 生成；手动文案必须保存为当前混剪草稿快照。
- 部分视频无法分析：标记失败并排除自动匹配，其他素材继续。
- 视频全部无法分析：允许用户手工编排，自动匹配不可用。
- TTS 失败：阻断时间轴生成，保留脚本和素材选择。
- 字幕对齐服务不可用：降级为按句时长比例对齐，并明确标记 `降级对齐`。
- 预览生成失败：保留可编辑时间轴，可重试低清预览。
- 封面截帧失败：可切换其他来源；不得显示假的最终封面。
- 导出失败：保留不可变渲染快照与日志，允许重试。

## 10. 验收标准

### 10.1 模块联动

- [ ] 模块 4 新完成的视频能进入对应分镜组素材池。
- [ ] 切换分镜组时，其他组视频不会混入当前素材池或自动匹配。
- [ ] 模块 3 脚本下拉只显示当前分镜组草稿。
- [ ] 切换脚本、手动修改和恢复导入版本均可用，状态提示准确。

### 10.2 AI 创作

- [ ] 四阶段真实进度可以从开始持续到完成或失败。
- [ ] TTS 真实时长成为视频、字幕和 BGM 的共同主轴。
- [ ] 场景匹配以 LLM 语义分矩阵为主信号；素材与脚本未变时重跑命中缓存（零 LLM 调用）且时间轴一致。
- [ ] 单素材失败不导致整组任务无条件失败。
- [ ] 刷新页面后能恢复任务真实状态。

### 10.3 预览与时间轴

- [ ] 9:16 和 3:4 预览均不覆盖播放器控制条或时间轴。
- [ ] 时间轴可横向滚动、纵向滚动、缩放和拖动播放头。
- [ ] 用户能看到视频、字幕、口播和 BGM 全部轨道。
- [ ] 视频片段排序、裁剪和保存后刷新仍保留。

### 10.4 封面

- [ ] 右栏展示真实封面缩略图，并能打开根级精调抽屉。

## 11. V1 之后

- 16:9 作为一等画幅完成全量验收。

- 可撤销/重做历史面板和更精细的键盘剪辑操作。

## 12. 已锁定决策

1. 第一步按模块 4 的 `shotSetId` 分组，不建立混合素材大池。
2. 第二步按同一 `shotSetId` 直接选择模块 3 脚本，保留手动编辑。
3. 自动创作采用真实四阶段进度。
4. 预览与时间轴严格分区，时间轴必须可滚动和缩放。
5. 封面使用根级精调抽屉、真实画面和持久化自定义预设。
6. 主副标题具有对等且独立的样式能力。
7. 导出文件名为 `成片-型号-日期`，型号来自 `productCode`。
8. 成片输出到当前项目的工作台成片目录，不落到孤立的下载目录。
9. V1 清晰度固定 1080 档（9:16 → 1080×1920，3:4 → 1080×1440）；2K 仅保留 `OUTPUT_PRESETS` 扩展口子，不进入本期验收。
10. 外部素材仅支持视频；静态图片为已否决需求，不做。
11. 场景匹配 = 缓存的 LLM 语义分矩阵（主信号）+ 确定性求解器 + 节拍吸附；LLM 打分失败降级为均匀矩阵继续，不中断。
