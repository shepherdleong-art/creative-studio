# 单条与批量混剪贴纸接入

**状态：** `ready-for-agent`

**日期：** 2026-11-17（UTC+8）  
**范围：** 将 dev 已有贴纸能力接入当前工作台，覆盖单条精准混剪与批量统一审片，兼容个人本地运行和团队统一生产服务。  
**本轮交付：** 规格与本地任务发布；尚未实施功能或运行功能验收。状态表示规格可进入实施，不表示本轮已经开始编码、提交、部署或发包。  
**任务入口：** [本地任务索引](../plans/2026-11-17-单条与批量混剪贴纸接入/README.md)。本文是产品行为与验收要求的唯一来源，具体代码落点由关联任务记录。

## Problem Statement

用户希望在现有工作台完成贴纸装饰、动效和批量差异化制作。dev 已具备贴纸素材库、单条编辑、自动布置与跨片随机变体，但当前分支没有这些能力。用户无法在当前正在使用的单条精准混剪和批量统一审片流程中直接完成这些操作。

当前分支同时拥有 dev 缺少的团队权限、正式产物登记、封面版本发布、统一封面编辑、专注剪辑布局及性能修复。整分支合并或整文件替换会使既有功能退回旧实现。用户需要完整接入贴纸，同时保住当前工作台的生产、审片与交付行为。

## Solution

在现有“视频包装”内提供“包装设置／贴纸”双页签。用户可以从四种风格的 115 张内置贴纸中搜索、点击或拖放添加，在预览直接调整位置、等比大小和旋转，在时间轴调整起止时间与层级，并选择六种动效。

用户可以一键生成开头、中段、结尾共六张基础贴纸，再继续调整。批量统一审片中的每条成片计划独立保存贴纸；用户完成一条后，可选择同批次版本的其他成片计划复制方案，为未编辑的自动贴纸生成素材、位置与动效变体。结果在生成时保存，之后预览、刷新和导出保持一致。

采用当前分支上的增量接入：复用 dev 的贴纸核心和素材，适配当前界面、授权、保存与发布链路。已有项目、关闭包装的项目、封面编辑、已排队任务和历史正式产物保持各自的既有语义。

## User Stories

1. 作为单条精准混剪用户，我希望在现有视频包装入口编辑贴纸，以便在同一工作台完成成片装饰。
2. 作为批量生产用户，我希望逐条编辑成片计划的贴纸，以便不同成片保留各自的制作决定。
3. 作为剪辑用户，我希望使用四种风格的完整 115 张内置贴纸，以便与现有四套包装搭配。
4. 作为剪辑用户，我希望按开头吸引、中段讲解、结尾引导、手势、箭头圈注及中文关键词筛选，以便快速找到合适素材。
5. 作为剪辑用户，我希望在当前模板和全部风格之间切换，以便既能统一风格也能明确混用素材。
6. 作为剪辑用户，我希望点击素材即新增贴纸，以便连续添加时不会误替换已选贴纸。
7. 作为剪辑用户，我希望拖入预览时按落点放置贴纸，以便直接决定画面位置。
8. 作为剪辑用户，我希望在画面中移动、等比缩放和旋转有效图案，以便透明边距不会干扰调整。
9. 作为剪辑用户，我希望在贴纸轨道整体移动和双边修剪，以便准确控制出现时间和持续时长。
10. 作为剪辑用户，我希望上下换轨改变贴纸层级而保持时间，以便处理同时出现的多个贴纸。
11. 作为剪辑用户，我希望使用可见磁吸开关和右键取消拖拽，以便精确编辑且能放弃尚未提交的操作。
12. 作为剪辑用户，我希望预览与时间轴同步选中，并能通过调整框或删除键删除，以便操作对象始终明确。
13. 作为剪辑用户，我希望撤销和重做贴纸编辑，以便尝试效果后恢复原有安排。
14. 作为剪辑用户，我希望同时比较柔和、Q 弹、上浮、滑入、缩放、无动画六种效果，以便直观选择。
15. 作为剪辑用户，我希望修改新增贴纸默认动效时保留已放置贴纸，以便不会意外重置已有调整。
16. 作为剪辑用户，我希望选中一张贴纸后只修改它的动效，以便突出特定内容。
17. 作为剪辑用户，我希望显式将动效应用到当前编辑范围的全部贴纸，以便统一效果且知道哪些调整会被覆盖。
18. 作为剪辑用户，我希望一键得到开头两张、中段两张、结尾两张基础贴纸，以便减少重复布置工作。
19. 作为剪辑用户，我希望正文或剩余时间不足时看到具体原因，以便改用合法的手动安排。
20. 作为剪辑用户，我希望“换一组”只替换自动组合并保留手动贴纸，以便已有人工设计不被覆盖。
21. 作为剪辑用户，我希望替换已编辑的自动组合前得到提醒，并能一次撤销整个替换，以便保护已花费的调整工作。
22. 作为剪辑用户，我希望共同功能贴纸跟随模板换风格时保持时间、位置和视觉大小，以便切换包装后不用重新摆放。
23. 作为剪辑用户，我希望跨风格固定贴纸和专属素材保留原风格，以便不会被换成不同含义的图案。
24. 作为剪辑用户，我希望关闭包装只隐藏贴纸，重新开启后恢复，以便比较有无包装的效果。
25. 作为剪辑用户，我希望刷新、重开和导出时看到相同贴纸安排，以便随机结果不会自行变化。
26. 作为批量生产用户，我希望选择多个有效目标复制贴纸，并优先使用已勾选目标，以便减少重复选择。
27. 作为批量生产用户，我希望看到无效目标及禁用原因，以便排除无法接收贴纸的成片计划后继续操作。
28. 作为批量生产用户，我希望提交前知道哪些目标的已有贴纸会被整体替换，以便避免误覆盖。
29. 作为批量生产用户，我希望复制仅改变贴纸和新增默认动效，以便目标自己的包装模板、字体、文案、卖点、版式、字幕、音频与画面设置保留。
30. 作为批量生产用户，我希望手动及已编辑自动贴纸按目标正文时长映射时间，以便保留设计意图并适配不同时长。
31. 作为批量生产用户，我希望未编辑自动贴纸按目标模板生成同类别的不同素材、位置和动效，以便降低成片雷同感。
32. 作为批量生产用户，我希望已删除的自动贴纸不会在复制时补回来，以便精简后的方案仍被尊重。
33. 作为批量生产用户，我希望贴纸变化后相应目标需要重新审核，以便已确认状态反映实际编辑内容。
34. 作为批量生产用户，我希望复制只发生在同项目、同批次、同当前批次版本，以便其他生产工作不被串改。
35. 作为多人协作用户，我希望来源或任一目标版本冲突时整次操作被拒绝，以便不会留下部分覆盖的结果。
36. 作为批量生产用户，我希望一次撤销或重做作用于上次复制的全部目标，以便整批操作保持一致。
37. 作为剪辑用户，我希望切换成片计划后旧请求和旧预览回调不再作用于新对象，以便不会串选中、串草稿或误保存。
38. 作为剪辑用户，我希望已排队任务按提交时的贴纸快照导出，以便后续编辑不会改变正在制作的版本。
39. 作为剪辑用户，我希望导出中的图案、位置、大小、层级和动效与预览一致，以便预览可以作为交付依据。
40. 作为剪辑用户，我希望贴纸只出现在正文且按轨道终点消失，以便不污染片头封面、不增加拖尾或成片帧数。
41. 作为剪辑用户，我希望缺图或素材校验失败时得到明确错误，以便不会把漏贴纸的成片误当作成功产物。
42. 作为团队成员，我希望登录后可以读取内置贴纸资源，以便在轻客户端正常浏览和预览。
43. 作为团队成员，我希望他人无法借贴纸接口读取或修改我的项目，以便既有项目隔离继续有效。
44. 作为剪辑用户，我希望修改封面、重新提取卖点或恢复文字版式后正文贴纸仍保留，以便不同编辑能力互不误伤。
45. 作为已有项目用户，我希望无贴纸的旧项目和显式关闭的包装保持原行为，以便升级后可以继续生产。
46. 作为剪辑用户，我希望在浅色、深色和较小窗口中完整访问贴纸控件与视频预览，以便沿用现有工作布局。
47. 作为工作台维护者，我希望生产产物完整携带贴纸资源且不依赖开发机目录或联网下载，以便部署后仍能预览和导出。
48. 作为团队成员，我希望带贴纸的正式产物继续正确登记、播放和下载，并保留封面历史版本，以便沿用现有交付流程。
49. 作为批量生产用户，我希望素材库按需读取缩略图、切换成片时保持现有加载机制，以便新增贴纸不会使工作台重新变慢。
50. 作为剪辑用户，我希望手动布置和自动变体使用内置资源与本地规则，以便无需为贴纸操作额外调用付费模型。

## Implementation Decisions

### D01 · 移植基线与模块边界

- 基线为当前分支的已核实实现与工作区已有修复；dev 固定提交作为能力来源。两个历史没有共同祖先，采用按职责增量移植，逐处核对现有调用者。
- 共享媒体层承载贴纸模型、素材解析、空间编辑桥、自动布置、时间轴规则和跨片变体。单条精准混剪与批量生产共用这些能力；批量生产保持只依赖共享媒体层的方向。
- UI 组件负责交互和状态协调，纯规划器负责随机、时间映射和槽位选择，保存命令负责权限、修订与事务。使用现有包装渲染链路，不增加第二套预览或动画引擎。
- 当前四模板编号与文案继续使用 f1–f4。保留当前统一封面编辑、工作区按需加载、专注剪辑布局及已有正式发布行为；不引入 dev 的旧实拍编辑入口。

### D02 · 素材与风格

- 四种素材风格与包装模板一一对应：圆润卡通 28 张对应花字种草，手帐拼贴 29 张对应手账拼贴，暖调杂志 29 张对应极简高级，立体综艺 29 张对应综艺撕纸。
- 原图为 115 张透明 PNG，素材库使用对应的 115 张 WebP 缩略图；原图、目录清单与共享运行时统一保存一份。目录提供功能 ID、中文名、分类、风格、尺寸、有效 alpha 包围框和 SHA-256。
- 默认查看当前模板，可按需查看全部风格；支持分类与中文搜索。只有预览或导出实际使用的原图进入对应加载路径。
- 28 个共同功能 ID 可跟随模板解析风格。从其他风格添加的素材固定为用户所选风格；`special` 因跨风格含义不同始终固定。切换模板保留实例时间、位置、旋转和有效图案宽度。
- 单份包装配置最多 128 个贴纸实例，沿用来源能力的数量上限；越界写入明确拒绝，不截断后保存。

### D03 · 面板、选中与空间编辑

- 包装卡内部使用“包装设置／贴纸”双页签；批量检查器顶层维持现有组织。点击另一素材始终新增贴纸。
- 点击添加以有效图案中心落在预览中央，连续添加轻微错位；拖放以松手位置为中心。初始有效图案宽度为画面宽度的 30%，保持原始宽高比。
- 预览支持移动、等比缩放、旋转及调整框删除。有效图案中心留在画布内，图案可部分超出并在导出时裁切；中心和尺寸按有效 alpha 包围框计算。
- 预览与时间轴双向选中，选中后自动打开贴纸页；点击预览空白取消选中。时间轴删除支持 Delete/Backspace，输入文字时保留文本编辑行为；从 iframe 转回轨道时显式管理焦点。
- 不恢复 dev 早期已取消的单张复制、右栏属性卡及位置数值输入；Ctrl/Cmd+D 不新增贴纸。现有其他轨道快捷键保持各自行为。
- 空间拖动可吸附画布中心、边缘和其他贴纸边缘；时间轴磁吸使用既有可见开关。拖拽中右键取消，恢复本次操作前状态且不生成历史。
- 操作中只维护本地草稿，松手后提交一次；切换目标、预览文档或版本后，旧手势及迟到回调失效。回调绑定正在编辑的对象及当前 iframe，统一封面预览不得截获正文贴纸操作。

### D04 · 时间与层级

- 使用 24fps 整帧，最终时间线前 20 帧为片头；贴纸起点最小为第 20 帧，终点为开区间，最大为第 20 帧加正文帧数。
- 手动添加从当前合法正文播放头开始，默认 48 帧。临近结尾按剩余帧数缩短；不足 19 帧拒绝添加，19 帧是最短时长。
- 批量时间轴继续以正文 0 秒为起点，与最终时间线的 20 帧偏移只在边界换算一次。时间轴移动与修剪吸附播放头、镜头边界、卖点边界及其他贴纸起止点。
- 贴纸轨道支持多贴纸同时出现；越靠上层级越高。换轨只改变层级，显示插入位置与占位，不修改起止时间。
- 画面总层级保持“视频及正片字幕 → 贴纸 → 包装主副标题和卖点文字”。贴纸动效完整包含在自身时间区间内，轨道终点之后不保留图案或动画尾部。

### D05 · 动效与自动布置

- 支持柔和、Q 弹、上浮、滑入、缩放和无动画；跟随模板时，花字种草、综艺撕纸采用 Q 弹，手账拼贴、极简高级采用柔和。短时长压缩入出场并保留稳定显示区间。
- 未选中贴纸时动效区编辑“新贴纸默认”，只影响之后新增；选中时编辑该实例，保存成功且新预览时间线就绪后播放实际效果。旧播放请求不得在切换之后执行。
- “应用到全部贴纸”显式更新当前编辑范围；存在个别动效覆盖时提示重置。单条沿用组级包装作用域，批量只作用于正在编辑的成片计划，不扩散到其他目标。
- 动效浮窗用同一示例图同时循环六张卡，关闭后停止；素材库不播放动画，不生成动画素材副本。
- 正文至少 144 帧时可一键布置六张：开头两张 opening，中段一张 explain 加一张 gesture，结尾两张 ending。同一阶段不重复，箭头和圈注不进入自动池。
- 沿用来源纯规划器的三等分阶段、阶段内 25%／75% 中心、19–48 帧时长和模板安全槽位。首次布置使用固定安全槽位；不进行全画面随机或 AI 遮挡分析。
- 六张实例共享自动组身份；人工移动、修剪、换轨、风格或动效调整标记为已编辑。“换一组”替换当前自动组合，保留手动实例；存在已编辑自动实例时先提示。自动组合全部删除后恢复首次布置入口。布置或换组均为一次可撤销操作。

### D06 · 配置、保存与兼容

- 贴纸实例与新增默认动效分别存入既有包装 JSON 的独立字段，不混入卖点。单条保存于组级包装，批量保存于各成片版本的包装配置；不新增数据库表或 schema 迁移。
- 实例保存稳定身份、功能素材 ID、固定／跟随模板风格、整帧起止、中心坐标、视觉宽度、旋转、轨道、动效和手动／自动来源。自动来源包含自动组身份和编辑标记。
- 旧配置缺省为无贴纸与模板推荐默认动效。修改其他包装字段时，未提交的贴纸字段保留；显式空数组表示清空。关闭包装只影响预览与导出，不删除配置。
- 读取旧数据可以兼容清洗，写入必须对原始请求中的贴纸及默认动效先严格校验。非法实例、重复 ID、数量越界及时间越界均拒绝；不得先清洗后以合法残余数据冒充成功保存。
- 覆盖普通包装保存、统一封面的整包应用、历史恢复与跨片恢复等所有写入入口。重新提取卖点、恢复文字版式和未修改的封面草稿应用都必须保留正文贴纸。
- 单条扩展已有组级修订命令与历史恢复能力；写入时确认关联成片草稿属于该组并按其正文时长校验。渲染任何成片草稿前重新检查帧边界，时间线缩短导致越界时明确拒绝导出，不静默裁掉贴纸。
- 批量沿用成片版本和编辑修订门禁；实质贴纸修改递增修订、清除对应审核确认，并影响完整渲染契约。纯正文贴纸变化不应额外重做封面或在保存时启动整片渲染。
- 编辑命令成功后才记录可回放历史；失败恢复或重取服务端状态，不显示虚假的保存成功。刷新可清空会话历史，但已保存的贴纸结果必须保留。

### D07 · 跨片复制、随机变体与事务

- 批量贴纸页提供“复制到其他成片”，来源无贴纸、包装关闭或不可编辑时禁用。仅列出同项目、同批次、同当前批次版本的其他成片计划；默认勾选已选且有效的目标，支持全选有效、清空和逐项调整。
- 无效目标显示具体原因。已有贴纸和已审核状态不阻断选择，但确认前分别提示整体替换和需重新审核。提交期间防止重复操作，成功数量来自实际事务结果。
- 只替换目标的贴纸与新增默认动效。目标其他包装、画面、字幕、音频和封面设置保持；来源不修改，也不进入撤销回写集合。
- 手动与已编辑自动实例保留素材选择规则、位置、大小、旋转、动效和相对层级；起止时间以正文相对帧按目标正文长度等比映射，再加片头偏移。映射后不足 19 帧或越界的目标整体不可复制，不丢弃实例或偷偷改时长。跟随模板的实例按目标模板解析实际风格；固定风格仍固定。
- 未编辑自动实例只复制来源仍存在的部分，按其开头／中段／结尾归属重排到目标三阶段；只有确实包含此类实例时，目标要求正文至少 144 帧。纯手动方案不套用六秒门禁。
- 自动素材从目标模板同类别池选择，同阶段去重，跨目标优先使用较少出现的素材；候选池不足时允许跨片重复，不承诺每条都唯一。位置在目标模板安全槽位内随机，尺寸、旋转与相对层级保留；每张独立抽取五种可见动效，不抽无动画或跟随模板。
- 每个目标生成新实例 ID 和新自动组 ID；已编辑自动实例保留自动来源及编辑标记，以维持后续换组提醒。随机只在本次显式命令执行时发生，返回和持久化同一结果，重做恢复原快照。
- 复制请求携带来源及全部目标的成片版本、编辑修订和稳定身份。服务端在同一事务内重验权限、谱系、可编辑状态和帧边界，再完成全部写入；来源或任一目标变化均整体拒绝，不部分成功。
- 恢复请求只接受贴纸与默认动效快照，并为每个目标携带当前预期版本与修订。一次撤销／重做覆盖同次复制的全部目标，修订继续递增，不倒写旧修订、不恢复旧审核确认；任一冲突则零写入，刷新相关目标并丢弃不可回放的历史。

### D08 · 共享预览、导出与发布

- 四套包装模板共用贴纸运行时、同一 GSAP 时间线和相同实例数据。共享透明预览与单条预览都注入贴纸配置、实际原图元数据及编辑桥，支持画内编辑与父页面时间同步。
- 入队时冻结贴纸、默认动效、模板及其他包装配置；渲染 worker 仅消费任务快照，不读取后续工作区配置，不重新规划随机结果。
- 正式包装按冻结配置解析实际原图，把共用运行时和用到的原图复制到私有任务目录，执行相对路径及 SHA-256 校验后渲染透明层，再叠加到底片。缺资源、校验异常或不支持模板明确失败，不能静默漏图发布。
- 保留当前透明预览的浅色文档配色契约、Windows 媒体工具显式传递、底片决定最终帧数和有限任务生命周期。贴纸不改变片头 20 帧、音轨、成片时长及封面构图。
- 保留当前正式产物登记、受管文件权限、封面独立版本、失败回滚与历史产物可读性。复制 dev 的贴纸渲染增量时，不替换当前发布编排。

### D09 · 团队权限、界面和生产资源

- 内置贴纸目录、缩略图及原图属于登录后可读资源；复制与恢复属于受项目／批次约束的写操作，进入当前路由分类、会话、CSRF 和资源授权体系。
- 对来源、目标、预期成片版本和嵌套快照引用逐项校验归属，不能只信任客户端传来的项目或批次 ID。继续执行当前领域访问上下文，不以新接口绕开既有门禁。
- 团队模式由统一生产服务保存、规划和渲染，工作台轻客户端负责交互与既有交付。个人本地运行复用相同领域能力，内置贴纸不增加外部模型请求。
- UI 采用当前设计令牌、字体和三态主题。贴纸轨道可保持可辨认的青绿色语义，但颜色须由令牌提供；沿用当前双侧栏／上下分隔、内部滚动、按需详情加载与取消旧请求机制。
- 通过现有生产资源白名单装配贴纸目录，保持隔离构建和构建后资源同步。不要用 dev 的旧文件追踪配置覆盖现有流程；生产产物不得依赖源码目录或开发机绝对路径。
- 贴纸运行资源随生产服务或个人完整工作台交付；轻客户端不因该功能携带本地生产后端。保持现有运行时版本锁、构建器来源核验和私有数据排除规则。

## Testing Decisions

### 验证边界

本规格沿用用户已认可的对比方案：以“真实编辑器操作 → 正式 API／保存命令 → 数据重载 → 正式导出”为主验证边界，覆盖用户可观察行为。继续使用现有应用、SQLite、HyperFrames 和 FFmpeg 测试设施，不为贴纸搭建另一套模拟后端或测试专用数据源。

高层闭环负责证明功能可用。以下情形在已有较低层公共边界补测：纯规划器的确定性与时间边界；事务冲突及非法输入；登录与资源权限；生产资源装配。测试断言实际配置、零写入、正式产物和帧内容，不锁死内部调用次数、组件拆分或源码字符串。

## Out of Scope

- 将 dev 整分支合并、替换当前工作台架构，或顺带迁移 dev 中与贴纸无关的功能。
- 本地实拍重组的新贴纸入口、classic/1 冻结模板改造、固定渲染命令新增贴纸输入；既有路径仅做受共享改动影响的回归。
- 自定义贴纸上传、素材市场、收藏／最近使用、自定义分组及自动生成新贴纸。
- 片头封面贴纸、AI 主体识别／遮挡避让、自动箭头指向；安全槽位不构成对任意画面都无遮挡的承诺。
- 单张复制、多选部分贴纸编辑、跨项目／批次／批次版本复制、非等比拉伸、镜像、逐帧关键帧和自定义动效曲线。
- 为贴纸新增数据库表、独立同步后台、第二份数据源，或改变单条组级包装为每个成片草稿独立保存。
- 改公司供应商、COS、LiteLLM、付费调度或用量规则；贴纸操作本身不调用外部模型。
- 本轮执行功能代码、发布服务器版本、生成分发安装包、推送提交或部署。后续实施中的生产构建与隔离验收不等于实际发布授权。
