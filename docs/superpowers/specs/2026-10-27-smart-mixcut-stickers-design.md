# 智能混剪贴纸系统设计

> 日期：2026-10-27
> 状态：交互、数据、渲染与验收方案已分四段确认，待书面规格审阅
> 范围：单条精准混剪 → 预览调整 → 包装
> 渲染边界：仅扩展现有 HyperFrames overlay 包装管线；不修改冻结的 classic/1

## 1. 目标

把四套包装对应的 115 张透明 PNG 贴纸整合进智能混剪，使用户可以：

- 通过点击或拖拽，把贴纸放到正文的任意整帧时间和画面位置。
- 在预览、时间轴和属性面板之间保持一致的选中、编辑和持久化状态。
- 使用可直观比较的固定组合动效，并统一或逐张设置。
- 一键生成“开头 + 中段 + 结尾引导”的 6 张基础贴纸，再继续增删改。
- 在正式导出中得到与预览一致的位置、时间、层级和动画结果。
- 以小步、可验证、可回退的 Git 检查点完成开发。

设计第一标准是直观、好用、易用和符合剪辑工具使用逻辑；时间预览轴交互优先参考剪映，但不照搬与首版无关的复杂能力。

## 2. 首版范围与非目标

### 2.1 首版包含

- 四套素材共 115 张全部接入。
- 单条精准混剪的贴纸素材库、预览编辑、时间轴、持久化和真实导出。
- 当前模板与全部风格混用、共同 ID 风格切换。
- 多贴纸并存、轨道即层级、整帧磁吸、撤销与重做。
- 六种组合动效、统一设置与单张覆盖。
- 一键基础布置与“换一组”。

### 2.2 首版不包含

- 片头 20 帧封面贴纸；正文从第 21 帧开始。
- 批量混剪的贴纸编辑入口或自动分配。
- classic/1 固定渲染模板改动。
- 多选部分贴纸后批量编辑。
- 收藏、最近使用、自定义素材分组。
- 非等比拉伸、镜像翻转、逐帧关键帧或自定义动画曲线编辑。
- 自动放置箭头和圈注，因为它们需要明确的指向目标。
- 为素材生成 GIF、视频或其他动画副本。

单条版完成基本验收时，必须提醒用户决定是否进入批量混剪贴纸阶段，不自动扩大范围。

## 3. 已确认的工作区交互

### 3.1 B+ 双页签

右栏保留一张“视频包装”卡，内部只设两个页签：

- **包装设置**：保留现有模板、字体和包装操作。
- **贴纸**：统一动效、一键基础布置、素材筛选、素材库和当前贴纸属性。

从预览或时间轴选中贴纸时，右栏自动进入“贴纸”页并显示紧凑的当前贴纸属性。素材库仍保持可见；点击另一张素材始终表示新增，不表示替换当前贴纸。

不采用独立长贴纸卡，也不增加第三个“动效”页签。

### 3.2 素材查找

- 默认显示“当前模板”，可切换“全部风格”。
- 分类为全部、开头吸引、中段讲解、结尾引导、手势、箭头圈注。
- 支持中文素材名搜索。
- 面板只加载轻量 WebP 缩略图；默认只加载当前模板，全部风格按需加载。
- 原图不进入素材库列表的批量加载路径。

### 3.3 包装总开关

贴纸随“视频包装”总开关启停。关闭包装时，贴纸不预览、不导出，但全部贴纸数据保留；重新开启后原样恢复。

## 4. 素材与模板映射

### 4.1 素材事实

源目录：

`H:\工具台包装测试\创意工作台-0.7.0-免安装版-20261019\GPT6生成包装\贴纸素材\warm_stickers_v3`

实际版本为 V3.1，共 115 张：

| 素材风格 | 数量 | 对应包装模板 |
| --- | ---: | --- |
| 圆润卡通 `comic` | 28 | A 花字种草 `overlay-poster` |
| 手帐拼贴 `journal` | 29 | B 手账拼贴 `overlay-journal` |
| 暖调杂志 `editorial` | 29 | C 极简高级 `overlay-minimal` |
| 立体综艺 `show` | 29 | D 综艺撕纸 `overlay-variety` |

素材按 `style + id` 识别，不使用文件名相似度、图像识别或中文文案猜测对应关系。

### 4.2 共同 ID 与专属素材

以下 28 个功能 ID 在四套中一一对应：

- 开头：`recommend`、`good_find`、`first_sight`、`something_special`、`home_surprise`、`look_here`
- 中段：`details`、`highlight`、`key_moment`、`another_angle`、`also_here`、`now_i_see`
- 结尾：`cart`、`save`、`more_details`、`take_home`、`worth_a_look`、`home_love`
- 手势：`like`、`ok`、`finger_heart`、`point_left`、`point_right`、`present`
- 圈注：`arrow_right`、`arrow_left`、`oval`、`round`

共同 ID 允许“跟随模板风格”。切换模板时保留实例的时间、位置、旋转和视觉大小，只替换对应风格的素材。

`special` 不是同一语义：show 为“哇！”，journal 为“喜欢”，editorial 为“细节”，comic 没有该素材。因此 `special` 强制为固定风格，不参与自动替换。

从“全部风格”添加的跨模板贴纸默认固定为所选风格；用户可以单独改回“跟随模板”。跨风格固定贴纸不因模板切换而丢失。

### 4.3 资源管理

- 原始 PNG 在共享贴纸资源目录只保存一份，不按模板重复复制。
- 统一清单记录 `style、id、category、label、file、width、height、alpha_gt8_bbox、sha256`。
- 轻量缩略图只用于面板；预览和正式导出读取原始 PNG。
- 导出任务必须携带或复制实际使用的原始素材，不能依赖开发机绝对路径。
- 素材缺失、哈希异常或读取失败时明确报错并停止相关导出，不静默跳过。

## 5. 手动添加与空间编辑

### 5.1 时间与初始尺寸

点击素材和拖入预览共用时间规则：

- 开始时间为当前播放头所在整帧。
- 默认时长 48 帧，即 24fps 下的 2 秒。
- 接近正文结尾时按剩余帧数缩短；不足 19 帧时不添加并提示。
- 19 帧约 0.792 秒，是首版最短贴纸时长。

空间规则：

- 点击添加：贴纸有效图案中心出现在画布中央，连续添加时轻微错位。
- 拖入预览：以松开鼠标的位置作为有效图案中心。
- 初始有效图案宽度为画面宽度的 30%。
- 尺寸按 `alpha_gt8_bbox` 计算，不按 PNG 透明画布计算。
- 始终保持素材原始宽高比。

### 5.2 编辑能力

- 支持拖动位置、等比缩放和旋转，不做自由拉伸及镜像。
- 拖近画布中心、边缘或其他贴纸边缘时显示对齐标线并吸附；离开吸附范围后可自由摆放。
- 有效图案中心不能离开画布；图案允许部分超出，导出按视频边界裁切。
- 点击预览或时间轴中的贴纸，另一处同步选中。

## 6. 时间轴与层级

### 6.1 帧模型

- 时间轴和渲染统一为 24fps 整帧。
- `startFrame` 是最终时间线的绝对帧号，最小为 `INTRO_FRAMES = 20`。
- `endFrame` 为开区间，最大为 `20 + bodyFrames`。
- 正文帧与最终时间线帧的换算只通过明确的 `bodyFrame = timelineFrame - 20` 完成。
- 入出场动画完整包含在 `[startFrame, endFrame)` 内；轨道终点就是完全消失的位置，不额外拖尾。

### 6.2 轨道组操作

- 新增可展开的“贴纸”轨道组；多个贴纸允许同时出现。
- 时间不重叠时可共享显示行，时间重叠时按轨道顺序分行。
- 支持整体拖动调时间、左右边缘修剪、Delete 删除、Ctrl/Cmd+D 复制。
- 复制保留素材、位置、尺寸、旋转和动效，默认紧接原贴纸之后。
- 所有添加、删除、移动、修剪、换轨、风格、动效和自动布置操作进入统一撤销／重做历史。
- 拖动过程只更新本地草稿，松开后一次提交；不在每次指针移动时写数据库。
- 首版不提供多选部分贴纸批量编辑。

### 6.3 磁吸与取消

- 复用现有可见“磁吸 开 / 关”按钮，不为贴纸新增 Alt 临时关闭。
- 吸附目标包括播放头、镜头边界、卖点边界和其他贴纸起止点。
- 贴纸换轨、调时和修剪过程中，单击右键取消本次拖拽并恢复原值，不打开右键菜单。
- Esc 不作为贴纸拖拽取消方式；现有其他轨道的快捷键行为不变。

### 6.4 轨道即层级

- 越靠上的贴纸轨道，画面层级越高。
- 上下拖动贴纸块换轨只改变层级，不改变开始时间或时长。
- 换轨时显示横向插入标线、目标轨高亮和半透明占位；松开才提交。
- 时间重叠的新贴纸默认放到最上方轨道。
- 属性区不设置层级按钮。

固定总层级：

`视频底片／正片字幕 → 贴纸 → 包装主副标题与卖点文字`

轨道顺序只管理贴纸之间的层级，不改动现有字幕和包装文字渲染顺序。

## 7. 动效系统

### 7.1 固定组合预设

首版只有以下六种组合预设，不提供自定义曲线编辑器：

| 预设 ID | 名称 | 入场与退场语义 |
| --- | --- | --- |
| `soft` | 柔和 | 淡入并轻微上浮，柔和淡出 |
| `bounce` | Q 弹 | 缩放淡入并轻微回弹，缩小淡出 |
| `rise` | 上浮 | 下方向上进入，向下淡出 |
| `slide` | 滑入 | 左侧进入，右侧淡出 |
| `zoom` | 缩放 | 平滑放大进入，缩小淡出 |
| `none` | 无动画 | 直接出现、直接消失 |

动画只使用透明度、位移和缩放，以 GSAP 时间线实现。默认入出场各约 0.25–0.35 秒，具体帧数由预设常量定义。

当贴纸总时长不足以完整播放动画时，入出场等比例压缩，各至少 1 帧，并至少保留 2 帧稳定显示；不得让动画超出 `endFrame`。

### 7.2 统一与单张设置

包装配置保存“统一动效”默认值，实例在创建时复制该值。修改默认值只影响之后新增的贴纸，不暗中修改已有贴纸。

默认值支持“跟随模板推荐”：

- `overlay-poster`、`overlay-variety` → `bounce`
- `overlay-journal`、`overlay-minimal` → `soft`

点击“应用到本视频全部贴纸”时，把当前统一设置显式写入全部已有实例。若存在不同的单张设置，先提示这会重置个别覆盖。

单张贴纸可以单独覆盖统一设置。实例保存的是 `follow-template` 或具体预设 ID，不保存一个会随默认值变化而变化的隐式继承引用。

### 7.3 动效选择小浮窗

- 从统一动效或当前贴纸的“预览动效”按钮旁弹出。
- 桌面端约 206px 宽，两列三行，无全屏遮罩，不覆盖视频预览和时间轴。
- 六张动效卡同时循环，便于直接比较，不逐个轮播。
- 所有卡片统一复用固定的 `show/highlight` 示例图，与当前模板和当前贴纸无关，也不让素材库运动。
- 点击卡片选择；选择、点击浮窗外部或点击 × 关闭。
- 浮窗关闭后停止示例动画；主视频预览用当前贴纸播放一次实际效果。
- 不生成任何动画版 PNG、GIF 或视频素材。

## 8. 一键基础布置

### 8.1 素材随机规则

点击“一键基础布置”后，从当前模板对应风格中一次生成 6 张：

- 开头：从 6 个 opening ID 中无重复抽取 2 张。
- 中段：从 explain 中抽 1 张，再从 gesture 中抽 1 张。
- 结尾：从 6 个 ending ID 中无重复抽取 2 张。

箭头和圈注不进入自动随机池。

随机只发生在点击时，由可注入随机源的纯规划器完成。选中的实例、时间和位置立即持久化，预览、刷新和导出不得再次随机。测试使用固定随机源验证结果。

### 8.2 时间规划

仅当 `bodyFrames >= 144`（6 秒）时允许自动布置，否则提示正文过短，建议手动添加。

- 用 `round(i * bodyFrames / 3)` 计算三个阶段边界，保证全部落在整帧。
- 每阶段两张贴纸的中心分别位于该阶段的 25% 和 75%。
- 默认时长为 `min(48, max(19, round(stageFrames * 0.4)))`。
- 起止帧按中心点和时长计算并限制在本阶段内，保持时长不变。
- 六张默认不在时间上重叠，也不进入片头。
- 动画继承生成时的统一动效。

### 8.3 空间规划

每套模板定义 6 个命名基础槽位，按开头、中段、结尾和左右／上下错落关系分配。槽位是固定常量，不使用全画面随机坐标，不依赖 AI 构图分析。实现验收以不遮挡正片字幕、视觉不过密和保持有效图案完整可读为准。

### 8.4 换一组与编辑保护

- 自动生成的 6 张共享 `autoGroupId`，初始 `autoEdited = false`。
- 用户移动、修剪、换轨、改风格或改动画后，对应实例标记为已编辑。
- 已存在自动组合时，按钮显示“换一组基础贴纸”。点击后替换当前自动组合并生成新的 6 张，不叠加为 12、18 张。
- 手动添加的贴纸不受影响；复制自动贴纸产生的新实例视为手动贴纸。
- 若当前自动组合中存在已编辑实例，换一组前明确提示这些调整会被重置；否则直接替换。
- 自动组合全部删除后，按钮恢复“一键基础布置”。
- 一键布置和换一组都作为一个原子历史操作，一次撤销即可恢复。

## 9. 数据模型与持久化

贴纸作为现有组级包装 JSON 的新增独立字段，不新建数据库表，不混入 `pointCues`。旧配置缺省为空数组和默认动效，无需重建数据库。

概念模型：

```ts
type StickerStyle = 'show' | 'comic' | 'journal' | 'editorial';
type StickerAnimation = 'follow-template' | 'soft' | 'bounce' | 'rise' | 'slide' | 'zoom' | 'none';

type PackagingStickerInstance = {
  id: string;
  assetId: string;
  styleMode: 'follow-template' | 'fixed';
  fixedStyle: StickerStyle | null;
  startFrame: number;
  endFrame: number;
  centerXPct: number;
  centerYPct: number;
  visualWidthPct: number;
  rotationDeg: number;
  trackIndex: number;
  animation: StickerAnimation;
  origin:
    | { kind: 'manual' }
    | { kind: 'auto'; autoGroupId: string; autoEdited: boolean };
};

type PackagingStickerDefaults = {
  animation: StickerAnimation;
};
```

约束：

- `assetId` 是功能 ID；实际文件由 `styleMode + fixedStyle + 当前模板` 解析。
- `styleMode = 'fixed'` 时 `fixedStyle` 必填；`styleMode = 'follow-template'` 时 `fixedStyle` 必须为 `null`。
- `special` 必须使用 `styleMode = 'fixed'`。
- `trackIndex` 越小，层级越高；换轨后归一化顺序。
- 中心点指有效图案包围框中心，不是 PNG 透明画布中心。
- 视觉宽度指有效包围框宽度；换风格时用新素材包围框重算原始图片显示尺寸，避免视觉跳变。
- 组级编辑继续使用现有 revision 乐观锁和串行命令；渲染按变体保存完整快照。
- 重新提取卖点、恢复文字版式不得清理贴纸。

## 10. 预览与导出架构

采用路线 A：扩展现有 HyperFrames 包装层。贴纸是新的独立实体，但复用现有透明 overlay 渲染管线，不另写 React 预览与 FFmpeg 动画双实现。

数据流：

`贴纸面板／时间轴 → 组级包装配置与 revision → 预览叠加层 → 渲染快照 → HyperFrames/GSAP 透明 WebM → FFmpeg 叠加成片`

必须满足：

- 预览、时间轴和导出读取同一份实例数据。
- 预览路由、渲染请求和 worker 的快照白名单全部显式包含贴纸及默认设置。
- 已排队任务使用排队时快照，后续编辑不改变该任务。
- 四套 overlay 模板共享贴纸运行时，不复制四套业务逻辑。
- 包装任务复制实际使用的原始 PNG 与共享运行时，不使用开发机绝对路径。
- `window.__timelines['overlay']` 继续作为预览／导出共用时间线；透明背景和 VP9 alpha 叠加约束不变。
- 不修改 classic/1 冻结资产、构建器和校验器。

建议的职责拆分：

| 单元 | 职责 |
| --- | --- |
| 贴纸目录与领域逻辑 | 清单、校验、风格解析、包围框几何、动效常量 |
| 自动布置规划器 | 可测试的随机抽取、三阶段帧规划、槽位分配 |
| StickerPanel | B+ 页签内容、筛选、统一动效、当前贴纸属性 |
| StickerAnimationPopover | 小浮窗及同图同时循环示例 |
| MixcutStickerTrack | 贴纸块、修剪、换轨标线、右键取消和选中同步 |
| 共享 overlay 贴纸运行时 | 实例挂载、帧可见性、层级和 GSAP 动画 |
| 包装任务与快照 | 持久化、资产复制、任务隔离和导出 |

避免继续把大量贴纸逻辑堆入已经较大的 `PackagingCard.tsx`、`PreviewStep.tsx` 或 `MixcutTimeline.tsx`；这些文件只保留集成与状态协调。

## 11. 异常、兼容与性能

- 包装未启用、正文不足或素材缺失时显示具体原因，不静默失败。
- 刷新、换项目和重新打开后恢复全部贴纸状态。
- 旧项目、无包装项目及没有贴纸字段的配置行为不变。
- 默认只加载当前模板缩略图，全部风格按需加载。
- 动效浮窗关闭后停止示例动画；素材库不播放动画。
- 时间轴拖动使用本地草稿，提交走现有组级 revision。
- 不改公司供应商、COS、LiteLLM 或媒体传输链路。

## 12. 验收标准

### 12.1 素材与面板

- 115 张素材清单、透明通道和哈希校验通过，缩略图可正常显示。
- B+ 双页签、当前／全部风格、分类搜索和选中联动符合定稿。
- 206px 小浮窗中所有动效以同一默认图片同时循环，关闭后停止。

### 12.2 手动编辑与时间轴

- 点击、拖拽添加及预览／时间轴双向选中正常。
- 移动、等比缩放、旋转、修剪、复制、删除、撤销和重做正常。
- 整帧起止、磁吸开关、右键取消、换轨插入标线和层级关系符合定稿。
- 刷新后状态一致，旧项目无回归。

### 12.3 自动布置

- 每次恰好生成 6 张，阶段、分类和同阶段不重复规则正确。
- 三阶段时间规划不越界、不进入片头，短视频门禁正确。
- 换一组只替换自动贴纸，手动贴纸保留；编辑提醒和一次撤销恢复有效。
- 预览、刷新和导出不会重新随机。

### 12.4 真实导出与回归

- 四套 overlay 模板分别完成真实成片导出，不只检查编辑器预览。
- 抽帧核对位置、尺寸、旋转、透明度、前后层级和六种动效。
- 起止帧与轨道一致，不多帧、不拖尾，预览与导出无可见偏差。
- 28 个共同 ID 换模板正确；`special` 与跨风格固定贴纸不被错误替换。
- 现有卖点、字幕、封面和 classic/1 回归结果不受影响。
