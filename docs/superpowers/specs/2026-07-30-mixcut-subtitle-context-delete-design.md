# 智能混剪字幕右键删除设计

## 目标

在“预览调整”时间线中，为字幕块增加与视频片段一致的右键删除入口。用户分割字幕后，无需切换工具或进入右侧检查器，即可删除其中一段字幕。

## 交互设计

- 在“选择”和“分割”两种工具模式下，右键任意字幕块均打开时间线上下文菜单。
- 打开菜单时选中被右键的字幕，但不移动播放头，也不触发字幕分割。
- 菜单显示红色危险操作“删除字幕”，沿用视频片段删除菜单的尺寸、位置约束和视觉样式。
- 点击“删除字幕”后立即关闭菜单，并提交现有的 `delete_subtitle_cue` 分组命令。
- 服务端接受删除后，如果当前选中的正是该字幕，则清除字幕选中态。
- 点击菜单外部、按 Esc 或窗口失焦时关闭菜单。
- 编辑被禁用时，不打开菜单，也不提交删除命令。

## 数据流与边界

本功能只改时间线交互层。`delete_subtitle_cue` 命令、服务端校验、修订号控制和字幕持久化均已存在，继续通过 `PreviewStep` 的分组命令队列执行。

删除单条字幕只从 `subtitleCues` 中移除目标 Cue，并在原时间范围留下字幕空白；不调整口播音频、视频片段、其他字幕或成片时长。失败时沿用现有命令队列的错误提示与重新同步行为。

## 实现范围

- 扩展 `MixcutTimeline` 的上下文菜单状态，使其支持字幕 Cue ID。
- 由 `SubtitleBlock` 把右键坐标和 Cue ID传回时间线，并阻止浏览器原生菜单及父级指针行为。
- 在共享时间线上下文菜单中渲染“删除字幕”，提交 `delete_subtitle_cue`。
- 更新时间线操作提示，使用户能发现字幕右键删除能力。

不新增后端命令、数据库迁移、确认弹窗、批量删除或撤销能力。

## 验证

- 端到端测试：分割字幕后右键其中一个新 Cue，确认出现“删除字幕”。
- 断言请求提交 `delete_subtitle_cue` 和正确的 `cueId`。
- 断言服务端响应后该字幕块从时间线消失。
- 断言分割模式下右键不会额外提交 `split_subtitle_cue`，也不会移动播放头。
- 运行 Mixcut UI 合约测试、相关 Playwright 测试、ESLint 和生产构建。
