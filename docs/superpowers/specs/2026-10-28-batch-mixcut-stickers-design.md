# 批量混剪贴纸与跨片随机变体设计

> 日期：2026-10-28
> 状态：已定稿；B1–B7 实施与针对性验收完成
> 验收：真实批量编辑器、双目标整体撤销／重做、四模板真实导出及生产构建均通过
> 前置能力：单条精准混剪贴纸首版已完成
> 范围：批量生产 → 统一审片 → 当前成片包装与跨片复制
> 渲染边界：复用现有 HyperFrames overlay 贴纸运行时，不修改 classic/1

## 1. 目标

把单条精准混剪的贴纸编辑能力接入批量统一审片，并提供可靠的“复制到其他成片”能力：

- 每条成片可以独立添加、编辑、自动布置和导出贴纸。
- 用户可以从一条来源成片选择多个目标成片，一次复制贴纸方案。
- 目标片在保持三阶段结构的同时获得不同素材、位置和动效，降低批量成片的雷同感。
- 多目标保存、撤销和重做必须整体成功或整体失败，不能留下半批结果。
- 预览、刷新、切换成片和正式导出始终读取已保存结果，不重新随机。

## 2. 已确认范围

### 2.1 本版包含

- 当前成片完整复用最新单条贴纸能力：115 张素材、分类搜索、点击／拖放添加、预览空间编辑、删除、时间轴调时／修剪／换轨、六动效、一键基础布置和换一组。
- 跨片复制弹窗、目标多选、无效目标原因、已有贴纸替换提示和已审核重审提示。
- 手动贴纸与已编辑自动贴纸的时间比例映射。
- 未编辑自动贴纸的三阶段重排，以及同类别素材、安全槽位和每张独立动效的随机变体。
- 批次级事务保存和多片整体撤销／重做。
- 批量实时预览、正式导出、任务快照与真实浏览器／渲染验收。

### 2.2 本版不包含

- 跨项目、跨批次或跨批次版本复制。
- 多选部分贴纸后编辑，或把单张贴纸复制到另一片。
- 全画面随机坐标、随机非等比尺寸、随机旋转或自定义随机动画曲线。
- 用 AI 分析画面构图、字幕遮挡或贴纸指向目标。
- 独立批量贴纸方案表、后台同步任务或第二份贴纸数据源。
- classic/1 固定渲染模板改动。

## 3. 当前成片编辑交互

入口为“批量统一审片 → 选择成片 → 包装 → 贴纸”。包装页内部保留“包装设置／贴纸”双页签，不在检查器顶层增加第六个页签。

- 从预览或时间轴选中贴纸时，自动进入贴纸页并同步当前成片。
- 中央预览、右栏和时间轴始终编辑同一 `planId + outputVersionId`；切片的选中、草稿和忙碌状态不得串用。
- “应用到全部贴纸”和“换一组”只影响当前成片。
- 删除只保留预览调整框按钮与 `Delete/Backspace`；不恢复复制贴纸、属性卡片或位置数值界面。
- 贴纸轨道沿用中文素材名、固定青绿区分色、轨道即层级、右键取消拖拽和可见磁吸开关。
- 包装关闭时贴纸不预览、不导出但保留数据；重新开启后原样恢复。

## 4. 跨片复制弹窗

贴纸页提供醒目的“复制到其他成片”按钮。来源片没有贴纸、当前不可编辑或包装未开启时禁用并说明原因。

弹窗遵守以下规则：

- 只列出同项目、同批次、同当前批次版本中除来源外的成片。
- 默认勾选时间轴已勾选且有效的目标；支持全选有效目标、清空和逐片调整。
- 每项显示成片序号、标题、是否已有贴纸、是否已审核及不可复制原因。
- 已有贴纸和已审核不是阻断项，但确认区必须明确提示“替换全部现有贴纸”和“修改后需重新审核”。
- 包装未开启、正文无法容纳实际复制内容、版本不可用或当前不可编辑的目标禁用；用户排除其余无效项后可继续。
- 确认按钮为“复制并生成变体”。提交期间禁止重复操作；成功后展示实际写入数量，失败不宣称部分完成。
- 来源片不被修改，也不进入复制历史的回写集合。

## 5. 复制内容与身份

只复制 `stickers` 和 `stickerDefaults`。目标片自己的包装模板、字体、文案、卖点、版式、字幕、音频和画面设置全部保留。

每条目标片中的全部贴纸获得新实例 ID；每个来源自动组合在每条目标片中获得新的 `autoGroupId`。来源自动实例的 `origin.kind = auto` 与 `autoEdited` 标记保留，已编辑自动实例只在本次复制的时间算法中按手动处理，不改造成手动来源。目标之后仍可执行换一组，已编辑实例继续受重置提醒保护。

所有实例保留来源 `trackIndex` 的相对层级，并通过现有轨道归一化逻辑整理；贴纸之间仍由轨道顺序决定层级，包装文字始终位于贴纸上方。

## 6. 时间适配算法

统一使用 24fps 整帧和片头 `INTRO = 20`，正文帧数记为 `sourceBodyFrames / targetBodyFrames`。

### 6.1 手动与已编辑自动贴纸

以正文相对帧做等比映射：

```text
mappedStart = round((startFrame - INTRO) * targetBodyFrames / sourceBodyFrames)
mappedEnd   = round((endFrame   - INTRO) * targetBodyFrames / sourceBodyFrames)
newStart    = INTRO + mappedStart
newEnd      = INTRO + mappedEnd
```

素材、固定／跟随模板风格、位置、尺寸、旋转、动效和轨道保持不变。映射后必须满足：

- `newStart >= 20`。
- `newEnd <= 20 + targetBodyFrames`。
- `newEnd - newStart >= 19`。

任一实例不满足时，该目标在提交前标记为不可复制，不静默缩短、丢弃或 clamp 成另一种结果。

### 6.2 未编辑自动贴纸

- 仅复制来源仍存在的实例，不补回来源已经删除的自动贴纸。
- 按来源中点所在正文三分之一判定开头／中段／结尾；按阶段内中点顺序判定 25%／75% 槽位。
- 使用与一键基础布置相同的三阶段边界、阶段内中心点、`min(48, max(19, round(stageFrames * 0.4)))` 时长和阶段内夹取规则，按目标正文重新计算起止帧。
- 只有实际包含未编辑自动贴纸时，目标才要求 `targetBodyFrames >= 144`；纯手动复制不错误套用 6 秒门禁。

## 7. 自动贴纸随机变体

随机规划器位于共享领域层，注入随机源和 ID 生成器；不得把随机算法写进 React 或在渲染时执行。

### 7.1 素材

- 从目标模板对应风格、相同功能类别中抽取：opening、explain、gesture、ending 各自保持原语义。
- 同一目标同一阶段不重复；完整六张组合仍表现为开头 2 张、中段讲解＋手势、结尾 2 张。
- 本次命令维护来源及各目标的类别使用记录，优先随机抽取使用次数最少的候选，使不同成片尽量不同。
- 候选池不足时按“先保证同阶段不重复，再允许跨片重复”的顺序放宽，不报错、不无限循环。
- 自动实例继续使用 `follow-template`，实际风格随目标自己的模板解析。

### 7.2 位置与尺寸

- 只从目标模板的 `PACKAGING_STICKER_AUTO_SLOTS` 安全槽位选择中心点。
- 开头与结尾在所属阶段的左右槽位中随机；中段在讲解／手势两个安全槽位中随机，避免全画面坐标随机。
- 同阶段两张优先使用不同槽位；只保留一张时使用该阶段任一安全槽位。
- 保留来源实例的视觉宽度、旋转和轨道，不随机尺寸或角度。

### 7.3 动效

每张未编辑自动贴纸独立从 `soft / bounce / rise / slide / zoom` 抽取一种可见动效；不抽 `none` 或 `follow-template`。不同贴纸允许不同动效，这是已确认的批量变体特征。手动及已编辑自动贴纸保留原来源动效。

`stickerDefaults` 按来源原样复制，只影响目标之后新增的贴纸，不回写本次随机实例。

## 8. 持久化、事务与历史

### 8.1 数据模型

继续使用每条成片 `arrangement.packaging.stickers / stickerDefaults`，不新增数据库表或迁移。服务端写入继续使用严格贴纸校验，旧配置缺省为空数组与默认动效。

### 8.2 批次级复制命令

新增批次级命令，输入来源 `planId`、目标 `planId[]` 及各目标期望 `outputVersionId + editRevision`。命令必须：

1. 验证批次已冻结、未停止，来源和目标均属于当前批次版本。
2. 在一个 SQLite 事务内重读所有谱系与修订，拒绝空目标、重复目标、来源自复制和跨批次目标。
3. 校验来源与目标包装已开启、目标可编辑、目标时长和素材目录。
4. 用固定输入一次生成全部目标结果，逐片只替换贴纸字段。
5. 任一校验、版本冲突或写入失败时整体回滚；全部成功后一次提交。
6. 按现有视觉编辑规则递增目标修订并清除目标审核态，不修改来源审核态。

不得在事务中调用 LLM、供应商、ffmpeg 或网络服务。

### 8.3 整体撤销与重做

批量历史项保存每个目标的包装前后快照及修订信息。撤销／重做通过批次级事务恢复所有目标：

- 任一片已有更新正式编辑或版本不一致时，整次恢复被拒绝，不能恢复其他片后再报冲突。
- 成功后刷新所有受影响 arrangement，并把整个历史项移到另一历史栈。
- 普通单片编辑继续使用现有历史项；两种历史项共用同一撤销／重做入口和容量上限。

## 9. 预览与正式导出

- 批量包装预览显式注入贴纸实例、默认动效、实际 PNG 资产和贴纸编辑桥；父页面处理选中、空间提交、删除和空白取消选中。
- 预览 iframe 的重载与动效播放沿用单条请求序号和就绪检查，避免保存后播放旧时间线。
- 批量正式渲染把任务快照中的贴纸及实际使用原图交给现有 HyperFrames 管线；运行资源只包含快照实际使用素材。
- 已排队任务使用排队时快照，后续复制、编辑或换一组不改变旧任务。
- 原图缺失、哈希异常或读取失败时明确停止相关导出，不静默跳过贴纸。
- 四套 overlay 继续共享同一贴纸运行时；不修改 classic/1、冻结资产、构建器或校验器。

## 10. 异常与兼容

- 旧批量项目没有贴纸字段时行为不变。
- 重新提取卖点、恢复文案或文字版式不得清理贴纸。
- 切换成片、刷新页面或重新打开批次后恢复各自贴纸与编辑结果。
- 复制中的随机结果只生成一次；预览、导出、撤销后重做均使用持久化结果，不再次随机。
- 目标已有贴纸被替换后可整体撤销恢复；目标已审核被清除后按现有规则重新审核。
- 批量统一审片指定 PRD／执行文档在当前工作树与 Git 历史中均未找到；不虚构其中条款。实施保持代码内已标记的 v14 行筛选、眼睛预览、选择、审核和导出行为不变。

## 11. 验收标准

### 11.1 领域与 API

- 比例映射、整帧、19 帧下限、20 帧片头、144 帧自动门禁和短视频判断正确。
- 自动结构、部分自动组合、类别抽样、跨片去重、池耗尽回退、安全槽位和五种随机动效符合规格。
- 固定随机源结果可重复；不同调用时间不影响已保存结果。
- 只修改目标贴纸字段，来源与目标其他包装／成片字段不变。
- 空目标、重复目标、跨批次、版本冲突和不可编辑输入均被拒绝。
- 多目标复制、撤销和重做均整体提交或整体回滚，审核失效正确。

### 11.2 真实编辑器

- 当前成片添加、预览空间编辑、删除、时间轴调时／修剪／换轨、动效和自动布置正常。
- 预览／时间轴／右栏选中同步，切片不串贴纸、草稿或忙碌状态。
- 弹窗默认目标、全选／清空、已有贴纸提示、无效原因和排除后提交正常。
- 复制后目标出现持久化变体，一次整体撤销／重做恢复所有目标。
- 包装开关、刷新和旧项目行为不回归。

### 11.3 真实导出与回归

- 至少两条不同正文时长的目标片完成真实批量导出，验证各自时间适配和不同变体。
- 四套模板均验证贴纸资源解析与正式导出；抽查三阶段、动效、位置、层级、透明度和片头无贴纸。
- 已排队任务快照不随后续编辑漂移，刷新和导出不会重新随机。
- 单条贴纸、批量包装、卖点、字幕、封面、审核与 classic/1 回归不受影响。
- 变更文件 lint、TypeScript 与生产构建通过；冻结目录零改动。

## 12. 实施与交付边界

按“文档 → 领域与事务 → 当前片编辑器 → 跨片弹窗 → 预览渲染 → 全量验收”分阶段提交。每阶段先运行针对性测试，再提交并双推 `origin/master` 与 `shepherd/dev`；网络失败时明确记录待推送状态，不把本地提交冒充远程交付。
