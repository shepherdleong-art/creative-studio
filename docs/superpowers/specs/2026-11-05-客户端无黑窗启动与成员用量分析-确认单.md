## 一、无黑窗客户端

- 新 Windows 包提供带应用图标的 `Creative Studio.exe`，作为使用说明及快捷方式指向的默认入口。正常启动全程无控制台闪现，客户端窗口正常可见和可操作。
- 使用 C#/.NET Framework 的 Windows GUI 启动器，编译为 WinExe，由 Windows 装配流程构建。直接隐藏运行包内运行时及稳定 launcher，不经 CMD；启动错误记录到客户端日志，并以中文弹窗提示原因和日志位置。
- 沿用签名、版本指针和更新健康提交状态校验。仅隐藏后台启动过程；用户可见的 Electron 仍保持 `windowsHide:false`，沿用独立日志、detached 与 unref 行为。
- 启动器退出不影响客户端。进程创建成功不等于应用健康成功，后续健康状态仍交由原有机制处理。
- 保留原 CMD 为明确标注的诊断入口，不再作为日常启动入口；同步打包白名单、包边界测试及使用说明。
- **只更新以后分发的新包**：不制作旧包补丁，不替换现有客户端或快捷方式，不修改连接模式、服务器地址和在线更新协议。本轮功能不通过版本内在线更新包宣称覆盖旧入口。

## 二、管理员成员总览

页面顺序：**团队本月额度摘要 → 筛选 → 成员费用排行及完整成员表 → 默认收起的全团队调用明细**。

- 默认全团队、本月、全部模型、全部结果。保留仅看自己、刷新及管理员 CSV 导出。
- 日期选项为今日、近 7 天、本周、本月、自选日期；沿用模型、结果筛选。北京时间自然日与自然月、周一起算、左闭右开查询边界。
- 顶部显示本月已计、已结算、待结算预留、有限额度合计及剩余、不限额成员数，明确其自然月账期不随分析筛选变化。
- 成员按筛选期已计费用降序，同金额按工号稳定排序。横条图展示前 10 位成员，标注金额、调用次数及“前 10 位”；完整表保留全部成员，包括零用量和已有停用成员。
- 表格显示姓名、工号、角色、期间调用次数、期间已计、本月已计、月度额度、剩余可用及查看用量入口；不限额不能显示成零元。
- 图中的成员及表格入口都能打开对应成员详情。首页不再先展示团队模型排行、模型趋势，也不新增团队总趋势。
- 成员表后保留默认收起、按需展开的全团队调用明细；导出沿用当前分析范围，不受图表前 10 位限制。

## 三、成员详情与员工视图

页面顺序：**成员身份与本月额度 → 筛选 → 模型费用排行及每日模型趋势 → 调用明细**。

- 管理员详情明确显示成员姓名、工号及返回全团队入口；进入时继承首页筛选，详情内调整不覆盖首页状态，返回恢复进入前筛选和列表位置。
- 模型费用排行包含模型名称、调用次数、已计费用、占比和横条比较，按费用降序；每日模型趋势沿用 SVG、日期及金额坐标、图例、悬浮与键盘提示，真正无调用的日期补零。
- 调用明细保留时间、模型、模块、结果、费用和可展开的任务、请求关联；不增加模块或项目费用分析。
- 普通员工直接进入自己的模型统计和明细，默认本月；没有团队列表、范围开关、他人详情或团队 CSV 操作。管理员仅看自己使用相同个人视图，仍可返回团队范围。
- 加载、空数据和失败分别显示；切换成员时不展示上一成员数据。支持浅色、深色、跟随系统及窄窗口，颜色使用设计令牌。

## 四、接口与费用语义

- 复用团队用量 GET、指定成员参数及 CSV；不新增账本、迁移、统计服务或图表依赖。管理员页面显式请求团队范围，接口未传范围仍默认本人，保持既有调用方兼容。
- 复用现有成员、模型、趋势及额度摘要；成员汇总新增筛选期未定价、不确定调用数，供列表和排行提示，现有字段保持兼容。权限由服务端校验，不能靠前端过滤全团队响应实现员工隔离。
- 用量以人民币已计费用为主、调用次数为辅。调用次数是实际执行尝试，包括真实重试与协议回退，不等于任务数。
- 沿用现有整数分账本：结算计实际费用，有效预留按现有规则计入已计，已释放不计入，预留不重复相加。不确定费用即使保留预留金额也必须附状态提示。
- 未定价不能表示免费，仅含未知费用的成员或模型不得只显示零元；无调用的真实零值与存在未知费用必须区分。导出也不得将未知状态伪装成零费用。
- 不增加 Token、图片张数、视频秒数、模块或项目统计，不修改定价、权限、额度、并发、供应商或生产策略。本地 Agent 仍不计入，金额仍不等于供应商最终账单；本地版保持原状。

## 五、验收和交付

- 新包从资源管理器双击默认入口验收全程无可见控制台、GUI 可操作、启动器退出后客户端存活；覆盖中文空格路径、运行时缺失、签名异常、进程创建失败、日志及诊断入口。不能用隐藏创建 CMD 的测试代替真实入口验收。
- 用量验收覆盖管理员总览、管理员详情、普通员工，多成员多模型对账、筛选和返回恢复、CSV 范围，以及越权请求。
- 数据场景覆盖结算、有效预留、释放、未定价、不确定、重试、零用量、停用成员、同金额排序、超过 10 位成员和跨月边界。
- 页面覆盖桌面、窄窗口、浅色、深色、长模型名、图表提示及加载/空/失败状态；未知费用不能通过图表被误读为免费。
- 各功能票自带定向自动测试及可演示验收，综合验收再完成 TypeScript、定向 ESLint、生产构建和浏览器检查。客户端单独完成真实入口与装配验收，不阻塞用量页面验收。
- 测试使用隔离数据根、临时包及测试签名，不产生真实付费调用，不关闭现有客户端，不调用关闭服务器端点。源码与测试包完成不等于已向员工分发或已部署服务器。
