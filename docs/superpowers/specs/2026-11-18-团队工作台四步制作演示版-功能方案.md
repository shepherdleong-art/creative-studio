# 团队工作台四步制作演示版

**状态：** `ready-for-agent`

2026-11-18 · 供 DeepSeek 实现、IT 接手、PM 验收。[本地任务入口](../plans/2026-11-18-团队工作台四步制作演示版/01-规格与实施入口.md)

## Problem Statement

IT 要根据一个能实际出片的工作台重写公司产品。PM 会自己带商品图试跑，需要看清楚一份可编辑的脚本文案和一组视频怎样进入混剪，以及预览里的镜头、包装和贴纸怎样出现在最终 MP4 中。

现有团队工作台已经具备大部分能力。这个演示版要收起无关入口，补齐管理员查看员工界面和员工跨项目复用个人提示词的操作。PM 还需要拿已有的视频和文字直接做单条或批量成片，验证后半段流程。

## Solution

**以现在的团队工作台为底，在同一仓库的独立分支上交付可运行的 Demo。** 使用现有团队模式在本机浏览器预览，复用管理员、员工账号和统一生产服务。PM 可以在常规项目中完成生图、生视频、写脚本、混剪四项工作。生图沿用「场景图」「分镜」两个页签，视频任务提交后即可去写脚本。

| 相对当前团队版的五处改动 | Demo 中的行为 |
| --- | --- |
| 关闭创作画布 | 关闭独立创作画布的导航、页面、接口和执行器。混剪时间线、包装预览与贴纸编辑照常可用。 |
| 移除实拍混剪入口 | 移除首页「实拍混剪」占位卡，沿用团队模式对本地实拍重组的禁用策略。两个混剪入口都保留普通视频导入。 |
| AI 写脚本只留爆文模板改写 | 首次生成、换模板和再生成均走爆文改写。保留商品卖点提取与复用、模板选择、人工编辑及保存项目脚本。 |
| 管理员一键查看用户视角 | 管理员在自己的登录会话中一键进入员工界面，也能一键返回管理界面。切换入口只对管理员开放。 |
| 员工跨项目保存「我的常用」 | 场景、分镜、视频运镜均支持从空白手写整段提示词，也可选择预设后自由改写。员工可保存个人常用词，在自己的其他项目继续使用。公共预设由管理员维护。 |

**单条精准混剪和批量生产都支持以下四种输入组合。** 自带脚本文案指用户已有的文字，可以直接输入、粘贴或用所在入口已有的文字导入方式带入。需要配音时，由混剪根据选定的文字生成。

| 视频来源 | 用已保存的爆文改写项目脚本 | 用自带脚本文案 |
| --- | --- | --- |
| 项目生成的模块 4 素材 | 单条、批量均可 | 单条、批量均可 |
| 用户导入的视频素材 | 单条、批量均可 | 单条、批量均可，可直接从混剪开始 |

## User Stories

1. 作为 IT 同事，我希望从现有仓库拉取独立 Demo 分支，在本机启动团队工作台，以便对照界面、源码和成片重写公司产品。
2. 作为管理员，我希望上传业务交给我的现用爆文 Excel，预览并发布这一版模板，以便员工统一选用我维护的内容。
3. 作为管理员，我希望维护公共提示词、供应商、可用模型和默认参数，以便员工在可用的配置范围内自行创作。
4. 作为管理员，我希望一键查看用户视角并一键返回，以便亲自检查员工能选什么模板、看到哪些制作入口。
5. 作为员工，我希望登录后直接使用制作界面，以便独立完成项目操作，公共资源的发布交由管理员负责。
6. 作为员工，我希望按商品选画幅、准备场景图和分镜组，以便挑选合适的分镜用于视频生成。
7. 作为员工，我希望在场景、分镜和视频运镜中自由写提示词，也能改写选中的预设，以便按本次商品和镜头调整表达。
8. 作为员工，我希望将提示词存入「我的常用」，在另一个项目取出、编辑或复用，以便积累自己的写法，并与公共预设分开管理。
9. 作为员工，我希望自己选用管理员配好的可用模型，以及该模型支持的视频时长，以便控制本次生成效果。
10. 作为员工，我希望从商品详情页提取卖点，或复用本项目已保存的卖点，再选爆文模板改写，以便得到符合这个商品的脚本文案。
11. 作为员工，我希望换模板再生成、编辑满意的一稿并保存为项目脚本版本，以便把自己最后确认的文字带进两种混剪。
12. 作为单条精准混剪用户，我希望在当前分镜组选择项目生成的视频，或导入自己的视频，以便决定这条片用哪些画面。
13. 作为单条精准混剪用户，我希望既能选项目脚本，也能直接带入自己的文字，以便只用自带视频和文案也能剪出一条片。
14. 作为批量生产用户，我希望从项目素材库选择模块 4 素材或自己导入的视频，确定批次素材池，以便指定这一批可用的画面。
15. 作为批量生产用户，我希望选择项目脚本或导入已有文字脚本，并按脚本设定生成份数，以便用自带内容或项目生成内容生产多条片。
16. 作为剪辑用户，我希望分别选择视频来源和文案来源，以便给自带视频配改写脚本，或给生成的视频配自己的文案。
17. 作为剪辑用户，我希望在两种混剪里都能从四套现有包装中选一套，修改标题和卖点文字，调整贴纸的位置、大小和出现时段，以便直接在预览中完成成片版式。
18. 作为批量审片用户，我希望单独给一条成片换镜头、调包装或加贴纸，以便分别确认和导出每一条成片版本。
19. 作为验收 PM，我希望用自己的素材跑通生成，并直接打开单条及批量导出的 MP4，以便核对保存的文案、画面、包装和贴纸是否都用到了。

## Implementation Decisions

- **工作台轻客户端和本机浏览器共用团队业务页面。** 制作任务由统一生产服务执行，沿用该服务的项目、权限、任务和正式产物记录。本机预览使用团队登录和演示数据根。
- 在 Demo 启动配置中显式关闭创作画布，同时移除首页的实拍混剪卡片。独立创作画布的开关作用于导航、页面和后台执行。导入普通视频所用的媒体处理、混剪编辑器继续服务于两种混剪。
- **爆文改写是 Demo 唯一可发起的 AI 写作模式。** 首次生成、从结果页再生成、打开旧项目后发起的新生成都遵守同一规则。提取或复用卖点是改写的前置步骤。人工编辑和导入文字可以独立进行。已有项目脚本和已开跑批次的脚本快照沿用原有版本规则。
- IT 使用现有 Excel 流程首次导入和更新爆文模板。公共模板发布、公共提示词及供应商配置的写操作均由服务端验证管理员身份。管理员进入用户视角时，看到普通制作导航、公共预设和自己的常用词，可以在自己的项目验证设置。返回后恢复管理界面，全程使用本人的登录身份。员工直接访问管理操作也受同一权限约束。
- **「我的常用」归员工账号所有。** 员工能在制作界面自由输入、选公共预设、保存及调用自己的常用词。在一个项目保存后，可在同一账号的其他项目读写。改写公共预设后，生成任务采用改过的全文，另存结果归入本人常用。复用现有运镜模板的私有归属能力，将保存和选用覆盖到场景、分镜及视频运镜。
- 供应商凭据、可用模型和全局默认值由管理员配置。项目画幅、已开放模型、模型支持的时长、批次脚本的生成份数由员工选择。任务提交沿用服务端既有准入规则。
- 单条精准混剪在项目与当前分镜组内读取视频。批量生产按用户明确选定的批次素材池和批次脚本开跑。两种模式的空状态都应指明如何导入自带视频、带入文字。包装、贴纸及正式渲染采用各自已保存的成片编辑结果。

## Testing Decisions

**主验收入口是本机团队工作台的真实浏览器会话，终点是下载并打开正式 MP4。** IT 用管理员账号导入现用 Excel、配置可用模型。PM 用员工账号自备商品图、详情页、视频和文字，重点检查脚本到混剪、预览到成片的交接。以下是实施后的通过条件。

| 验收项 | 操作及通过条件 |
| --- | --- |
| 范围及角色 | 用管理员和普通员工分别打开工作台。两种视角都没有创作画布和实拍混剪入口，原画布地址及任务接口不可用。管理员可进入用户视角并返回。员工可选已发布模板，直接请求切换管理视角、发布 Excel 或写公共预设均无法取得管理能力或修改公共数据。 |
| 提示词及参数 | 员工甲在项目 A 中为场景、分镜、运镜各保存一条常用词，重开会话后在自己的项目 B 中取用原文。员工乙只能看见公共预设和自己的常用，尝试修改甲的私有常用词时被拒绝。甲改写公共预设后，任务使用新文字，公共库仍展示管理员发布的原文。员工实际选用已开放模型、项目画幅、支持的时长及生成份数。 |
| 项目生成到混剪 | 用同一商品跑通一次生图和生视频。首次写脚本及结果页再生成均可选择爆文模板，界面和任务均只提供这一种 AI 写作模式。改一句可辨认的文字并保存。单条精准混剪与批量生产分别选用这份项目脚本，核对采用的版本。启用配音或字幕时，在导出的 MP4 中核对这句话。 |
| 自带文字与视频 | 在两个混剪入口分别选用「视频来源 × 文案来源」表中的四种搭配。另在没有生成视频或 AI 脚本记录的项目内，为单条选定分镜组、为批量建立批次，各自导入视频并带入自写文字。两处均能预览并导出使用这些输入的正式 MP4。 |
| 单条包装与贴纸 | 在预览中选包装模板、改一处标题或卖点，把贴纸放到指定位置和时段。保存并导出，打开下载的 MP4，在贴纸出现前、出现期间和结束后分别检查画面，并核对包装文字和所选视频。 |
| 批量逐条独立 | 设定生成份数，使同一批次至少有两条成片。只在第二条换镜头、加一张可辨认的贴纸，逐条审片并导出。分别播放两个 MP4，第一条对应原预览，第二条在指定时间出现改过的镜头和贴纸，各自的脚本和包装与各自预览一致。 |

自动回归复用已有的团队权限矩阵和爆文改写、单条精准混剪、批量贴纸浏览器测试。页面操作覆盖日常制作，权限测试补查员工直接发起写请求时的结果。主流程检查使用模拟供应商并关闭装饰包装，适合验证步骤间的数据交接。包装和贴纸的最终效果按上表播放实际 MP4 验收。[主流程检查](../../reference/主流程检查.md) · [两种混剪的贴纸导出验收先例](../../2026-11-17-贴纸接入收尾验收.md)

## Out of Scope

- 创作画布、本地实拍重组，以及「多方向生成」「痛点解决型 · 15秒」两种 AI 脚本模式。
- 公司素材库对接、云端素材处理和全司生产部署。这些属于 IT 对照 Demo 重写公司产品的阶段。
- 从个人本地版重建团队功能、分别制作管理员和员工安装包，或引入另一套登录体系。演示采用现有团队账号与本地预览。
