## 恢复与故障定位

- **结果未知**：查 `execution_media_tasks/channels`、`execution_operations/attempts`、异常中心的 remoteId；保持占用，只续查/核对，不重发。
- **画布取消后无下游**：确认 task `cancelRequestedAt/outputAssetId` 与 `creative_canvas_node_states` 未被发布；用户可查看/下载，但不自动推进。
- **通道一直被避让**：查 `/api/team/channel-health` 的三态、原因码、avoidUntil；恢复探针只放行一条普通任务。管理员手动停用必须单独重新启用 provider。
- **管理员核对冲突**：按 idempotencyKey/observed version 返回 409，刷新列表后重试；不要删除父任务或重置 channel。
- **旧任务不动**：旧行无统一父任务时按原快照；旧数据库升级失败先看 readiness code 和升级审计，不要手工改 migration 表。
