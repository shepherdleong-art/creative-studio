## 范围与基线

- 基线：`580c2bf6b78482878072bdf89c916fbc8fdbd6b7`，包含 PR #12–15。
- 独立分支：`codex/packaging-layout-v2-20261117`。
- 来源：旧分支 `d45feb92..1412328367bd929d1634e5bbeeffbb13f386eef9` 的布局增量。旧分支与当前 main 无共同祖先，没有整体合并其历史。
- 适配：保留主线末段贴纸的 65%／81% 位置、PR #14 原地版式同步，以及 PR #15 的历史互斥、复制版本检查、失败手势回滚和 Window／Document 身份检查。
- 原开发工作区保持原有分支和未提交改动；实施、构建和验收使用独立 worktree 与临时数据根。

## 实现与修复

1. 自动布局按实际模板、字体、透明贴纸和动画外框求解。开头／中段自动贴纸与正文卖点约束在画面上 40%；手动固定的位置优先。单条、批量、三种画幅共享求解与重放。
2. 资源身份包含模板、画幅、字体、贴纸、运行脚本、Chromium 和依赖。冻结文件使用独立副本；当前部署资源变化不会改写已有任务。引擎清单与内容哈希绑定，复制前后重验。
3. 首次冻结与完整性检查改成异步文件操作，避免阻塞 HTTP 轮询。并发请求共享进行中的引擎快照；不能用硬链接代替冻结。
4. v2 预览通过当前成片授权的资源路由读取冻结包，只交付清单内的浏览器资源；路径、内容摘要、模板及画幅不匹配时拒绝。配置切换后，已发出的 HTML 仍可在同一成片下加载原资源；跨成片、未发出的旧包及篡改文件仍拒绝。
5. 几何编辑、撤销、重算继续同步现有 iframe 文档。结构变化等待新布局就绪；自动贴纸手动编辑后固定解析位置，避免保存后回弹。撞上 stale 窗口的占位页在就绪后补载一次，防止永久等待；真实文档不会因此刷新。
6. 普通保存使旧解析结果失效；专用布局命令保存可信求解结果。派生缓存不增加用户修订、不清审核、不新增撤销；公开 PATCH 不能借派生更新绕过内容修订。
7. 单条后台校验键包含组／草稿修订、画幅、布局状态与实际包装输入，处理同修订卖点刷新；取消请求清理去重键。布局时长使用含口播倍速的实际成片时长。
8. 批量布局与已有编辑／复制／历史共用写入互斥，界面同步禁用相关编辑，避免点击后静默拒绝。自动重算失败后保留手动编辑能力，由「重试布局」显式重试，避免无限循环。跨片复制在事务内重验来源版本及修订；重试复用候选，全部目标成功或全部回滚。
9. 每个导出任务按自身草稿画幅、实际时长和最新卖点冻结布局。渲染前在冻结 Chromium 中等待字体、图片和重放 ready；缺失元素不进入正式渲染。包装未成功前不发布 v2 的半套视频／封面。
10. 离线资源装配增加布局服务和重放脚本；classic 渲染冻结域没有改动。
11. 单条预览的“成片时间线”角标不再拦截鼠标事件，自动布局在左上角的贴纸可以正常拖动。生产最小复现已确认修复前没有 pointerdown／保存请求，透传后同一位置保存返回 200。
12. 首次自动贴纸保存可能归一化旧同轨项，层级编号变化改为按 runtime 的 `1000 - trackIndex` 原地更新，不再因结构键变化重建 iframe。四模板新增回归在修复前出现额外 HTML 请求，修复后请求数与文档身份保持不变。
13. v2 将正式封面延后到包装完成时，同步延后原片 worker 的产物登记，避免提前登记不存在的文件导致导出失败。本地首次包装也返回封面路径，成功时登记视频／封面、失败时一并撤销；旧版先发布封面和团队不可变版本行为保留。

## 复现方式与边界

在本分支 worktree 运行 `npm run build`，将产物放到独立的 standalone 目录后设置：

```powershell
$env:STICKER_TEST_STANDALONE = '<独立 standalone 的绝对路径>'
$env:STICKER_TEST_TEAM = '1'
$env:STICKER_TEST_EVIDENCE_DIR = '<单条证据目录的绝对路径>'
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/packaging-stickers-editor.playwright.test.mjs
$env:STICKER_TEST_EVIDENCE_DIR = '<批量证据目录的绝对路径>'
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/batch-stickers-editor.playwright.test.mjs
```

生产浏览器验收使用 Windows、隔离团队账号与数据库、独立 standalone 负载；保护脚本阻止外网访问和源码资源回退。本次未执行 macOS 或安装程序验收。

测试保持原有交互约定：历史恢复后清空选中，验证文档身份后重新选中再执行手势；边缘控件按其在 iframe 内的可见部分取鼠标坐标；字体测量等待目标冻结文档及输入哈希匹配。导出视频通过 FFmpeg 管道抽取 PNG，再由 Node 保存，保留完整解码、音轨、帧数及贴纸像素断言。
