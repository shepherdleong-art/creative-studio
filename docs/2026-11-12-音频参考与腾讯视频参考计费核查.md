# 音频参考与腾讯视频参考计费核查

核查日期：2026-11-12（Asia/Singapore）。本记录核对公开文档、本地代码，并运行隔离上传与模拟供应商回归；没有提交真实付费生成任务，没有读取密钥。

## 工作台入口与音频参考能力

**画布可以上传音频，普通项目的视频面板目前没有音频参考上传按钮。** 画布素材节点的选择器接受 `audio/*`，素材导入支持音频；把音频素材连到视频节点，选择「全能参考/参考生视频」后提交。四个模型的生成参考合同都只开放 WAV/MP3（`audio/wav`、`audio/x-wav`、`audio/mpeg`）；M4A/AAC/OGG 虽能作为画布素材导入，也不能据此认定可直接发给这些模型。[画布素材选择器](../components/creative-canvas/nodes.tsx)、[素材导入](../lib/creative-canvas/assets.ts)、[视频参考合同](../lib/video-reference-contract.ts)

普通 `VideoGenerationPanel.tsx` 的文件输入只有首帧/尾帧图片，当前 H3/Wan 参考模式默认使用分镜图，不能在这个面板另外选择 MP3/WAV；底层项目上传接口与有序参考任务快照已经支持音频。后端支持和界面已经提供上传入口是两件不同的事。[视频面板](../components/VideoGenerationPanel.tsx)、[默认模式](../lib/video-generation-options.ts)、[项目参考素材上传](../app/api/projects/[id]/video-reference-assets/route.ts)

| 模型 | 本地允许的音频 | 单段时长 | 音频总长 | 纯音频条件 |
| --- | --- | --- | --- | --- |
| Seedance 2.0 标准版 | WAV/MP3，最多 3 段，单段 ≤15 MiB | 2–15 秒 | ≤15 秒 | 必须搭配图片或视频 |
| Seedance 2.5 | WAV/MP3，最多 10 段，单段 ≤15 MiB | 2–30 秒 | ≤30 秒 | 官方与本地均允许纯音频参考 |
| MiniMax H3 | WAV/MP3，最多 3 段，单段 ≤15 MiB | 2–15 秒 | ≤15 秒 | 本地允许；原厂和腾讯 TokenHub 文档有差异，VOD 纯音频未做付费验证 |
| Wan 3.0 | WAV/MP3，最多 5 段，单段 ≤15 MiB | 1–15 秒 | ≤15 秒 | 本地允许；腾讯 VOD 具体组合未做付费验证 |

以上数量和时长由本地精确模型合同及 prepare 校验共同约束。[共享合同](../lib/video-reference-contract.ts)、[画布公司能力](../lib/creative-canvas/adapters/company-capabilities.ts)、[公司提交前校验](../lib/creative-canvas/adapters/company.ts)、[Seedance 组合校验](../lib/creative-canvas/adapters/external.ts)

Seedance 两代的音频限制和组合条件由火山官方确认；Wan 的单段 1–15 秒、总长 ≤15 秒、最多 5 段、WAV/MP3、≤15 MB 来自阿里原厂，不能单凭原厂合同宣称已完成腾讯 VOD 真实音频出片验收。[火山视频 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Seedance 2.5 能力对照](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[Wan 3.0 原厂 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)

音频参考与首尾帧模式互斥，需使用参考生成模式。请求中的音频不会丢弃：Seedance 编成 `content[].type=audio_url`、`role=reference_audio`；H3/Wan 编成 `FileInfos[].Category=Audio`、`Usage=Reference`。本地音频交付必须经 COS 取得供应商可访问的 URL，缺配置或交付失败在生成 POST 前阻止提交。[Seedance 请求构造](../lib/video-providers/jimeng.ts)、[腾讯公司请求构造](../lib/video-providers/openai-video.ts)、[参考素材交付](../lib/video-providers/reference-media.ts)

## Seedance：音频参考如何计费

火山公式是 `(输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 输出帧率 / 1024`。这里不计输入音频秒数：只有文字/图片/音频、没有视频时，按「输入不含视频」单价；若同时给视频参考，使用「输入包含视频」档，并计入参考视频时长及最低 token 限制。实际用量以 `usage.completion_tokens` 为准。[火山官方价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)

| 模型 | 输出分辨率 | 输入不含视频（可含图片/音频） | 输入含视频（可同时含音频） |
| --- | --- | ---: | ---: |
| Seedance 2.0 标准版 | 480P / 720P | ¥46/百万 token | ¥28/百万 token |
| Seedance 2.0 标准版 | 1080P | ¥51/百万 token | ¥31/百万 token |
| Seedance 2.0 标准版 | 4K | ¥26/百万 token | ¥16/百万 token |
| Seedance 2.5 | 480P / 720P | ¥70/百万 token | ¥42/百万 token |
| Seedance 2.5 | 1080P | ¥77/百万 token | ¥46/百万 token |

本表为火山官方刊例价，Seedance 2.0 指标准版，不是 Fast 或 Mini。[官方模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)

以 16:9、1080P、输出 5 秒、没有视频参考为例，Seedance 2.0 约 **¥12.39**，Seedance 2.5 约 **¥18.71**；增加参考音频不会把音频秒数叠加进上述视频用量公式。Seedance 2.5 样片为 480P，约 **¥3.36/5 秒**，再转高清单独计费。[官方价格示例](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)、[本仓库样片计价记录](2026-11-12-Seedance2.5样片与转高清计价.md)

## 腾讯云：先确认产品和结算渠道

本项目公司网关最终透传的是云点播 VOD 的 `CreateAigcVideoTask`，其请求域名为 `vod.tencentcloudapi.com`。接口文档直接指向 VOD 的「按量计费（新）→ AIGC 生视频」，因此应优先使用该产品的人民币价格。`FileInfos[].Category` 可为 `Image`、`Video`、`Audio`，参考素材通过 `Usage=Reference` 标记；字段能够接收音频不代表每个模型、每种媒体组合都已被承诺支持。[VOD 创建任务](https://cloud.tencent.com/document/api/266/126239)、[VOD 数据结构：AigcVideoTaskInputFileInfo](https://cloud.tencent.com/document/api/266/31773#AigcVideoTaskInputFileInfo)

VOD 新价格页在本次读取时显示更新时间为 2026-11-03。旧价格页仅针对 2023-09-01 前开通且月结的特定用户。MPS（product 862）和 TokenHub（product 1823）是另两个产品；不能仅因同为腾讯云便套用其价格或能力合同。[VOD 新计费](https://cloud.tencent.com/document/product/266/95125#96b3b59a-f9e1-49e9-966a-bedb70a4bf12)、[VOD 旧计费适用范围](https://cloud.tencent.com/document/product/266/14666)

## MiniMax H3：参考视频价格已确认

当前应用使用的原生档位是 768P、2K。下表来自 VOD 自身价表，单位为人民币元/秒；示例假设生成成功、原生输出、参考图片不超过 5 张，不包含存储、传输等费用。[VOD Hailuo H3 价表](https://cloud.tencent.com/document/product/266/95125#96b3b59a-f9e1-49e9-966a-bedb70a4bf12)

| 原生输出档位 | 输入参考视频 | 输出视频 | 无视频参考，输出 5 秒 | 输入视频 5 秒 + 输出 5 秒 |
| --- | ---: | ---: | ---: | ---: |
| 768P | ¥0.50/秒 | ¥0.50/秒 | ¥2.50 | ¥5.00 |
| 2K | ¥0.80/秒 | ¥0.80/秒 | ¥4.00 | ¥8.00 |

计算式为 `输入视频总秒数 × 输入单价 + 输出秒数 × 输出单价 + max(输入图片数 − 5, 0) × ¥0.20`。输入视频按**输出档位**计价；原厂价格说明对此明确表述，且原厂这两档单价与 VOD 一致。因此，先把参考视频降成低清并不能据此按低清单价计费。VOD 用量对象也分别提供 `InputSeconds`、`OutputSeconds`、`TotalSeconds`。[MiniMax 原厂价格说明](https://platform.minimax.cn/docs/pricing/overview)、[VOD 用量结构](https://cloud.tencent.com/document/api/266/31773#AigcVideoTaskUsage)

VOD 页面另列 H3 的 1080P、4K 档位：输入视频分别 ¥0.50、¥0.80/秒，输出分别 ¥0.65、¥0.96/秒。直接检查网页表格标记可见，这两列 H3 价格带下划线及斜体，对应腾讯的超分直出；768P、2K 两列没有该标记。不要把 1080P、4K 当作当前模型的原生档位。腾讯声明超分增强直出已自 2026-04-15 开始收费，API 的 `EnhanceSwitch` 还允许在超过模型原生清晰度时启用增强。[VOD 超分与价格说明](https://cloud.tencent.com/document/product/266/95125#96b3b59a-f9e1-49e9-966a-bedb70a4bf12)、[VOD 输出配置](https://cloud.tencent.com/document/api/266/31773#AigcVideoOutputConfig)

H3 的上述数值也能在 MPS 的官方价表找到对应项；这证明本次核查的 **H3 刊例单价相同**，不证明两个产品的所有模型、增强处理或账单规则都共用。TokenHub 的 H3 价表也折合为 768P 输入/输出各 ¥0.50、2K 各 ¥0.80，但其用量按 token 结算。[MPS 价格](https://cloud.tencent.com/document/product/862/36180)、[TokenHub 模型价格](https://cloud.tencent.com/document/product/1823/130055)

VOD AIGC 新计费以元/秒列价，价格已乘抵扣比例；不应再给上表乘一次抵扣比例。本次未找到 H3 参考视频小数时长如何取整、是否有单次最低输入计量的明确条款；也不能把页面其他「转码不足一分钟按一分钟」的规则移用到 AIGC H3。上述整数 5 秒示例不涉及这个缺口。[VOD AIGC 出账说明](https://cloud.tencent.com/document/product/266/95125#96b3b59a-f9e1-49e9-966a-bedb70a4bf12)

## H3：音频参考支持，但“纯音频”存在渠道差异

MiniMax 原厂 API 与腾讯国内 TokenHub 指南均列出音频参考：WAV/MP3；最多 3 段；每段 2–15 秒；合计不超过 15 秒；单段不超过 15 MB。参考视频最多 3 段、每段 2–15 秒、总计不超过 15 秒、每段 50 MB；腾讯 TokenHub 的该段还限制图片/视频/音频混合输入合计最多 12 个文件。[MiniMax 原厂 API](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)、[原厂输入条件](https://platform.minimax.cn/docs/guides/video-generation)、[腾讯 TokenHub H3 指南](https://cloud.tencent.com/document/product/1823/135737)

**音频费用需要区分原厂与腾讯：** 原厂当前价格页明确说明音频输入免费，图片前 5 张免费、第 6 张起 ¥0.20/张。腾讯 VOD 的 H3 价格表列了输入图片、输入视频和输出视频，未列独立音频输入收费项；TokenHub 价表也未列 H3 音频计量。这能支持“未见额外音频价项”，尚不足以把原厂免费政策写成腾讯 VOD 已明确承诺的计费合同。[MiniMax 原厂价格](https://platform.minimax.cn/docs/pricing/overview)、[VOD 价格](https://cloud.tencent.com/document/product/266/95125#96b3b59a-f9e1-49e9-966a-bedb70a4bf12)、[TokenHub 价格](https://cloud.tencent.com/document/product/1823/130055)

**不要仅凭一份渠道文档判定 H3 纯音频可用或必然失败。** 腾讯 TokenHub 指南明确要求音频参考至少搭配一张图片或一个视频。当前 MiniMax 原厂 API/指南则写参考图片、视频或音频的组合，未列相同视觉媒体前提。VOD 通用 API 没有公开 H3 具体媒体组合限制，并提示开发者索取模型文档或参考原厂资料。本地当前 `allowsAudioOnly: true` 与 TokenHub 的限制有冲突，但不能直接把 TokenHub 限制移植为 VOD 的已验证合同；应将“VOD H3 纯音频”标记为待渠道确认或真机验证。[TokenHub 多模态参考说明](https://cloud.tencent.com/document/product/1823/135737)、[原厂输入组合](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)、[VOD 模型限制说明](https://cloud.tencent.com/document/api/266/126239)

## 已确认与待验证的边界

| 问题 | 本次结论 |
| --- | --- |
| H3 能参考音频吗 | 原厂及腾讯 TokenHub 明确支持；VOD 通用字段支持 Audio，具体渠道出片未实测 |

| H3 腾讯 VOD 视频参考价格 | 原生768P输入/输出各 ¥0.50/秒；2K各 ¥0.80/秒；输入与输出相加 |
