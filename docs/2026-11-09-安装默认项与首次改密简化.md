# 安装默认项与首次改密简化

## 行为

- 后续团队 Beta EXE 安装器默认勾选「内网连接」中的当前账号证书信任，仍允许用户取消。
- 不再生成或安装 `使用说明.txt`，安装完成页不再出现查看说明选项；许可证保留。
- 一次性密码登录成功后，仅填写新密码与确认密码。刷新登录页时，凭有效会话继续设置密码。
- 服务端从数据库判断是否处于已消费一次性凭据的首次改密状态；普通改密仍校验当前密码。改密后撤销会话，使用新密码重新登录。

## 验证与发布

认证服务、认证路由、登录字段校验测试已通过，覆盖不提交旧密码的首次/重置后改密、普通改密防绕过、无会话/失效/过期会话拒绝。TypeScript、相关 ESLint、主题令牌与深色契约检查通过。

浏览器回归脚本增加首次改密不显示旧密码框、刷新后继续改密的断言，并更新相关运维验收脚本。Chromium 与 WebKit 完整验收通过，覆盖首次改密、页面刷新、改密后重新登录，以及管理员与员工流程；浅深色截图检查通过。

本次修改源码与后续构建配置，未重打包或部署现有客户端、服务器。首次改密行为须随新版服务器页面与认证服务一起发布。
