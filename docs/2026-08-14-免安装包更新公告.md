# 创意工作台（免安装包）更新公告 · 2026-08-14 · 0.5.0

各位，共享盘里的创意工作台免安装包更新到 0.5.0 了。这轮最大的变化是**电脑上什么都不用装了**，另外修了几个影响使用的问题。请大家按文末指引更新。

## 一、修了什么 / 新功能

1. **不用装 Python 了** —— 包里已内置全部运行环境（Node + Python）。新电脑零安装，双击 `start-windows.cmd` 就能跑；启动不再有 1–3 分钟的环境重建，全程不需要联网。
2. **脚本生成不再丢进度** —— 以前生成脚本时切到别的步骤或刷新页面，进度和内容就丢了。现在生成由服务端任务持有，切走再切回来、刷新页面都会接着显示进度；取消按钮照常可用。
3. **部分公司模型报 401 Invalid token** —— 已修复。之前 seedance 视频等 13 个模型通道的 Key 是占位符，现在全部补齐。
4. **新增脚本模型 Luna（GPT-5-6-Luna-Standard）** —— 设置页可选。
5. **新版 GPT 模型报 400（temperature 不支持）** —— 已自动兼容，遇到不支持的模型会静默摘掉该参数重试。
6. **批量生产支持手动导入脚本** —— 第 5 步「批量生产」里可以手动粘贴/导入脚本，一次可导入多条。

## 二、你要做什么

**情况 A：你现在用的是 0.4.0 或更早（绝大多数人）**
整包复制新版本，但**保留你本地的 `data\` 和 `storage\` 两个文件夹不要覆盖**（那是你的项目和生成的素材）：
1. 把共享盘 `U:\内容摄制部\AI工作台\创意工作台-0.5.0-免安装版` 整个复制到本地磁盘
2. 如需保留旧数据：把旧包里的 `data\` 和 `storage\` 拷进新目录再启动
3. 本地残留的旧版 `.venv-litellm\` 文件夹可以删掉，新版用不到它

**情况 B：今天白天已经拷过 0.5.0 首装**
只做增量：从共享盘覆盖 `.next\standalone`（整目录）、`config.yaml`、`portable-manifest.json`、`使用说明.txt` 四样，重启工作台即可。

共享盘路径：
- `U:\内容摄制部\AI工作台\创意工作台-0.5.0-免安装版`
