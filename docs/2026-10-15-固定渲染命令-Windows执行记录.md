## 运行时升级与 D 模板修复

升级前真实运行 0.8.21 四模板测试，保存到 `packaging-0.8.21/`；统一升级至 0.8.134 后重跑并保存到 `packaging-0.8.134/`。Chrome 保持 152.0.7977.30。四模板第 0、10、34、47 帧共 16 帧全部 SSIM≥0.98，最低 0.993503；明细 `packaging-upgrade-ssim.json`。

既有 `packaging-preview-scale.playwright.test.mjs` 首轮发现 D 模板正文默认位置随预览尺寸偏移：360px 时 cue.y=0.3115，180/720/1080px 时为 0.2858/0.3243/0.3286。预览测试直接读取模板，不调用 HyperFrames。模板以 CSS `translate(-50%,-50%)` 初始化，GSAP 将偏移缓存成像素；缩放后缓存不随元素尺寸调整。

先在隔离返回 HTML 中将该处 `gsap.set` 补上 `x:0,y:0,xPercent:-50,yPercent:-50`，四模板全部缩放检查通过；随后依据执行文档第 3 节请求范围确认。用户明确授权“应用修复并补验”，仅在 `packaging/templates/overlay-variety/index.html` 修改这一行。
