### 已确认的两处 UI 问题

1. **批量正式封面下载 404**：`BatchStepExport.tsx` 把封面 artifact ID 传入 `artifactId`；`output-media.ts` 的契约是以视频 artifact ID 绑定视频及配对封面。两条均复现 `该版本没有正式视频产物`。只读诊断把参数改为同对视频 ID 后，两张 JPG 均返回 200 且 SHA256 与磁盘一致。
2. **Windows 导出目录文案只显示 `storage/`**：`BatchPreparationPanel.tsx` 仅按 `/` 切分服务端返回的反斜杠路径。实际文件归库正确；桌面打开目录逻辑另用 `workspace.exportDirName`，不据此断言实际打开目录错误。

用户于本轮明确授权「应用这两处修复并复测」。修改范围：封面链接改用正式视频 ID；提取显示目录前统一反斜杠。未放宽媒体谱系验证。补充 `batch-export-download-links.test.mjs`，实际渲染 React 导出卡，覆盖首次发布、正式版本替换、无封面与未发布情况。
