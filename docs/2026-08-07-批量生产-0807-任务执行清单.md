# T4 · 断句句数对齐（口播优先的前置）

## 🔴 先读这一段：两种形态是有意设计，不许统一成一种

仓库里有两套断句，**这是设计，不是历史遗留**（用户 2026-08-07 确认）：

| 位置 | 行为 | 用途 |
|---|---|---|
| `lib/batch-production/narration.ts:56` `splitScript` | 零宽 lookbehind，**保留标点** | 脚本内容预览、TTS 朗读、句段 id |
| `lib/batch-production/allocator.ts:463` `splitAllocationScriptBody` | **吃掉标点** | 分配、语义匹配 |

设计意图：字幕不能出现多余标点。（实际上标点在展示层还会再清一次 —— `splitNarrationForDisplay` 会把 `"周末午后，她窝在洒满阳光的客厅沙发里。"` 变成 `"周末午后"` / `"她窝在洒满阳光的客厅沙发里"`，所以字幕无论走哪条路径都不带标点。）

**所以：本卡要保留两种形态，只是让它们出自同一次切分。谁把两种形态合并成一种，就是把用户的设计砸了。**

## 目标
