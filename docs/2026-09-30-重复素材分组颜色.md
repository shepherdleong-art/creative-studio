# 重复素材分组颜色

统一橙色只能显示重复位置，无法对应是哪一个素材。本次将当前全批次的重复视频按素材 ID 排序，分配 A/B/C… 编号及 8 色色盘；跨成片的同一素材同色同编号，隐藏行仍参与统计。颜色循环时编号继续唯一，超过 Z 使用 AA/AB…。

同源图的不同视频保留独立身份：后端返回带权威原图 key 的 `sourceConflictGroups`，前端按 S1/S2… 分组。同一片段同时属于素材复用与同源提醒时，主体采用素材组色，同源徽标采用自己的组色。选择、定位、筛选和行顺序不会改变当前分组；编辑改变重复集合后按最新集合重新编号。源区间交叠斜纹保留，颜色随素材组变化。

浅深主题使用全局设计令牌，`@theme static` 防止 Tailwind 删除动态变量。选中片段仍保留蓝色选择框，其他组不因当前定位而失去色块；短片段徽标优先保留组号，其余说明截断，悬浮可查看分组含义。

- `batch-review-repeat-render.test.mjs`：真实组件色号/徽标、选中/定位兼容，以及 Tailwind 编译后动态颜色令牌仍存在。
- `batch-workspace.test.ts`、`batch-output-clip-edit.test.ts`：权威原图 key 随工作区及编辑视图返回，原有编辑及审核约束通过。
- `npx tsc --noEmit`、修改文件 ESLint、`git diff --check`。
- Playwright 操作隔离的真实时间线组件和编译后 CSS：4 组重复视频、2 组同源视频，共 6 组颜色各异，跨片对应一致；选中、重复筛选、浅深主题均验证。证据在 `outputs/repeat-group-check/`，不使用用户项目数据库。
