# 项目素材分析与预览 P0 执行边界

> 日期：2026-08-03
> 分支：`mixcut01`
> 基线：`f554e9c feat: complete batch mixcut phase E output pipeline`

## 1. 问题

批量准备区把没有 `currentAnalysisId` 的项目素材直接禁用，但只在批次快照已经建立并开始生产后才创建 `asset_prepare` 任务。快照又强制要求每份素材提交真实分析版本，导致新素材无法从用户界面进入批次。同时，选择卡只显示文件名、时长和尺寸，用户无法在选择前识别或播放素材。

这是 Phase A–E 从技术链路走向真实用户流程的 P0 阻塞；未修复前不进入 Phase F。

## 2. 用户流程

1. 用户进入批量准备区，每张在线项目素材卡立即显示真实缩略图。
2. 点击缩略图或“预览”可在当前页面播放原片；不暴露本地绝对路径。
3. 顶部“分析全部待分析”可一次排队所有在线待分析素材；每张卡也可单独开始。
4. 卡片显示持久任务的排队、定位来源、探测媒体、失败和重试状态；刷新后不丢失。
5. 分析成功后重新读取项目素材目录，卡片自动变为可选，不需要先建立批次快照。

## 3. 分析语义

- 当前 `asset_prepare` 只做本地 FFprobe 技术分析：容器、时长、宽高等可验证事实。
- 该结果标记为 `technical`，界面显示“基础分析可用”；不宣称已完成语义、质量、场景或可用区间理解。
- 只有未来真正产生场景、可用区间等内容理解结果的 Adapter 才标记为 `content`。
- `technical` 素材可被明确选入批次，但必须提示联合分配会使用基础时长回退；不伪造内容标签或语义评分。
- 本轮不调用真实 AI、TTS 或公司媒体网关。

## 4. 任务与数据边界

- 继续使用唯一的 `batch_tasks` / batch scheduler，不新增第二套队列。
- 选中的 draft 批次是分析任务的触发和恢复载体；分析版本仍属于项目素材库，可跨批次复用。
- 稳定 `requestKey` 保证重复提交幂等；失败重试只增加 attempt，不增加素材或成片计划。
- 批次开跑时不再为已锁定分析版本的素材重复建立分析任务。
- 跨项目、离线、已归档、内容已变化的素材不能排队或被读取。

## 5. 媒体安全

- 预览和缩略图只接受 `projectId + assetId`，路径从 SQLite 权威来源解析，不接受客户端路径。
- 每次解析前重验项目归属、普通文件、来源健康和完整 SHA-256；符号链接、越界、离线和内容变化统一拒绝。
- 缩略图从已核验原片抽真实帧，写入 `dataRoot()/storage` 下受控缓存，使用任务临时文件和原子发布，不修改原片。
- 原片预览支持 HTTP Range 和拖动，使用流输出，不把整个大文件读入内存。

## 6. API

- `POST /api/batch-production/batches/[id]/assets/analyze?projectId=...`
  - body: `{ "assetIds": ["..."] }`
  - 返回每份素材的 `ready | queued | running | failed` 及稳定 `taskId`。
- `GET /api/batch-production/assets/[assetId]/thumbnail?projectId=...`
  - 返回真实 JPEG 缩略图。
- `GET /api/batch-production/assets/[assetId]/preview?projectId=...`
  - 返回原片 Range 流。
- `GET /api/batch-production/prepare?projectId=...`
  - 每份素材增加 `analysisLevel`、`thumbnailUrl` 和 `previewUrl`，不返回任何本地路径。

## 7. 验收门禁

1. 项目素材可在快照前单条或批量排队，重复请求幂等，失败可重试。
2. 刷新页面恢复真实任务状态；完成后自动变为可选。
3. 每张在线素材卡显示真实缩略图，可键盘打开原片预览并关闭。
4. 链接、托管、模块 4 来源都通过真实 FFmpeg 缩略图验证；跨项目、内容变化和符号链接被拒绝。
5. 分析结果文案明确区分 `technical` 与 `content`，不伪造分析深度或进度。
6. Phase A–E 专项、TypeScript、lint、build、全部非 Playwright 测试和批量准备区 Playwright 通过。

## 8. 明确不做

- 不调用真实 AI、TTS、公司 LiteLLM 或媒体网关。
- 不生成伪内容标签、伪语义分数或伪可用区间。
- 不把项目素材分析绑定成不可复用的批次快照结果。
- 不新增平行队列、`mixcut_sessions` 或客户端任意路径参数。
- 不进入 Phase F，不 push。
