# 创意工作台（免安装包）更新公告 · 0.5.2 · 2026-08-19

各位，共享盘里的创意工作台免安装包已发布 0.5.2，新增「消耗」看板和可灵智能分镜开关，并修复了批量生产「换一批画面」换了等于没换的问题，请大家按文末指引更新本地包。

## 一、这次更新了什么

1. **新增「消耗」页** —— 顶部导航多一个「消耗」tab。公司 image2-medium（生图）、公司可灵 3.0、公司即梦 Seedance 2.0 Fast（视频）、GPT-5-6-Luna-Standard（脚本）、豆包 seed-tts-2.0（配音）五个核心模型的今日/本周/本月预估消耗、近 30 天趋势图、逐条调用流水都在这里看。注意是**按固定单价的预估口径，不是上游真实账单**；公网和其他自建供应商不统计。
2. **公司可灵 3.0 新增「智能分镜」开关** —— 在视频工位每条运镜卡里，模板/秒数旁边，默认开启。开启后可灵会自动把一条运镜拆成多个镜头（实测同一句提示词会出现全景切特写）；关掉就是原来的单镜头连续画面。只影响之后新建的视频任务，已生成的任务不变。
3. **修复「换一批画面」换了等于没换** —— 批量生产第 3 步的「换一批画面」之前是确定性分配：每次点都选回同样的素材、同样的开场和封面，同一个按钮点第二次甚至完全不产生新版本。现在点击会避开当前版本用过的素材和封面，**连续点、持续换**；素材池实在没有替代时才会复用旧素材。
4. **分镜生成模板默认文案更新** —— 改为床品类新版：「保持图中床和模特的一致性不变，更换卧室的其他家具和软装布置，构图参考分镜底图」。**只对新建项目生效**；已有项目在工作台「分镜生成模板」里手动改一下即可。

0.5.1 / 0.5.0 的内容你也一并拿到：

- 视频工位支持**首尾帧**（每条运镜可上传尾帧图，公司可灵 3.0、公司即梦 Seedance 2.0 均已实测，可灵出片 1080P 档）；
- **公司供应商开箱即用**：公司生图 image2-medium、公司可灵 3.0、公司即梦 Seedance 2.0 Fast、脚本 GPT-5-6-Luna-Standard 全部预置好，密钥由包内持有，不用手填地址和密钥；
- 脚本生成改为服务端任务化：生成中切步骤、刷新页面不再丢进度；
- 批量生产支持手动导入脚本（一次多条）；
- 内置 Node + Python 运行时，新电脑双击 `start-windows.cmd` 就能跑，不用装任何环境。

## 三、怎么更新（三选一）

**情况 A：整包重拷（最省心）**
1. 完全退出本地工作台（应用菜单「退出」）；
2. 把共享盘新包整个拷到本地一个新目录；
3. 把旧目录里的 `data\` 和 `storage\` 两个文件夹整个拷进新目录（这两个就是你的全部数据和素材，新包本身不带）；
4. 以后从新目录启动。旧目录改名留几天，确认没问题再删。

**情况 B：增量更新（最快）**
完全退出工作台后，只把共享盘里的 `.next\standalone`（整目录）、`portable-manifest.json`、`使用说明.txt` 覆盖到本地对应位置，重启工作台即可。

**情况 C：让 AI 帮你更新**
把下面这段话原样发给你的 AI 助手（workbuddy 等）：

> 帮我更新创意工作台免安装包到 0.5.2。共享盘路径：U:\内容摄制部\AI工作台\创意工作台-0.5.2-免安装版，我的本地路径是：【在这里填你的本地路径】。规则：只把共享盘的 .next\standalone、portable-manifest.json、使用说明.txt 覆盖到本地对应位置；绝对不要覆盖 data\ 和 storage\。完成后运行本地的 环境自检.cmd，把输出给我看。更详细的规则见共享盘包里的 使用说明.txt 第 8 步和末尾的更新记录。

共享盘路径：`U:\内容摄制部\AI工作台\创意工作台-0.5.2-免安装版`

## 四、注意事项

- 更新前一定先完全退出工作台，运行中拷贝可能拷到写了一半的数据库。
- 数据库是单向迁移：0.5.2 打开过的库不要再拷回旧版用。
- 不要直接在共享盘上双击运行，一定拷到自己电脑的本地磁盘再用。
- 包里的 config.yaml 和 .env.local 含公司密钥，请勿外传。
- 遇到问题：双击包里的 `环境自检.cmd`，把窗口输出发给 PK。
