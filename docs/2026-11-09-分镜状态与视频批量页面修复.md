# 分镜状态与视频、批量页面修复

## 原因与行为

- 分镜组的持久化 `generating` 状态没有随最后一张图完成而更新。列表和详情现在共用 `lib/shot-set-status.ts`，从各分镜当前任务与结果派生显示状态；已有结果的重做仍显示生成中，失败或取消不会冒充完成，保留人工审核状态。不迁移或重写历史项目数据。
- H3 / Wan 3.0 原来被固定到全能参考模式，首尾帧入口因此隐藏。按用户确认的原交互：单图自动全能参考，始终保留尾帧入口；上传尾帧后自动首尾帧，移除后自动回到全能参考，不要求手动切模式。旧草稿的模式字段不覆盖当前图片状态。尾帧上传、移除中或失败时阻止提交，供应商能力 allowlist 与 COS 交付门禁保持原规则。
- 视频左栏缩略图使用共享悬浮放大。浮层挂到 body，位置计算预留说明文字与边框空间，避免被工作台裁切或溢出窗口。
- 视频描述列表缺少独立滚动约束，增加描述会撑高工作区。右栏现在独立滚动，添加、生成操作固定在栏底；播放器按实际控制条高度容纳画面，竖视频不会因控制条换行而不断缩小。
- 批量「脚本与口播」的纵向 flex 页面被压缩，配音选项溢出所属卡片并覆盖背景音乐、封面和字幕。页面现在按内容高度展开，主区承担滚动，卡片不再互相覆盖。
- 批量脚本参照 0.7.1 本地版恢复宽窗口双列摘要，窄窗口单列。勾选与展开独立，最多展开一个编辑器（跨列使用完整宽度），脚本区最高 70dvh / 640px、内部滚动；全选 40 条不会展开 40 份配音表单，也不把后续设置推得更远。折叠保留份数和配音设置，编辑器切换不影响是否参与生成。
