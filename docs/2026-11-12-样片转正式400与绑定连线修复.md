# 样片转正式 400 与绑定连线修复

用户截图中的转正式节点已经通过 `draftAssetId` 固定绑定样片，但旧界面没有绘制这层关系；生成按钮创建请求时默认带 `returnLastFrame=false`，适配器把它编码为 `return_last_frame:false`。上游返回 `400: draft promotion cannot include return_last_frame; invalid_draft_task`，拒绝的是请求参数。

## 修复

- 转正式使用独立白名单，完全省略 `return_last_frame`（false 与 true 都不允许出现在该请求中）。公司网关仍只补传输层要求的空 `prompt`；普通直接生成保留返回尾帧能力。
- 新节点不再预置这个选项，Final 界面隐藏“返回尾帧”，规划器剔除旧节点保存的该参数。现有样片及固定身份保留，用户刷新后可从同一个样片发起新的正式生成，无需重做样片。
- 按固定样片资产 ID 派生一条带“固定样片”标签的只读虚线。它不写入参考槽位或任务输入，不触发分支生成，也不把样片算作收费的视频参考。刷新后由原绑定重建；替换素材不会改变固定样片。

## 验证

`seedance-final-request.test.ts` 已先复现相同 400，再验证原生与公司网关两条真实适配器的请求都不带该字段；网络由模拟传输接管。`creative-canvas-draft-binding.test.ts` 覆盖显示关系、刷新重建、资产替换、普通生成和已有连线去重。完整供应商回归覆盖规划、持久化和提交。

其余验证包括 Seedance、即梦适配器、画布规划/图模型、阶段计费回归、严格 TypeScript 和 ESLint。浏览器验收与生产构建结果随部署记录保存。验证没有发起真实付费生成，也没有自动重试用户失败任务。

生产编译与完整 TypeScript 检查通过；独立 standalone 构建通过，浏览器 Seedance 套件验证虚线显示、刷新重建、无返回尾帧选项且未产生生成请求。完整主流程检查也通过。
