## Standards

1. **保存失败后预览保留未保存的贴纸位置。** 空间编辑提交返回成功状态，失败恢复初始几何；文档已切换或已有更新的手势时，旧回滚不得覆盖新状态。浏览器通过注入保存 500 验证。
2. **批量贴纸回调未绑定来源 iframe。** 共用回调检查来源 Window 与 Document，并使用当前处理器；旧文档、其他 iframe 和已切换的预览无法提交或改变选择。独立真实 iframe 回归通过。
3. **恢复尚未完成时可操作旧历史。** API 已写入但安排刷新未结束时，连续重做可能取到前一条局部历史；同时进行复制又可能导致撤销误删新历史。普通编辑、跨片复制、撤销与重做现在共用操作锁，覆盖写入、权威刷新与历史栈更新，所有退出路径释放锁。慢响应回归先在旧生产包稳定失败，再在修复包检查按钮禁用、快捷键/添加/复制零额外写入和最终整组重做。
