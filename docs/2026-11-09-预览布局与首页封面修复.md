# 预览布局与首页封面修复

## 范围

- 首页封面通过共享 storage URL 转换生成相对地址，避免服务器绝对路径进入图片 URL；图片本身未丢失。
- 单条混剪的画幅约束放到实际画面，不再给含工具栏和播放控件的整个容器套画幅。普通预览与全屏都按可用宽高完整容纳画面。
- 单条包装 GET HTML 与 iframe 显式使用相同的浅色合成模式，保持透明。页面本身仍支持浅色、深色。
- 场景图/分镜原图和结果使用同高、受窗口高度约束的容器；完整显示图片，点击大图打开居中预览，Esc 关闭并恢复焦点。
- 删除视频的重复只读设置卡片；选择或预览一条视频时回填原有可编辑设置。保留改动提示和还原功能。
- 批量素材改为至少 260px 的等高卡片，统一完整缩略图、两行文件名、横向状态、独立分析操作；来源详情折叠，保留定位、预览、选择和 LUT 操作。

## 根因证据

原项目 `3aea872f-bd19-48a1-b8c5-dd114ce92cc3` 的 7 条原视频仍存在，当前单条时间轴有 7 个片段。在生产数据库在线备份和视频副本上启动原版服务，7 个预览 URL 均返回 `206 video/mp4`，实际使用 `overlay-poster`。

取该副本产生的实际包装 HTML 重放，在深色宿主下中央像素被不透明背景替换。`node scripts/single-packaging-theme.playwright.test.mjs --legacy` 对原版设置稳定失败；去掉 `--legacy` 后，实际 GET HTML 构造器的四套模板、浅深色全部通过。此测试检查视频透出像素，不仅检查 DOM 是否存在。
