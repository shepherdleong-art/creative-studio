## 6. 运行方法与两个必踩的坑

```bash
node --unhandled-rejections=warn scripts/final-edit-mixcut.playwright.test.mjs
```

**坑 1：不要接管道。** `node ... | tail -60` 拿到的是 `tail` 的退出码（0），会让你误判为通过。要退出码就直接跑，或 `> log 2>&1; echo $?`。

**坑 2：真错误会被掩盖。** 脚本用 `try/finally` 关浏览器。断言一抛错，`finally` 关掉浏览器，此前创建但未 await 的 `page.waitForResponse(...)` promise 随即 reject，抛出

```
page.waitForResponse: Target page, context or browser has been closed
```

这个未捕获拒绝会先杀掉进程，**把真正的断言错误吞掉**。所以必须带 `--unhandled-rejections=warn` 才能看到真因。看到 `waitForResponse ... has been closed` 时，**它不是根因，往下翻**。
