## 二、新增功能：7 大功能组 / 18 项操作能力

### 1. 视频提示词批量工作流（5 项）

把"每条自己填"改造成可复用、可检查、可一次提交的标准流程：

- 模板池：复用常用视频与运镜表达；
- 一键填充：批量给待生成分镜补提示词；
- 保留手写：已有人工内容不被强制覆盖；
- 批量检查：提交前确认缺失与异常；
- 全部生成：一次发起整组视频任务。

### 2. 运镜模板（1 项）

自定义运镜模板与随机填充池开关；内置模板从 6 条扩充到 11 条，并对齐模型词表、去重。常用运镜从临时手敲变成可复用选择。

### 3. 全局三态主题（1 项）

浅色 / 深色 / 跟随系统，适配长时间生产与暗光环境。

### 4. 批量任务控制（2 项）

- 生产并发可调；
- 队列支持暂停与恢复，进度卡支持手动停止，停止后再开跑不再卡死。

### 5. 成片片段级自由编辑（6 项）

批量混剪从"生成即定稿"升级为"生成后可精修"：

- 时间线预览；
- 调整长度；
- 替换片段；
- 插入片段；
- 删除片段；
- 分割片段。

### 6. 每脚本封面样式（1 项）

同一批次内可为不同脚本选择不同封面方案，并带封面标题预览切换。

### 7. 脚本生成透明化（2 项）

- 生成阶段指示：知道进行到哪一步；
- 正文流式输出：从"无响应式等待"变成过程可见。

## 三、优化与修复：32 项，分六类

以下按类别给出数量与代表性事项（完整清单见 `git log 9415939..54810de`）。

### 脚本（8）

校验分级基座（blocking/advisory + 最优候选保留）；模板可行性改降级出稿（部分阶段缺失不再一票否决）；封面标题三级兜底（严格结构 → 沿用模型措辞 → 服务端合成）；卖点采用表改服务端推导；错误码与 details 白名单打通前端；警告条与可操作失败面板替代 alert 死胡同；脚本生成统一固定 `temperature=1`（公司 Luna 网关只接受默认温度）；生成中保留上次耗时参照、修正校验卡文案与封面分隔符。

### 图片（4）

公司图片原生像素交付（只裁不缩）；七牛图片请求改无损 PNG、产物按真实格式落盘；分镜生成默认提示词更新（构图与机位景别严格参考图1）；尺寸吸附与任务恢复类修复。

### 视频（4）

批量检查抽屉改版与首尾帧体验改进；批量生成确认从 window.confirm 改为抽屉内联二次确认；队列并发控制；结果归一化与尾帧守卫。

### 批量生产（7）

混剪预览流式 + ETag 缓存与拖动手感改造，修复 Windows 口播丢失；片段调整期不排重渲染（退出该轮时一次性提交）；封面标题预览脚本下拉独占整行并加悬停提示；批量生产进度卡手动停止，修复停止后再开跑卡死与语义匹配无限重试；调度、隔离与恢复类修复。

### 界面（6）

全局三态外观切换与夜间模式；深色模式下原生 select 弹层可读性修复，桌面壳同步 nativeTheme；数字输入点击聚焦全选、失焦才夹取边界（修复输入被瞬时夹成上限）；项目列表任务数计入视频任务，与全口径金额对齐；日志文件时间戳改用本地时间；状态与错误表达改进。

### 成本与用量（3）

核心模型消耗看板完善；视频消耗识别放宽至回环网关并回填存量公司视频任务；七牛 image 模型序列标签加供应商前缀，避免与 image2-medium 混淆。

## 四、一线反馈闭环状态

- **已解决（2）**：视频批量生成；混剪手动修改。
- **明显改善（6）**：模板、脚本、封面、控制、统计与交互。
- **仍待解决（7）**：封面/分镜/场景数量规范；分镜提示词模板库；场景、素材与封面的感知查重；安全产量边界（多少素材支撑多少视频）；口播音量 / 总音量 / 渐入控制；封面字体真实映射与差异；每日端到端生产与花费看板。
- **待定义（1）**："紫菜卷"需业务方补充含义。

## 五、下一步优先级

- **P0 · 直接影响交付**：补齐口播 / 总音量 / 渐入控制，以及字体真实映射。
- **P1 · 降低审核风险**：感知查重与安全产量，从"靠人记住别重复"升级为系统预警与产量边界。
- **P2 · 形成规模治理**：生产规范与每日看板，统一数量、提示词与端到端进度 / 花费口径。
