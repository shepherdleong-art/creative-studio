# 画布任务面板增强（时间 + 缩略图预览）与 @ 素材自动补全

## Context

用户两个诉求（对标 ComfyUI / 即梦）：

1. **全部任务面板**：现在只显示画布名、类型、nodeId、状态和错误文本（[CanvasTaskDrawer.tsx](file:///Users/liangpeijian/for-cc/creative-studio-canvas/components/creative-canvas/CanvasTaskDrawer.tsx)），没有生成时间、没有产物缩略图，看结果必须回画布找节点。希望像 ComfyUI 一样显示生成时间和缩略图，点击缩略图直接预览产物。
2. **@ 素材引用**：生成节点的提示词是纯 `<textarea>`，`@参考N` 靠手写文本 + 事后正则校验（`resolveCanvasMentions`），引用只能靠手动连线产生。希望像即梦一样：输入 `@` 即弹出素材候选（带缩略图），点一下自动完成引用。

现状关键点（已核实）：

- `CanvasTaskDto` 已有 `outputAssetId / createdAt / updatedAt / mediaKind / phase`，产物 URL 用 `canvasAssetUrl(outputAssetId)` 拼（[api.ts](file:///Users/liangpeijian/for-cc/creative-studio-canvas/components/creative-canvas/api.ts) L225），无需改后端。
- 素材节点的 lightbox 是内联实现、仅支持图片（[nodes.tsx](file:///Users/liangpeijian/for-cc/creative-studio-canvas/components/creative-canvas/nodes.tsx) L408-426），抽成共享组件即可复用。
- 连线即引用：material/prompt/生成节点 → 生成节点 加边后 `reconcileCanvasGraph` 自动建槽位、分配 label；`editor-store` 的 `commit` 同步更新 `nodesRef.current`，加边后 label 可立即读回。重复连线被 `checkCanvasConnection` 以 `duplicate_connection` 拒绝。

## 改动一：任务面板（CanvasTaskDrawer.tsx + 共享 Lightbox）

1. **新增共享组件** `components/creative-canvas/AssetLightbox.tsx`：全屏遮罩（复用 `--color-media-scrim`）、支持图片与视频（`<video controls autoPlay>`）、下载按钮、点击遮罩/Esc 关闭。把 MaterialNode 内联 lightbox 抽到这里，MaterialNode 改用它（行为不变，`data-testid="material-lightbox"` 保留）。
2. **CanvasTaskDrawer.tsx** 列表项：
   - 有 `outputAssetId` 时显示 40×40 缩略图：图片用 `<img>`，视频用 `<video muted playsInline preload="metadata">`（首帧即缩略）+ 小 ▶ 角标；点击缩略图打开 AssetLightbox（`e.stopPropagation()`，不触发定位），`data-testid="task-thumb-${task.id}"`。
   - 时间行：`MM-dd HH:mm:ss`（createdAt）+ 终态任务追加 `· 耗时 Xs`（updatedAt − createdAt，<1s 显示 `<1s`；终态 = succeeded/failed/cancelled/download_failed）。进行中任务显示已耗时可后续再加，本期不做。
   - 失败任务无产物：不显示缩略图，错误文本保持现状。
3. 样式加到 `app/globals.css` 现有 `sc-canvas-*` 区块旁（`.sc-canvas-task-thumb` 等），全部走设计令牌，不加硬编码浅色值。

## 改动二：@ 素材自动补全（GenerationNode）

1. **纯逻辑** `lib/creative-canvas/mention-completion.ts`（可单测）：
   - `findActiveMentionQuery(text, caret)`：光标前最近 `@` 起、中间无空白/换行、且 `@` 前是空白或行首时，返回 `{ start, query }`；否则 null。
   - `filterMentionCandidates(candidates, query)`：按标题 + `@参考N` 形式做不区分大小写子串匹配，空 query 返回全部。
   - `replaceMentionWithLabel(text, start, caret, label)`：把 `@query` 段替换为 `@参考{label} `，返回新文本与新光标位置。
2. **controller 新方法** `connectReference(targetNodeId, sourceNodeId): number | null`（editor-store.ts，挂进 `CanvasController` 接口）：复用 `checkCanvasConnection` + `commit`；`duplicate_connection` 时不报错、直接返回既有槽位 label；其他失败 toast 并返回 null；成功后从 `nodesRef.current` 读回 `slot.sourceNodeId === sourceNodeId` 的 label。
3. **GenerationNode UI**（nodes.tsx）：
   - 候选源 = `graph.nodes` 中 kind 为 `material` / `prompt` / 生成节点（排除自身）；素材与生成节点用 `resolveSourceAssetId` 取缩略图，prompt 节点显示「文本」占位；每项显示标题、类型角标、已连接时的 `@参考N`。
   - textarea 包一层 relative 容器，下方绝对定位候选菜单（`nodrag`、`data-testid="mention-menu"`），项 `data-testid="mention-option-${nodeId}"`。
   - 交互：onChange/onSelect 时按 `findActiveMentionQuery` 更新菜单；↑↓ 移动高亮、Enter/Tab 选中、Esc 关闭；IME 组合期间（`isComposing`）不拦截按键；菜单项用 `onMouseDown + preventDefault` 保持 textarea 焦点。
   - 选中流程：`connectReference(id, sourceNodeId)` 拿 label → `replaceMentionWithLabel` 替换文本 → 走现有 `promptIme` 的 commit（`updateNodeData` coalesce）→ 恢复光标。连线由 commit 自动产生（用户能看到溯源边，与手动连线完全一致）。
4. 样式：`.sc-canvas-mention-menu` 等，跟随现有弹层风格（圆角、hairline 边框、表面色令牌）。
